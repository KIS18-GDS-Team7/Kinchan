# ユースケースドキュメントのファイル名は UC-XXX.md とする

## ステータス
決定

## 背景
- 要件定義書に基づいてユースケース(UC)ドキュメントを作成するにあたり、`docs/usecase/README.md` のディレクトリ構成例が `UC-XXX-hoge.md` 形式(番号+説明語)になっていた
- 説明語を付けるとUC名の変更のたびにファイル名のリネームが必要になり、参照元のリンク切れも起きやすい
- UC番号は要件定義書やADRからも参照されるため、番号だけで一意に特定できる名前のほうが追いやすい

## 決定
- UCドキュメントのファイル名は `UC-XXX.md`(例: `UC-001.md`)とし、説明語は付けない
- UCの名称はファイル名ではなくドキュメント本文の見出しで表現する
- `docs/usecase/README.md` のディレクトリ構成例の修正は、本ADRのマージ後に別PRで実施する
