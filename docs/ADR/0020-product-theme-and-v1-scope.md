# 勤怠管理の Web アプリを作り、位置情報による打刻制限は v1.0 に入れない

## ステータス

決定

## 背景

- 作るものの候補として、経費計算アプリ、教える人と教わる人のマッチングアプリ、グッズ交換のマッチングアプリ、位置情報から打刻の可否を決める勤怠システムが挙がった ([#3](https://github.com/KIS18-GDS-Team7/Kinchan/issues/3))。
- 勤怠システムに決めた後、ブレストで出た機能の案から v1.0 に入れるものを選んだ ([#6](https://github.com/KIS18-GDS-Team7/Kinchan/issues/6))。
- 要件定義書の 2 章 (スコープ) は、対象範囲・対象外とも TBD のままである。

## 決定

- Web アプリとして作る (#3、2026/09/30)。
- 勤怠管理のシステムを作る (#3、2026/09/30)。
- v1.0 で作る機能は次のとおりとする (#6、2026/10/01)。
  - シフトの機能と打刻の機能。
  - 勤怠管理者向け: 勤怠の修正、シフトの登録・変更・削除、シフト希望の承認、勤務実態の表示。
  - 従業員向け: 打刻、勤怠修正申請の送信、シフト希望の送信、シフトの表示 (自分の分だけでなく)、シフト日時変更申請の送信。
- 次の機能は v1.0 に入れず、v1.1 以降で必要に応じて加える (#6)。
  - 位置情報による打刻制限。
  - #6 で「カレンダー機能」と呼んだもの。
- v1.0 に入れていた「勤務可能時間によるシフト制限」は外す ([ADR-0015](./0015-drop-availability-and-staffing.md))。
- 要件定義書の 2 章への反映は別の PR で行う。
