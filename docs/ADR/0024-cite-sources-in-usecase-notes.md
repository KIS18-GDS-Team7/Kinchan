# UC 記述の備考に、判断の出典と未決の点を書く

## ステータス

決定

## 背景

- [#73](https://github.com/KIS18-GDS-Team7/Kinchan/issues/73) の議論 (#74〜#97) で決まったことに沿って、UC 記述を全件書き直した ([#98](https://github.com/KIS18-GDS-Team7/Kinchan/pull/98))。
- UC 記述に反映した判断の出典は、issue だけではない。モックの案A の判断ログ (A-番号) から取り込んだものと、#73 の sub-issue を閉じた日 (2026/10/21・22) の UnrealKinoko と Claude の会話で決めたものがある。会話で決めたものは issue に記録していない (#98)。
- #98 では、会話が出典の箇所に異論があれば指摘するよう求めた。
- 2026/11/05 時点で、UC 記述と要件定義書には「暫定」が 104 か所、「TBD(要起票)」が 45 か所ある。

## 決定

- UC 記述の備考に、反映した判断の出典を書く (#98、2026/10/22)。出典は次の形で書く。
  - `#番号`: issue で決まったもの。
  - `A-番号`: モックの案A の判断ログから取り込んだもの。
  - `2026-10-21の会話` など: その日の会話で決まったもの。
  - `〜からの導出`: 出典の判断から導いたもの。
  - `暫定`: 仮に決めたもので、変わりうるもの。
  - `TBD(要起票)`: 未決で、issue を立てて決めるもの。
- 未決の点は備考に `TBD` と書き、用語集にない語で埋めない ([ADR-0003](./0003-avoid-ambiguous-terms.md))。
- 振り直し前の UC の ID は、モックの判断ログで使われているので書き換えない ([docs/usecase/usecase-diagram.md](../usecase/usecase-diagram.md))。
