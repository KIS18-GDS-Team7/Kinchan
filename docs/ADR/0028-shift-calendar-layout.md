# シフトのカレンダー表示

## ステータス

提案（PR #120 のモック。管理者表示と日別表示は [ADR-0029](./0029-shifts-for-multiple-employees.md) で更新）

## 背景

- 利用者から、公開モックのシフトをカレンダー方式で見やすく表示するよう依頼された。
- UC-308 は所属単位の従業員の公開済みシフトを対象期間ごとに表示する。表示範囲と公開条件は維持する必要がある。
- [ADR-0021](./0021-no-screen-layout-in-usecases.md) により、カレンダーなどの画面の形は画面設計で扱う。

## 決定

- モックの従業員のシフト一覧と勤怠管理者のシフト管理は、選択した対象期間を月ごとのカレンダーで表示する。一覧表示にも切り替えられる。
- 日付を選択すると、その日の従業員名・開始時刻・終了時刻と、既存のシフト詳細への操作を表示する。
- 自分のシフトは色と「自分」の文字で区別する。勤怠管理者には「公開」「下書き」を文字でも表示する。
- 狭い画面では日付ごとの件数を表示し、選択した日の詳細をカレンダーの下に表示する。曜日は7列で配置する。
- 対象期間が複数月にまたがる場合は、その対象期間に含まれる月だけ切り替えられる。
- 従業員に最初に提示する対象期間は UC-308 の TBD のままとし、対象期間の選択を求める。ログイン直後の打刻画面と、既存の登録・変更・削除・公開・申請の条件は維持する。
