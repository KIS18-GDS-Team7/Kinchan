# 複数人のシフトを表示する画面

## ステータス

提案（PR #120 のモック。ADR-0028 の管理者表示と日別表示を更新）

## 背景

- 利用者から、複数人が同じ日に勤務する場合も表示しやすいように、従業員は月カレンダーと日別の全員の勤務時間、勤怠管理者は従業員と日付の表へ変更するよう依頼された。
- UC-308 は所属単位の従業員の公開済みシフトを表示する。UC-201 の備考4では、同じ従業員に1日複数のシフトを登録できる。
- 日付内に一部の従業員名だけを表示すると、複数人の勤務時間を比較できない。[ADR-0021](./0021-no-screen-layout-in-usecases.md) に基づき、表示の形を変更する。

## 決定

- 従業員の月カレンダーには、その日にシフトがある人数・シフト件数と、自分のシフトがあることを表示する。日付を選択すると、その日の全員の公開済みシフトを従業員ごとに表示する。同じ従業員の複数の勤務時間も省略しない。
- 勤怠管理者のシフト管理は縦に管理先の従業員、横に選択した対象期間の日付を配置する。シフトがない従業員の行も表示する。従業員名と日付はスクロール時も固定して表示する。
- 各従業員・日付の欄に、該当するすべてのシフトの開始時刻・終了時刻・「公開」「下書き」を表示する。勤務時間から既存のシフト詳細を開く。
- 日付を選択すると、その勤務日を入力済みにして既存のシフト登録へ進める。「—」はシフトがないことを表し、休日とは判定しない。一覧表示への切り替えも維持する。
- UC-308 の最初の対象期間は選択を求めるままとする。ログイン直後の打刻画面、公開範囲、権限、登録・変更・削除・公開・申請の処理条件は変更しない。TBD の値や業務機能は追加しない。
