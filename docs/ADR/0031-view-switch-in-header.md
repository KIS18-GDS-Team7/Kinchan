# 表示する画面の切り替えをヘッダー右上に配置する

## ステータス

決定

## 背景

- PR作成者 GkGit0 から、本PRのモック調整を進めているチャットで、「表示する画面」と従業員・勤怠管理者などの切り替えを右上に配置するよう指示を受けた。

## 決定

- 既存の画面切り替えをヘッダー右上に配置し、ラベルと選択中の画面を表示する。
- 狭い画面では通知・アカウントの下に右寄せし、ボタンの操作領域を維持する。勤怠管理者・マスタ管理者の画面選択は従来どおりヘッダーの下に表示する。
- ログイン直後の打刻画面、権限に対応した選択肢と画面遷移は変更しない。業務機能や TBD の条件は追加しない。
