# ユーザー登録と編集の入口を明示する

## ステータス

提案（PR #120 のモック）

## 背景

- 既存のユーザー登録・編集をどこから開くか分かりやすくするよう依頼された。GitHub にない機能は追加しない。
- main の UC-101 はユーザー登録、UC-102 は対象ユーザーの氏名・ユーザーID・パスワードの変更、UC-107 は一覧と詳細の表示を定義している。いずれもマスタ管理者が操作する。

## 決定

- マスタ管理者ホームに「ユーザー登録」と「ユーザー編集」を分けて表示し、既存の登録画面と対象を指定する一覧へリンクする。
- 追加の依頼に従い、PC のメニュー・狭い画面の画面選択・画面名を「ユーザー検索」と表示する。当初は氏名と操作を同じ列にしたが、その後の依頼で、氏名・ユーザーID・権限・所属・管理先を別々の列にした表に戻す。既存の編集・詳細ボタンは「操作」欄にまとめ、狭い画面では表の横スクロールで表示する。
- 詳細の編集ボタンを「ユーザー情報を編集する」と表示する。権限・所属・管理先は従来どおり別の操作とし、削除済みユーザーの編集は追加しない。
- 追加の依頼に従い、既存の検索欄に「ユーザー検索」と対象条件を表示し、ボタンを「検索する」と表示する。UC-107 の検索条件と対象範囲は変更しない。
- 登録・編集の入力項目、検証、確認、キャンセル、権限、登録後の詳細表示は維持する。ログイン直後の打刻画面と右上の画面切り替えも維持し、新たな業務機能や TBD の条件は追加しない。
