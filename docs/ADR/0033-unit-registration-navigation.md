# 所属追加をマスタ管理者のメニューに表示する

## ステータス

提案（PR #120 のモック）

## 背景

- 利用者から、所属単位登録のボタンを左メニューに追加するよう依頼された。
- 続けて、登録操作の表示を「所属追加」に変更するよう依頼された。
- main の UC-108 は、マスタ管理者による所属単位の名称入力・検証・登録確認・登録を定義している。モックには既存の登録フォームがある。

## 決定

- マスタ管理者の左メニュー・画面名・既存の登録ボタンを「所属追加」と表示し、既存の登録フォームを使用する。狭い画面では既存の画面選択に同じ項目を表示する。
- メニューから開いた画面は、登録完了または入力画面のキャンセルでマスタ管理者ホームへ戻る。既存のホーム・ユーザー検索画面から開く登録操作は維持する。
- マスタ管理者だけが操作できる条件、名称の必須・重複検証、登録前の確認とキャンセル時の入力破棄を維持する。所属単位の変更・削除や勤怠管理者の人数など、TBD の条件は追加しない。
