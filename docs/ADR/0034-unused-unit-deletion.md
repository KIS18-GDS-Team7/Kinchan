# 未使用の所属単位だけを削除する

## ステータス

提案（PR #120）

## 背景

- 所属削除の依頼があったが、main の UC-108 では変更・削除が TBD だったため、未実装として削除条件を提示した。
- 「現在・過去の参照がない所属だけを削除し、使用中には理由を表示する」方針について承認があり、GitHubへの仕様記載後にモックへ実装するよう依頼された。

## 決定

- UC-110・FR-028と用語の定義を追加し、先に仕様だけをコミット・pushしてから実装する。mainへの直接pushやPRのマージは行わない。
- マスタ管理者だけが操作でき、対象の所属単位名を提示して削除の確認を求める。実行時にも権限・対象の存在・現在と過去の参照を再判定する。
- ユーザーの所属と管理先の過去の参照を保持する。シフト・シフト希望と申請・対象期間と受付期間・勤怠記録とそれらの履歴も、日付・状態・削除済みユーザーの別を問わず判定する。勤務実績の所属を後から推測しないよう、勤怠記録が作られた時点の所属単位を保持する。
- 使用中の場合は理由を表示するだけとし、関連データの削除や所属・管理先の自動解除は行わない。未使用の場合だけ登録済みの所属単位から対象を除外する。保存方法に依存せず、削除後は所属と管理先に指定できない。
- モックはマスタ管理者の左メニューとホームから「所属削除」を開き、対象ごとに削除可否と理由を表示する。使用中の対象では削除ボタンを無効にする。キャンセルでは変更しない。
- 追加の依頼に従い、削除確認ダイアログに「ユーザーの所属・管理先・シフト・申請・対象期間・勤怠記録などで使われている所属は削除不可。過去の参照も含めます。」と表示する。
- 所属単位名の変更・使用中の所属単位の閉鎖・復元などは追加しない。SVG・PNG・astahの図は変更せず、Mermaidと一覧にUC-110を追記し、SVGが追加前であることを明示する。
