# 所属の追加と削除を所属一覧にまとめる

## ステータス

提案（PR #120 のモック）

## 背景

- 左メニューを「所属一覧」とし、その遷移先から所属の追加と削除を行う構成にするよう依頼された。
- あわせて「ユーザー検索」のメニュー名と画面名を「ユーザー一覧」に変更するよう依頼された。

## 決定

- マスタ管理者の左メニューと狭い画面の画面選択に「所属一覧」を1項目だけ表示する。ホーム・ユーザー一覧からの所属への入口も同じ一覧へ遷移する。
- 所属一覧の「所属追加」で既存の入力・確認ダイアログを開き、各所属の削除ボタンで既存の削除確認を開く。完了・キャンセル後も更新した一覧を表示する。ホームへ戻る操作は一覧に表示する。
- 以前の所属追加・削除のURLは所属一覧へ遷移させる。単独の追加画面・削除画面はメニューに表示しない。この配置はADR-0033・0034の入口を置き換える。
- ユーザーのメニュー名と画面名は「ユーザー一覧」とする。画面内の「ユーザー検索」の見出しと検索条件、項目を分けた表、編集・詳細の操作は維持する。
- UC-108の追加条件、UC-110の未使用・過去参照の判定、最終実行前の再判定と指定の説明文は変更しない。新たな業務機能や他のTBDの条件は追加しない。
