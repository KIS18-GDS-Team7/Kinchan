# 所属一覧の説明を簡潔に表示する

## ステータス

提案（PR #120 のモック）

## 背景

- 利用者から、所属一覧の上部の説明を指定の短い文面に置き換え、所属ごとの詳しい理由の箇条書きを表示しないよう依頼された。

## 決定

- 上部の案内を「ユーザーの所属・管理先・シフト・申請・対象期間・勤怠記録などで使われている所属は削除不可」と表示する。
- 各所属には名称・削除可否・削除ボタンを表示する。参照先ごとの詳細理由と未使用時の補足文は表示しない。削除ボタンの説明には削除可否を関連付ける。
- 共通の案内と削除可否で使用中の所属を削除できないことを表示する。UC-110 の現在・過去の参照、最終実行前の再判定、確認ダイアログの説明文は変更しない。理由の判定自体は削除せず、モデルの検証とエラー処理を維持する。
