# 入力画面と所属一覧の不要な戻りボタンを表示しない

## ステータス

提案（PR #120 のモック）

## 背景

- ユーザー登録の入力画面の「キャンセル」と所属一覧の「ホーム」は不要と依頼された。

## 決定

- ユーザー登録の入力画面の下部は「内容を確認する」だけを表示する。所属一覧の下部に「ホーム」は表示しない。この配置はADR-0035の一覧内の戻り操作を置き換える。
- 左メニューと狭い画面の画面選択による移動は維持する。ユーザー登録から画面を移動した後に入力内容を残さない既存の動作は変更しない。
- 登録・追加・削除の確認ダイアログ、および他の入力画面のキャンセルは維持する。入力検証・確認・登録・削除の条件は変更しない。
