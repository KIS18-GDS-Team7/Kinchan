# ログアウトを左メニューの下部に表示する

## ステータス

決定

## 背景

- ログアウトボタンを左下に表示するよう依頼された。

## 決定

- 勤怠管理者・マスタ管理者のPC画面で、左メニュー最下部の所属・権限表示の下に「ログアウト」を表示する。
- 高さが狭い画面ではメニュー部分をスクロールできるようにし、下部のログアウト操作は表示領域内に配置する。
- UC-302の既存のログアウト確認を使用する。キャンセルでログイン状態を維持し、実行でログアウト完了を表示する条件は変更しない。
- 左メニューを表示しない画面では、従来のアカウントメニューや従業員メニューからのログアウトを維持する。ログイン直後の打刻画面や権限は変更しない。
