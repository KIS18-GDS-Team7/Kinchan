# ユーザー一覧の編集ボタンから詳細画面を開く

## ステータス

決定

## 背景

- PR作成者 GkGit0 から、本PRのモック調整を進めているチャットで、ユーザー一覧の「詳細」ボタンを削除し、「編集する」の遷移先を従来の詳細画面に変更するよう指示を受けた。
- UC-107は一覧から指定したユーザーの詳細表示と、削除済みユーザーを含める検索を定義する。UC-102では削除済みユーザーを編集対象にしない。

## 決定

- ユーザー一覧の未削除ユーザーには「編集する」を1つだけ表示し、従来の詳細画面へ遷移する。独立した「詳細」ボタンと、一覧から変更フォームを直接開く操作は表示しない。
- 詳細画面内のユーザー情報・権限・所属・管理先などの既存の操作は維持する。この判断はADR-0032の一覧から変更フォームを直接開く配置を置き換える。
- 削除済みユーザーは「表示する」から同じ詳細画面を開く。変更操作を表示しない既存の条件を維持する。
- 一覧の説明文とREADMEを遷移に合わせる。表形式、検索条件、マスタ管理者だけの操作範囲、ユーザー登録の専用画面、各変更の検証・確認・キャンセルは変更しない。業務機能やTBDの条件は追加しない。
