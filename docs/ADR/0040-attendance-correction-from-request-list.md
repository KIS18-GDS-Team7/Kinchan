# 勤怠修正を勤怠修正申請の一覧から開く

## ステータス

決定

## 背景

- 勤怠管理者の左メニューに「勤怠修正申請」と「勤怠修正」が別々の項目として並んでいた。勤怠修正申請の一覧には、勤怠記録を直接修正する操作を表示していなかった。
- 勤怠管理者は、届いた勤怠修正申請の内容を基に勤怠記録を修正する場合がある。一覧と修正が別の項目に分かれていると、申請の対象者と対象日を修正画面で指定し直す必要があった。
- 勤怠記録の修正を勤怠修正申請の一覧から開けるようにし、左メニューの項目を1つにまとめたい。
- UC-207〜209 は勤怠修正申請の処理、UC-210 は勤怠管理者による勤怠記録の修正を定義している。

## 決定

- 勤怠管理者の左メニューと狭い画面の画面選択から「勤怠修正」を削除する。勤怠修正の画面を表示している間は「勤怠修正申請」を選択中として表示する。
- 勤怠修正申請の一覧に「従業員と日付を指定して勤怠を修正する」を表示し、既存の従業員・対象日の指定から勤怠修正を開く。
- 一覧の各申請に「勤怠を修正する」を表示し、申請の従業員と対象日を指定した勤怠修正を開く。削除済みユーザーの申請には表示しない。
- 勤怠修正申請の一覧から開いた勤怠修正は、完了・キャンセル後に勤怠修正申請の一覧へ戻る。勤務実態から開いた勤怠修正は、従来どおり勤務実態へ戻り、「勤務実態」を選択中として表示する。
- 勤怠記録を直接修正しても申請の処理状態は変更しない。勤怠修正の入力項目・検証・確認・権限、申請の承認・却下の条件は変更しない。業務機能や TBD の条件は追加しない。
