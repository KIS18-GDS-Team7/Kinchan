# 従業員の申請をドロップダウンにし、メニューをアカウントボタンにまとめる

## ステータス

決定

## 背景

- 従業員の下部メニューには「ホーム・勤怠・シフト・申請・メニュー」があり、「申請」と「メニュー」はそれぞれ専用の画面へ遷移していた。どちらの画面も画面遷移図にはなかった ([#127](https://github.com/KIS18-GDS-Team7/Kinchan/issues/127))。
- 「申請」の画面は各申請画面へのリンクを並べるだけで、「メニュー」の画面の内容（ユーザーID・所属単位・権限・通知・ログアウト）は右上のアカウントボタンの内容とほぼ重なっていた。
- 画面遷移図にない画面をなくし、申請と個人の情報を、画面を移動せずに開けるようにしたい。

## 決定

- 従業員の下部メニューは「ホーム・勤怠・シフト・申請」の4項目にする。「メニュー」の画面は削除する。
- 「申請」は画面を開かず、下部メニューの上にドロップダウンを表示する。内容は従来の申請画面と同じとし、勤怠修正申請一覧・シフト希望一覧・シフト希望提出（受付期間中だけ）・シフト日時変更申請一覧・勤怠修正申請の送信を表示する。
- ドロップダウンは項目の選択、外側の選択、Escキー、画面の移動で閉じる。申請に関する画面を表示している間は「申請」を選択中として表示する。
- 右上のアカウントボタンで開くアカウントメニューに、ユーザーID・所属単位・権限・通知・ログアウトを表示する。勤怠管理者・マスタ管理者の画面でも同じ内容を表示する。
- 以前の申請画面・メニュー画面のURLは従業員のホームへ遷移させる。各申請画面、ログアウトの確認、権限による表示範囲は変更しない。業務機能や TBD の条件は追加しない。
