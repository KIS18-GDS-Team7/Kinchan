## 1. 目的・背景

### 1.1 本システム(Kinchan)が解決する課題

- 法律では勤怠を1分単位で記録することが義務付けられているが、現状15分単位など実施していない店舗が存在する
- 出勤時・退勤時の打刻忘れや誤入力が発生し、管理者の修正業務など手間が発生している
- アナログで勤怠を登録しているため、手作業による時間や記入ミス・確認ミスのリスクがある
- 労働時間や残業状況が可視化されず、36協定の労働時間超過や過重労働のリスクがある

### 1.2 目的

- 法律に基づいた1分単位の勤怠の打刻・記録が行えるシステムの構築
- 希望シフトの提出から勤怠集計までの一連の業務をシステムで行い、手作業による転記・集計の負担を解消すること
- リアルタイムでの勤務実態の可視化と、管理業務の効率化

### 1.3 ゴール

- 1分単位で打刻、及び勤怠実態をシステムで一括管理できる状態にすること
- 従業員のシフト希望提出・変更申請、管理者の承認・シフト管理をシステム上で完結できる状態にすること
- 打刻データ・確定シフトに基づき、手作業なしで予定シフトと実際の勤務状況を確認できる状態にすること

## 3. ステークホルダー・アクター

| アクター | 説明 |
| --- | --- |
| 従業員 | 勤怠ツールで打刻する、クライアント企業の従業員 |
| 管理者 | クライアント企業に最低一人は存在する、アカウント発行・失効・他各種オペレーションを行う管理者 |
| 勤怠管理者 | 支店や事業部単位で、従業員の勤怠実績や勤怠修正の承認・拒否などを行う者 |
