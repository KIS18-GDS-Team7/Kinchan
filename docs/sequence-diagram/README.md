# シーケンス図

ユースケース記述 (`docs/usecase/`) の各 UC を 1 枚ずつシーケンス図にしたもの。#42 の成果物。

- `sequence-diagram.asta` — astah のプロジェクト。全 43 枚をパッケージ「シーケンス図」に入れている
- `images/UC-xxx.svg` — レビュー用に書き出した画像。`.asta` から astah CLI で出力したもの (#72・#107 と同じく手元で出力。CI 導入後は CI が生成する画像に置き換える想定)

担当: @Luka-Jr2

## 書き方

| 要素 | 書き方 |
| --- | --- |
| ライフライン | 左から アクター / 画面 (Boundary) / 制御 (Control) / エンティティ。画面名は画面遷移図、エンティティ名は概念クラス図に合わせている |
| メッセージ | UC のメインフローの 1 ステップを 1〜2 本のメッセージにする。戻りメッセージ (破線) は、データを受け取るところだけに書く |
| 結果の提示 | 制御 → 画面「〜を表示する」、画面 → アクター「〜を提示する」の 2 本。成功もエラーも同じ形 |
| 代替・例外フロー | UC を終了するものは break、条件つきのステップは opt、元のステップに戻るものは alt + ノート、繰り返しは loop |
| 別図にする代替フロー | 10 ステップ以上の別経路 (UC-306・UC-307 の Alt-1) は別の図にし、本編のノートから参照する |
| ノート | 判断の出典 (ADR・Issue 番号) と、UC の事後条件から決まること |

書き方は ADR にする予定 (番号は PR を出すときに取る)。

## 編集するときの注意

この `.asta` は UC 記述から起こしたテキスト (1 UC 1 ファイル) を astah API で描画して作っている。生成元はまだリポジトリに入れていないので、**astah で直接編集した内容は、作り直したときに失われる**。

- 図を直したいときは @Luka-Jr2 に連絡するか、生成元をリポジトリに入れてから直す
- UC 記述が変わったら、その UC のテキストを直して全図を描き直す

生成元 (テキストと生成スクリプト) をリポジトリに入れるかは別途相談したい。

## 未決の点
