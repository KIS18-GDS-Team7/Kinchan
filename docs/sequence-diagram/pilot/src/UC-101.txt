title UC-101 ユーザーを登録する
scope メインフロー、Alt-1、Alt-2、Ex-1、Ex-2

actor A マスタ管理者
boundary HM システム管理者ホーム画面
boundary F ユーザ登録画面
control C ユーザー管理制御
entity U 従業員

# メインフロー 1〜2
A -> HM : ユーザ登録ボタンを押す(ユーザーの登録を要求する)
note : システム管理者ホーム画面のユーザ登録ボタンからユーザ登録画面に移る(画面遷移図)
HM -> C : ユーザーの登録を要求する
C -> F : ユーザ登録画面を渡す

# メインフロー 2〜4 と Alt-1・Alt-2
loop 誤りが無くなるまで繰り返す
F -> A : ユーザー情報(氏名, ユーザーID, パスワード)の入力を求める
A -> F : ユーザー情報を入力する
F -> C : 入力内容の検証を要求する(氏名, ユーザーID, パスワード)
C -> C : 入力規則を検証する
note : ユーザーID: 半角英数字と . _ - の4〜20文字。パスワード: 8文字以上で英字と数字を含む。氏名: 1〜30文字(備考1、A-17)
C -> U : 同じユーザーIDのユーザーを探す(削除済みユーザーを含む)
U --> C : 有無
note : ユーザーは概念クラス図の「従業員」。削除済みユーザーのユーザーIDとも重複できない(備考3)
opt ユーザー情報が無効、またはユーザーIDが重複している
C -> F : 無効である理由、またはユーザーIDの重複を渡す
F -> A : 無効である理由、またはユーザーIDが重複していることを提示する
note : Alt-1・Alt-2。メインフロー2に戻る
end
end

# メインフロー 5
C -> F : 入力されたユーザー情報を渡す
F -> A : 入力されたユーザー情報を提示し、登録の確認を求める

# Ex-1
break 登録のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を渡す
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。ユーザーは登録されない
end

# メインフロー 6〜7
A -> F : 登録ボタンを押す(ユーザーの登録を指示する)
F -> C : ユーザーの登録を要求する(氏名, ユーザーID, パスワード)
C -> U : ユーザーを登録する(氏名, ユーザーID, パスワード)
note : 登録したユーザーは権限を持たず、所属も未設定(事後条件、備考2)。権限は UC-104、所属は UC-105 で扱う

# Ex-2 とメインフロー 8
alt 保存に失敗した
C -> F : 保存に失敗したことを渡す
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー5に戻る
else 保存に成功した
C -> F : 登録の完了を渡す
note : 登録ボタンではユーザ登録画面にとどまる(画面遷移図)
F -> A : ユーザーの登録が完了したことを提示する
end
