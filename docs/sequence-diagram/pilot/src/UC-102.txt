title UC-102 ユーザーを編集する
scope メインフロー、Alt-1〜3、Ex-1、Ex-2

actor A マスタ管理者
boundary HM システム管理者ホーム画面
boundary F ユーザ情報編集画面
control C ユーザー管理制御
participant DM DataManager
entity U 従業員

# メインフロー 1〜3
A -> HM : ユーザ編集ボタンを押す(ユーザー情報の変更を要求する)
note : システム管理者ホーム画面のユーザ編集ボタンからユーザ情報編集画面に移る(画面遷移図)
HM -> C : ユーザーの一覧を要求する
C -> DM : 削除済みでないユーザーの一覧を取得する
DM -> U : 削除済みでないユーザーの一覧を取得する
U --> DM : ユーザーの一覧(氏名, ユーザーID)
DM --> C : ユーザーの一覧(氏名, ユーザーID)
note : 削除済みユーザーは対象にしない(事前条件)
C -> F : ユーザーの一覧を渡す
F -> A : ユーザーの一覧を提示し、対象のユーザーの指定を求める
A -> F : 対象のユーザーを指定する
F -> C : 対象のユーザーのユーザー情報を要求する(ユーザー)
C -> DM : 対象のユーザーを取得する
DM -> U : 対象のユーザーを取得する
U --> DM : 氏名, ユーザーID
DM --> C : 氏名, ユーザーID

# メインフロー 4〜6 と Alt-1〜3
loop 誤りが無くなるまで繰り返す
C -> F : 対象のユーザーの現在の氏名とユーザーIDを渡す
F -> A : 対象のユーザーの現在の氏名とユーザーIDを提示し、変更後のユーザー情報(氏名, ユーザーID, パスワード)の入力を求める
A -> F : 変更後のユーザー情報を入力する
F -> C : 入力内容の検証を要求する(氏名, ユーザーID, パスワード)
opt パスワードが入力されていない
C -> C : 対象のユーザーのパスワードを変更の対象から除く
note : Alt-3。メインフロー6に進む(備考2、A-18)
end
C -> C : 入力規則を検証する
note : 入力規則は UC-101 と同じ(備考1、A-17)
C -> DM : 対象以外で同じユーザーIDのユーザーを探す(削除済みユーザーを含む)
DM -> U : 対象以外で同じユーザーIDのユーザーを探す(削除済みユーザーを含む)
U --> DM : 有無
DM --> C : 有無
note : 削除済みユーザーのユーザーIDとも重複できない(備考3、暫定)
opt ユーザー情報が無効、またはユーザーIDが重複している
C -> F : 無効である理由、またはユーザーIDの重複を渡す
F -> A : 無効である理由、またはユーザーIDが重複していることを提示する
note : Alt-1・Alt-2。メインフロー4に戻る
end
end

# メインフロー 7
C -> F : 変更後のユーザー情報を渡す
F -> A : 変更後のユーザー情報を提示し、変更の確認を求める

# Ex-1
break 変更のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を渡す
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。ユーザー情報は変更されない
end

# メインフロー 8〜9
A -> F : ユーザー情報の変更を指示する
F -> C : ユーザー情報の変更を要求する(ユーザー, 氏名, ユーザーID, パスワード)
C -> DM : ユーザー情報を変更後の内容に更新する(氏名, ユーザーID, パスワード)
DM -> U : ユーザー情報を変更後の内容に更新する(氏名, ユーザーID, パスワード)
note : 権限は UC-104、所属は UC-106 で扱い、ここでは変えない(備考6)

# Ex-2 とメインフロー 10
alt 保存に失敗した
C -> F : 保存に失敗したことを渡す
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー7に戻る
else 保存に成功した
C -> F : ユーザー情報の変更の完了を渡す
F -> A : ユーザー情報の変更が完了したことを提示する
note : 変更後のユーザー情報はメインフロー7で提示済みのため、更新後に取得し直さない(メインフロー10)
end
