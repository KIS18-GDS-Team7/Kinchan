title UC-103 ユーザーを削除する
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A マスタ管理者
boundary F ユーザ情報編集画面
control C ユーザー管理制御
participant DM DataManager
entity U 従業員
entity SF シフト
entity SD シフト削除履歴
entity OU 所属単位

# メインフロー 1
A -> F : ユーザーの削除を要求する
note : ユーザーの削除を要求する画面は画面遷移図にない。ユーザ情報編集画面を流用する(暫定)
F -> C : ユーザーの一覧を要求する
C -> DM : 削除済みでないユーザーの一覧を取得する
DM -> U : 削除済みでないユーザーの一覧を取得する
U --> DM : ユーザーの一覧(氏名, ユーザーID)
DM --> C : ユーザーの一覧(氏名, ユーザーID)

# メインフロー 2〜3 と Alt-1
loop アクター自身でないユーザーが指定されるまで繰り返す
C -> F : ユーザーの一覧を渡す
F -> A : ユーザーの一覧を提示し、対象のユーザーの指定を求める
A -> F : 対象のユーザーを指定する
F -> C : 削除の確認を要求する(ユーザー)
C -> C : 対象のユーザーがアクター自身かを判定する
opt 対象のユーザーがアクター自身
C -> F : 削除できないことを渡す
F -> A : 対象のユーザーがアクター自身であるため削除できないことを提示する
note : Alt-1。メインフロー2に戻る。最後のマスタ管理者の削除もこれで防ぐ(備考4、A-20)
end
end

# メインフロー 4
C -> DM : 対象のユーザーを取得する
DM -> U : 対象のユーザーを取得する
U --> DM : 氏名, ユーザーID
DM --> C : 氏名, ユーザーID
C -> DM : 対象のユーザーの勤務日が翌日以降のシフトを取得する
DM -> SF : 対象のユーザーの勤務日が翌日以降のシフトを取得する
SF --> DM : シフトの一覧
DM --> C : シフトの一覧
note : 状態が「下書き」か「公開」かを問わない(備考3)
C -> DM : 対象のユーザーに割り当てられた管理先を取得する
DM -> OU : 対象のユーザーに割り当てられた管理先を取得する
OU --> DM : 管理先の一覧
DM --> C : 管理先の一覧
C -> F : 氏名・ユーザーID、翌日以降のシフトの件数、割り当てが外れる管理先を渡す
F -> A : 対象のユーザーの氏名・ユーザーID、勤務日が翌日以降のシフトの件数、削除によって割り当てが外れる管理先を提示し、削除の確認を求める

# Ex-1
break 削除のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> F : キャンセルの完了を渡す
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。ユーザーは削除されない
end

# メインフロー 5〜9
A -> F : ユーザーの削除を指示する
F -> C : ユーザーの削除を要求する(ユーザー)
loop 対象のユーザーの勤務日が翌日以降のシフトごと
C -> DM : 削除するシフトを削除履歴に記録する(削除シフト日時, 操作者, 操作日時)
DM -> SD : 削除するシフトを削除履歴に記録する(削除シフト日時, 操作者, 操作日時)
note : 操作者は概念クラス図にない(UC-203 備考4、暫定)
C -> DM : シフトを削除する
DM -> SF : シフトを削除する
end
C -> DM : 対象のユーザーを削除済みにする
DM -> U : 対象のユーザーを削除済みにする
note : 論理削除(備考1、ADR-0013)。削除済みを表す属性は概念クラス図にない(暫定)。勤怠記録・申請・履歴は残す。削除したユーザーには通知しない(備考2・3)
C -> DM : 対象のユーザーに割り当てられた管理先を外す
DM -> OU : 対象のユーザーに割り当てられた管理先を外す
note : 管理先が無ければ外すものは無い(備考5、暫定)。シフト・削除履歴・ユーザー・管理先はまとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 10
alt 保存に失敗した
C -> F : 保存に失敗したことを渡す
F -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー4に戻る
else 保存に成功した
C -> F : ユーザーの削除の完了を渡す
F -> A : ユーザーの削除が完了したことを提示する
end
