title UC-104 ユーザーの権限を変更する
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A マスタ管理者
boundary E ユーザ情報編集画面
boundary F ユーザ権限変更画面
control C 権限制御
entity U 従業員
entity P 権限
entity OU 所属単位

# メインフロー 1
A -> E : ユーザ権限変更ボタンを押す(ユーザーの権限の変更を要求する)
note : ユーザ情報編集画面のユーザ権限変更ボタンからユーザ権限変更画面に移る(画面遷移図)
E -> C : ユーザーの一覧を要求する
C -> U : 削除済みでないユーザーの一覧を取得する
U --> C : ユーザーの一覧(氏名, ユーザーID)

# メインフロー 2〜3 と Alt-1
loop アクター自身でないユーザーが指定されるまで繰り返す
C -> F : ユーザーの一覧を表示する
F -> A : ユーザーの一覧を提示し、対象のユーザーの指定を求める
A -> F : 対象のユーザーを指定する
F -> C : 権限の変更の入力を要求する(ユーザー)
C -> C : 対象のユーザーがアクター自身かを判定する
opt 対象のユーザーがアクター自身
C -> F : 権限を変更できないことを表示する
F -> A : 対象のユーザーがアクター自身であるため権限を変更できないことを提示する
note : Alt-1。メインフロー2に戻る。最後のマスタ管理者から権限を外す操作もこれで防ぐ(備考3、A-20)
end
end

# メインフロー 4〜5
C -> P : 対象のユーザーの現在の権限を取得する
P --> C : マスタ管理者権限・勤怠管理者権限の有無
C -> F : 対象のユーザーの現在の権限を表示する
F -> A : 対象のユーザーの現在の権限を提示し、変更後の権限(マスタ管理者権限・勤怠管理者権限それぞれの有無)の入力を求める
A -> F : 変更後の権限を入力する
F -> C : 変更の確認を要求する(変更後の権限)

# メインフロー 6
C -> F : 変更前と変更後の権限を表示する
opt 変更後の権限に勤怠管理者権限が含まれない
C -> F : 管理先の割り当てが外れることを表示する
F -> A : 管理先の割り当てが外れることを提示する
note : メインフロー6。変更後の権限に勤怠管理者権限が含まれない場合だけ提示する
end
F -> A : 変更前と変更後の権限を提示し、変更の確認を求める

# Ex-1
break 変更のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を表示する
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。権限は変更されない
end

# メインフロー 7〜9
A -> F : 権限の変更を指示する
F -> C : 権限の変更を要求する(ユーザー, 変更後の権限)
C -> P : 対象のユーザーの権限を変更後の内容に更新する
note : 付与も解除もここで扱う(備考2)。1人が両方の権限を持てる(備考1、暫定)。「従業員」は権限ではない(ADR-0012)
opt 変更後の権限に勤怠管理者権限が含まれない
C -> OU : 対象のユーザーに割り当てられた管理先を外す
note : 管理先の割り当てを外すことは暫定(備考4)
end
note : 権限と管理先はまとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 10
alt 保存に失敗した
C -> F : 保存に失敗したことを表示する
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー6に戻る
else 保存に成功した
C -> F : 権限の変更の完了を表示する
F -> A : 権限の変更が完了したことを提示する
note : 勤怠管理者権限を付けたユーザーには UC-109 で管理先を割り当てる(備考7)
end
