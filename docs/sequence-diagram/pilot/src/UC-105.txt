title UC-105 ユーザーの所属を設定する
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A マスタ管理者
boundary HM システム管理者ホーム画面
boundary F ユーザ所属設定画面
control C 所属制御
entity U 従業員
entity OU 所属単位

# メインフロー 1〜3
A -> HM : 所属設定ボタンを押す(ユーザーの所属の設定を要求する)
note : システム管理者ホーム画面の所属設定ボタンからユーザ所属設定画面に移る(画面遷移図)
HM -> C : ユーザーの一覧を要求する
C -> U : 削除済みでないユーザーの一覧を取得する
U --> C : ユーザーの一覧(氏名, ユーザーID)
C -> F : ユーザーの一覧を表示する
F -> A : ユーザーの一覧を提示し、対象のユーザーの指定を求める
A -> F : 対象のユーザーを指定する
F -> C : 所属の設定の入力を要求する(ユーザー)
C -> U : 対象のユーザーの所属を取得する
U --> C : 所属

# Alt-1
break 所属がすでに設定されている
C -> F : 所属がすでに設定されていることを表示する
F -> A : 対象のユーザーの所属がすでに設定されていることを提示する
note : Alt-1。このユースケースを終了する。設定済みの所属は UC-106 で変更する(備考2、A-21)
end

# メインフロー 4〜5
C -> OU : 登録されている所属単位を取得する
OU --> C : 所属単位の一覧(名称)
C -> F : 登録されている所属単位を表示する
F -> A : 登録されている所属単位を提示し、所属とする所属単位の指定を求める
A -> F : 所属とする所属単位を1つ指定する
note : 1ユーザーにつき所属は1つ(備考1、ADR-0007)
F -> C : 設定の確認を要求する(ユーザー, 所属単位)

# メインフロー 6
C -> F : 対象のユーザーと指定された所属単位を表示する
F -> A : 対象のユーザーと指定された所属単位を提示し、設定の確認を求める

# Ex-1
break 設定のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を表示する
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。所属は設定されない
end

# メインフロー 7〜8
A -> F : 所属の設定を指示する
F -> C : 所属の設定を要求する(ユーザー, 所属単位)
C -> U : 対象のユーザーの所属を指定された所属単位に設定する
note : 所属が未設定のユーザーは、シフト・打刻・シフト希望・申請の UC を実行できない(備考3、暫定)

# Ex-2 とメインフロー 9
alt 保存に失敗した
C -> F : 保存に失敗したことを表示する
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー6に戻る
else 保存に成功した
C -> F : 所属の設定の完了を表示する
F -> A : 所属の設定が完了したことを提示する
note : 管理先は所属とは別のデータで、UC-109 で扱う(備考6)
end
