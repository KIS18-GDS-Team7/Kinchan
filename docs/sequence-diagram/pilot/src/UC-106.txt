title UC-106 ユーザーの所属を編集する
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A マスタ管理者
boundary S ユーザ所属設定画面
boundary F 所属変更画面
control C 所属制御
participant DM DataManager
entity U 従業員
entity OU 所属単位

# メインフロー 1〜3
A -> S : ユーザ所属変更ボタンを押す(ユーザーの所属の変更を要求する)
note : ユーザ所属設定画面のユーザ所属変更ボタンから所属変更画面に移る(画面遷移図)
S -> C : ユーザーの一覧を要求する
C -> DM : 削除済みでないユーザーの一覧を取得する
DM -> U : 削除済みでないユーザーの一覧を取得する
U --> DM : ユーザーの一覧(氏名, ユーザーID)
DM --> C : ユーザーの一覧(氏名, ユーザーID)
C -> F : ユーザーの一覧を渡す
F -> A : ユーザーの一覧を提示し、対象のユーザーの指定を求める
A -> F : 対象のユーザーを指定する
F -> C : 所属の変更の入力を要求する(ユーザー)
C -> DM : 対象のユーザーの現在の所属を取得する
DM -> U : 対象のユーザーの現在の所属を取得する
U --> DM : 所属
DM --> C : 所属

# Alt-1
break 所属が設定されていない
C -> F : 所属が設定されていないことを渡す
F -> A : 対象のユーザーの所属が設定されていないことを提示する
note : Alt-1。このユースケースを終了する。未設定の所属は UC-105 で設定する(備考3、A-21)
end

# メインフロー 4〜5
C -> DM : 登録されている所属単位を取得する
DM -> OU : 登録されている所属単位を取得する
OU --> DM : 所属単位の一覧(名称)
DM --> C : 所属単位の一覧(名称)
C -> F : 現在の所属と登録されている所属単位を渡す
F -> A : 対象のユーザーの現在の所属と登録されている所属単位を提示し、変更後の所属とする所属単位の指定を求める
A -> F : 変更後の所属とする所属単位を1つ指定する
note : 1ユーザーにつき所属は1つ(備考1、ADR-0007)
F -> C : 変更の確認を要求する(ユーザー, 所属単位)

# メインフロー 6
C -> F : 変更前と変更後の所属を渡す
F -> A : 対象のユーザーの変更前と変更後の所属を提示し、変更の確認を求める

# Ex-1
break 変更のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を渡す
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。所属は変更されない
end

# メインフロー 7〜8
A -> F : 変更ボタンを押す(所属の変更を指示する)
F -> C : 所属の変更を要求する(ユーザー, 所属単位)
C -> DM : 対象のユーザーの所属を指定された所属単位に更新する
DM -> U : 対象のユーザーの所属を指定された所属単位に更新する
note : 既存のシフト・申請・勤怠記録は変更しない(事後条件、備考2)。所属を変えた後の既存のシフトと「未処理」の申請の扱いは TBD(備考5)

# Ex-2 とメインフロー 9
alt 保存に失敗した
C -> F : 保存に失敗したことを渡す
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー6に戻る
else 保存に成功した
C -> S : 所属の変更の完了を渡す
note : 所属変更画面の変更ボタンからユーザ所属設定画面に戻る(画面遷移図)
S -> A : 所属の変更が完了したことを提示する
end
