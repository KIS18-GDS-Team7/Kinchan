title UC-107 ユーザー一覧を表示する
scope メインフロー、Alt-1〜4

actor A マスタ管理者
boundary F ユーザ情報編集画面
control C ユーザー管理制御
entity U 従業員
entity OU 所属単位

# メインフロー 1〜2
A -> F : ユーザーの一覧表示を要求する
note : ユーザーの一覧を提示する画面は画面遷移図にない。ユーザ情報編集画面を流用する(暫定)
F -> C : ユーザーの一覧を要求する
C -> U : 削除済みでないユーザーを取得する
U --> C : ユーザーの一覧(氏名, ユーザーID, 権限のリスト, 所属)
note : 削除済みユーザーは通常は除く(備考2、ADR-0013)。権限は従業員が持つ権限のリスト(マスタ管理者権限・勤怠管理者権限)。概念クラス図では権限は別のクラス(暫定)
C -> OU : 各ユーザーの管理先を取得する
OU --> C : 管理先の一覧
note : 管理先は勤怠管理者権限を持つユーザーにだけある(備考1)

# Alt-1
alt 該当するユーザーが存在しない
C -> F : 該当するユーザーが存在しないことを渡す
F -> A : 該当するユーザーが存在しないことを提示する
note : Alt-1。Alt-2 の1に進む(下の opt)
else 該当するユーザーが存在する
C -> F : ユーザーの一覧を渡す(氏名, ユーザーID, 権限, 所属, 管理先)
F -> A : 削除済みでないユーザーの一覧(氏名, ユーザーID, 権限, 所属, 管理先)を提示する
end

# Alt-2・Alt-3・Alt-4
opt 条件を指定した、または該当するユーザーが存在しなかった
loop 条件に合うユーザーが存在するまで繰り返す
A -> F : 条件(氏名, ユーザーID, 権限, 所属)を指定する
note : Alt-2 の1。Alt-1 からはここに進む。氏名・ユーザーIDで探し、権限・所属で絞る(備考3、A-31)。削除済みユーザーを含めることも指定できる(Alt-3)
F -> C : 条件に合うユーザーの一覧を要求する(氏名, ユーザーID, 権限, 所属, 削除済みユーザーを含めるか)
C -> U : 条件に合うユーザーを取得する
U --> C : ユーザーの一覧(氏名, ユーザーID, 権限のリスト, 所属)
C -> OU : 各ユーザーの管理先を取得する
OU --> C : 管理先の一覧
opt 条件に合うユーザーが存在しない
C -> F : 条件に合うユーザーが存在しないことを渡す
F -> A : 条件に合うユーザーが存在しないことを提示する
note : Alt-4。Alt-2 の1に戻る
end
end
C -> F : 条件に合うユーザーの一覧を渡す(氏名, ユーザーID, 権限, 所属, 管理先)
F -> A : 条件に合うユーザーの一覧を提示する
note : Alt-2・Alt-3。削除済みユーザーを含めると指定した場合は、削除済みユーザーを含めた一覧を提示する。メインフロー3に戻る
end

# メインフロー 3〜4
A -> F : 一覧からユーザーを1人指定する
F -> C : ユーザーの詳細を要求する(ユーザー)
C -> U : 指定されたユーザーを取得する
U --> C : 氏名, ユーザーID, 権限のリスト, 所属, 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
C -> OU : 指定されたユーザーの管理先を取得する
OU --> C : 管理先の一覧
C -> F : ユーザーの詳細を渡す(氏名, ユーザーID, 権限, 所属, 管理先, 削除済みかどうか)
F -> A : 指定されたユーザーの詳細(氏名, ユーザーID, 権限, 所属, 管理先, 削除済みかどうか)を提示する
note : 登録・変更・削除・権限・所属・管理先の操作は各 UC で行う(備考5)
