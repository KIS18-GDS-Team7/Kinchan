title UC-201 シフトを登録する
scope メインフロー、Alt-1〜4、Ex-1、Ex-2

actor A 勤怠管理者
boundary H 勤怠管理者ホーム画面
boundary S シフト作成画面
control C シフト制御
entity OU 所属単位
entity TP シフト対象受付期間
entity SF シフト

# メインフロー 1〜3
A -> H : シフト制作ボタンを押す(シフトの登録を要求する)
note : 勤怠管理者ホーム画面のシフト制作ボタンからシフト作成画面に移る(画面遷移図)
H -> C : シフトの登録を要求する
C -> OU : アクターの管理先の従業員を取得する
OU --> C : 従業員の一覧
C -> S : 管理先の従業員の一覧を表示する
S -> A : 管理先の従業員の一覧を提示し、対象の従業員の指定を求める
A -> S : 対象の従業員を指定する
note : 削除済みユーザーを指定できるかは TBD(備考8)

# メインフロー 4〜7 と Alt-1〜4
loop 誤りが無く、重複が無くなるまで繰り返す
S -> A : シフトの内容(勤務日, 開始時刻, 終了時刻)の入力を求める
A -> S : シフトの内容を入力する
A -> S : 確認ボタンを押す
S -> C : 入力内容の検証を要求する(従業員, 勤務日, 開始時刻, 終了時刻)
C -> C : 入力されたシフトの内容と、勤務日が当日以降であることを検証する
note : 誤りは未入力と、終了時刻が開始時刻と同じ入力(Alt-1、備考5)。当日より前は不可(Alt-2、備考2)
C -> TP : 対象の従業員の所属に登録された対象期間を取得する
TP --> C : 対象期間の一覧
C -> C : 勤務日が対象期間に含まれることを検証する
note : 対象期間は UC-215 で登録したもの(備考3)
alt 誤りがある、勤務日が過去日、または対象期間に含まれない
C -> S : 誤りの内容、または登録できない理由を表示する
S -> A : 誤りの内容、または登録できない理由を提示する
note : Alt-1・Alt-2・Alt-4。メインフロー4に戻る
else 誤りが無く、勤務日が当日以降で対象期間に含まれる
C -> SF : 同じ従業員の、時刻が重なる他のシフトを探す
SF --> C : 重複するシフト
note : 1日に同じ従業員のシフトを複数登録できる。重複は時刻の重なりで判定する(備考4、A-33)。終了時刻が開始時刻より前なら翌日の時刻として扱う(備考5)
opt 同じ従業員の他のシフトと重複している
C -> S : 重複しているシフトを表示する
S -> A : 重複しているシフトを提示する
note : Alt-3。メインフロー4に戻る
end
end
end

# メインフロー 8
C -> S : 入力されたシフトの内容を表示する(従業員, 勤務日, 開始時刻, 終了時刻)
S -> A : 入力されたシフトの内容を提示し、登録の確認を求める

# Ex-1
break 登録のキャンセルを要求した
A -> S : キャンセルボタンを押す
S -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> S : キャンセルの完了を表示する
S -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフトは登録されない
end

# メインフロー 9〜10
A -> S : シフトの登録を指示する
S -> C : シフトの登録を要求する(従業員, 勤務日, 開始時刻, 終了時刻)
C -> SF : シフトを登録する(従業員, 勤務日, 開始時刻, 終了時刻, 状態=下書き)
note : 下書きは UC-216 で公開するまで従業員に提示されない。このユースケースでは通知しない(備考1)

# Ex-2 とメインフロー 11
alt 保存に失敗した
C -> S : 保存に失敗したことを表示する
S -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー8に戻る
else 保存に成功した
C -> S : 登録の完了を表示する
S -> A : 登録が完了したことを提示する
end
