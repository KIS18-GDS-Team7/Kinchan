title UC-202 シフトを変更する
scope メインフロー、Alt-1〜7、Ex-1、Ex-2

actor A 勤怠管理者
boundary S シフト作成画面
control C シフト制御
entity SF シフト
entity TP シフト対象受付期間
entity SH シフト変更履歴
entity U 従業員
entity N 通知

# メインフロー 1〜3、メインフロー4の判定と Alt-1
A -> S : シフトの変更を要求する
note : シフトの変更をシフト作成画面で行うことは画面遷移図にない(暫定)
S -> C : 管理先の従業員のシフトを要求する
loop 勤務済みでないシフトが指定されるまで繰り返す
C -> SF : 管理先の従業員のシフトを取得する
SF --> C : シフトの一覧(下書きを含む)
C -> S : シフトの一覧を表示する
S -> A : シフトの一覧を提示し、変更するシフトの指定を求める
A -> S : 変更するシフトを指定する
S -> C : シフトの変更の入力を要求する(シフト)
C -> SF : シフトを取得する
SF --> C : 従業員, 勤務日, 開始時刻, 終了時刻, 状態
C -> C : シフトが勤務済みかを判定する
note : 勤務済みとは、シフトの終了日時を現在時刻が過ぎていること。打刻は見ない。勤務中のシフトは変更できる(備考2、A-35)
opt 勤務済みのシフト
C -> S : 変更できないことを表示する
S -> A : 勤務済みのシフトは変更できないことを提示する
note : Alt-1。メインフロー2に戻る
end
end

# メインフロー 4〜7 と Alt-2〜6
loop 誤りが無く、重複が無くなるまで繰り返す
C -> S : 現在の内容を表示する(従業員, 勤務日, 開始時刻, 終了時刻, 状態)
S -> A : 指定されたシフトの現在の内容を提示し、変更後の内容(勤務日, 開始時刻, 終了時刻)の入力を求める
A -> S : 変更後の内容を入力する
A -> S : 確認ボタンを押す
S -> C : 入力内容の検証を要求する(変更後の勤務日, 開始時刻, 終了時刻)
C -> C : 変更後の内容と、勤務日が当日以降であること、変更前と異なることを検証する
note : 誤りの内容は UC-201 と同じ(備考11)。当日より前は不可(Alt-3、備考3)。変更前と同じ内容は受け付けない(Alt-5、備考5、A-83)
C -> TP : 対象の従業員の所属に登録された対象期間を取得する
TP --> C : 対象期間の一覧
C -> C : 変更後の勤務日が対象期間に含まれることを検証する
note : 対象期間は UC-215 で登録したもの(備考4)
alt 誤りがある、過去日、対象期間に含まれない、または変更前と同じ
C -> S : 誤りの内容、または変更できない理由を表示する
S -> A : 誤りの内容、または変更できない理由を提示する
note : Alt-2〜5。メインフロー4に戻る
else 誤りが無く、変更前と異なる
C -> SF : 同じ従業員の、時刻が重なる他のシフトを探す
SF --> C : 重複するシフト
note : 重複は時刻の重なりで判定する。日をまたぐシフトの表し方は UC-201 と同じ(備考11)
opt 同じ従業員の他のシフトと重複している
C -> S : 重複しているシフトを表示する
S -> A : 重複しているシフトを提示する
note : Alt-6。メインフロー4に戻る
end
end
end

# メインフロー 8
C -> S : 変更前と変更後の内容を表示する
S -> A : 変更前と変更後の内容を提示し、変更の確認を求める

# Ex-1
break 変更のキャンセルを要求した
A -> S : キャンセルボタンを押す
S -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> S : キャンセルの完了を表示する
S -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフトは変更されない
end

# メインフロー 9〜11
A -> S : シフトの変更を指示する
S -> C : シフトの変更を要求する(シフト, 変更後の勤務日, 開始時刻, 終了時刻)
C -> SH : 変更前の内容を変更履歴として記録する(変更前内容, 操作者, 操作日時)
note : 変更履歴は削除できない(備考6)。操作者は概念クラス図にない(備考6、暫定)
C -> SF : シフトを変更後の内容に更新する(勤務日, 開始時刻, 終了時刻)
note : 状態は変えない(備考1)。まとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 12〜13
alt 保存に失敗した
C -> S : 保存に失敗したことを表示する
S -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー8に戻る
else 保存に成功した
C -> U : 対象の従業員が削除済みかを取得する
U --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt シフトの状態が「公開」で、対象の従業員が削除済みユーザーでない
C -> N : 通知を登録する(対象の従業員, シフトが変更された)
note : 下書きのシフトの変更と、削除済みユーザーには通知しない(Alt-7、備考1)
end
C -> S : 変更の完了を表示する
S -> A : 変更が完了したことを提示する
end
