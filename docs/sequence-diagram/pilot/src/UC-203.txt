title UC-203 シフトを削除する
scope メインフロー、Alt-1、Alt-2、Ex-1、Ex-2

actor A 勤怠管理者
boundary S シフト作成画面
control C シフト制御
entity SF シフト
entity SD シフト削除履歴
entity U 従業員
entity N 通知

# メインフロー 1〜3、メインフロー4の判定と Alt-1
A -> S : シフトの削除を要求する
note : シフトの削除をシフト作成画面で行うことは画面遷移図にない(暫定)
S -> C : 管理先の従業員のシフトを要求する
loop 勤務済み・勤務中でないシフトが指定されるまで繰り返す
C -> SF : 管理先の従業員のシフトを取得する
SF --> C : シフトの一覧(下書きを含む)
C -> S : シフトの一覧を渡す
S -> A : シフトの一覧を提示し、削除するシフトの指定を求める
A -> S : 削除するシフトを指定する
S -> C : シフトの削除の確認を要求する(シフト)
C -> SF : シフトを取得する
SF --> C : 従業員, 勤務日, 開始時刻, 終了時刻, 状態
C -> C : シフトが勤務済み、または勤務中かを判定する
note : 判定は UC-202 と同じ(備考2、A-35)
opt 勤務済み、または勤務中のシフト
C -> S : 削除できないことを渡す
S -> A : 勤務済み・勤務中のシフトは削除できないことを提示する
note : Alt-1。メインフロー2に戻る
end
end

# メインフロー 4
C -> S : シフトの内容を渡す(従業員, 勤務日, 開始時刻, 終了時刻, 状態)
S -> A : 指定されたシフトの内容(従業員, 勤務日, 開始時刻, 終了時刻, 状態)を提示し、削除の確認を求める

# Ex-1
break 削除のキャンセルを要求した
A -> S : キャンセルボタンを押す
S -> C : キャンセルを要求する
C -> S : キャンセルの完了を渡す
S -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフトは削除されない
end

# メインフロー 5〜7
A -> S : シフトの削除を指示する
S -> C : シフトの削除を要求する(シフト)
C -> SD : 削除するシフトの内容を削除履歴として記録する(削除した内容, 操作者, 操作日時)
note : 削除履歴は削除できない(備考4)。元に戻す操作は無い(備考3、A-37)。操作者は概念クラス図になく、概念クラス図の削除理由は UC にない(暫定)
C -> SF : シフトを削除する
note : 物理削除か、削除済みの印を付けて残すかは未定(ADR-0013、#100 の[12])。まとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 8〜9
alt 保存に失敗した
C -> S : 保存に失敗したことを渡す
S -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー4に戻る
else 保存に成功した
C -> U : 対象の従業員が削除済みかを取得する
U --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt シフトの状態が「公開」で、対象の従業員が削除済みユーザーでない
C -> N : 通知を登録する(対象の従業員, シフトが削除された)
note : 下書きのシフトの削除と、削除済みユーザーには通知しない(Alt-2、備考1)
end
C -> S : 削除の完了を渡す
S -> A : 削除が完了したことを提示する
end
