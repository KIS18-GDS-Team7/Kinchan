title UC-205 シフト希望を承認する
scope メインフロー、Alt-1〜6、Ex-1、Ex-2

actor A 勤怠管理者
boundary L 従業員シフト希望一覧表示画面
boundary V シフト希望承認確認画面
control C シフト希望承認制御
entity SH シフト希望
entity U 従業員
entity TP シフト対象受付期間
entity SF シフト
entity N 通知

# メインフロー 1〜2
A -> L : 「未処理」のシフト希望を指定して承認を要求する(UC-204 から)
note : 一覧の内容確認ボタンからシフト希望承認確認画面に移る(画面遷移図)
L -> C : 承認するシフト希望の内容を要求する(シフト希望)
C -> SH : シフト希望を取得する
SH --> C : 従業員, 希望日, 希望開始時刻, 希望終了時刻, 処理状態
C -> V : 承認するシフト希望の内容を表示する
V -> A : 承認するシフト希望の内容を提示し、承認の確認を求める

# Alt-3
opt 対象がアクター自身のシフト希望
C -> V : アクター自身のシフト希望であることを表示する
V -> A : 対象がアクター自身のシフト希望であることを提示する
note : Alt-3。メインフロー3に進む。自身のシフト希望も承認できる(備考8、A-55)
end

# Ex-1
break 承認のキャンセルを要求した
A -> V : キャンセルボタンを押す
V -> C : キャンセルを要求する
C -> V : キャンセルの完了を表示する
V -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらず、シフトは登録されない
end

# メインフロー 3〜4
A -> V : 承認ボタンを押す
V -> C : 承認を要求する(シフト希望)
C -> SH : シフト希望を取得する
SH --> C : 従業員, 希望日, 希望開始時刻, 希望終了時刻, 処理状態
note : 承認を指示した時点の内容で判定する(備考4)
C -> U : 対象の従業員が削除済みかを取得する
U --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
C -> TP : 対象の従業員の所属に登録された対象期間を取得する
TP --> C : 対象期間の一覧
C -> C : 処理状態が「未処理」、削除済みでない、希望日が当日以降、対象期間に含まれることを検証する
note : 当日より前は不可(備考5)。対象期間は UC-215 で登録したもの(備考6)

# Alt-2・Alt-4・Alt-5・Alt-6
break 「未処理」でない、削除済みユーザー、希望日が当日より前、または対象期間に含まれない
C -> V : 承認できない理由を表示する
V -> A : 承認できないことと、その理由を提示する
note : Alt-2・Alt-4・Alt-5・Alt-6。UC-204 に戻る。処理状態は「未処理」のまま(備考3)
end

# メインフロー 5
C -> SF : 同じ従業員の、希望日時と重複するシフトを探す
SF --> C : 重複するシフト
note : 時刻の重なりで判定する。日をまたぐ希望は希望日の翌日の時刻として扱う(備考9)

# Alt-1
break 登録済みのシフトと重複している
C -> V : 重複しているシフトと、承認できないことを表示する
V -> A : 重複しているシフトと、承認できないことを提示する
note : Alt-1。UC-204 に戻る
end

# メインフロー 6〜7
C -> SH : 処理状態を「承認済」に更新する
C -> SF : シフトを登録する(従業員, 勤務日=希望日, 開始時刻=希望開始時刻, 終了時刻=希望終了時刻, 状態=公開)
note : 更新と登録はまとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 8〜9
alt 保存に失敗した
C -> V : 保存に失敗したことを表示する
V -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー2に戻る
else 保存に成功した
C -> N : 通知を登録する(従業員, 承認結果)
note : 承認結果の通知が公開の通知を兼ねる(備考1)
C -> L : 承認の完了を表示する
note : 承認ボタンから従業員シフト希望一覧表示画面に戻る(画面遷移図)
L -> A : 承認が完了したことを提示する
end
