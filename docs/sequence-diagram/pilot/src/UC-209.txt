title UC-209 勤怠修正申請を却下する
scope メインフロー、Alt-1〜3、Ex-1、Ex-2

actor A 勤怠管理者
boundary L 勤怠修正申請一覧表示画面
control C 勤怠修正承認制御
entity AR 勤怠修正申請
entity U 従業員
entity N 通知

# メインフロー 1
A -> L : 「未処理」の勤怠修正申請を指定して却下を要求する(UC-207 から)
note : 却下理由の入力と却下の確認を求める画面は画面遷移図にない(暫定)
L -> C : 却下する勤怠修正申請の内容を要求する(勤怠修正申請)
C -> AR : 勤怠修正申請を取得する
AR --> C : 従業員, 対象日, 修正後の打刻の一覧, 申請理由, 処理状態

# メインフロー 2〜6 (却下理由の検証まで)、Alt-1、Alt-3、Ex-1 の 1
loop 却下理由が入力されるまで繰り返す(キャンセルを要求したら抜ける)
C -> L : 却下する勤怠修正申請の内容を渡す
L -> A : 却下する勤怠修正申請の内容を提示し、却下理由の入力を求める
opt 対象がアクター自身の勤怠修正申請
C -> L : アクター自身の勤怠修正申請であることを渡す
L -> A : 対象がアクター自身の勤怠修正申請であることを提示する
note : Alt-3。メインフロー3に進む。自身の勤怠修正申請も却下できる(備考5、A-55)
end
A -> L : 却下理由を入力する
note : 必須の自由記述。定型文から選んで挿入できる(備考1、A-46)
L -> A : 却下の確認を求める
alt 却下のキャンセルを要求した
A -> L : キャンセルボタンを押す
L -> C : キャンセルを要求する
note : Ex-1。繰り返しを抜けて、下の break に進む
else 却下を指示した
A -> L : 勤怠修正申請の却下を指示する
L -> C : 却下を要求する(勤怠修正申請, 却下理由)
C -> C : 却下理由が入力されていることを検証する
opt 却下理由が入力されていない
C -> L : 却下理由が必要であることを渡す
L -> A : 却下理由の入力が必要であることを提示する
note : Alt-1。メインフロー2に戻る
end
end
end

# Ex-1 の 2〜4
break 却下のキャンセルを要求した
C -> C : 入力された内容を破棄する
C -> L : キャンセルの完了を渡す
L -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらない
end

# メインフロー 6 (処理状態の検証) と Alt-2
C -> AR : 勤怠修正申請を取得する
AR --> C : 従業員, 処理状態
note : 却下を指示した時点の内容で判定する(備考7)
C -> C : 処理状態が「未処理」であることを検証する
break 処理状態が「未処理」でなくなっている
C -> L : 却下できない状態であることを渡す
L -> A : 対象の勤怠修正申請が却下できない状態であることを提示する
note : Alt-2。UC-207 に戻る。他の勤怠管理者が処理した、または従業員が取り下げた場合(備考7)
end

# メインフロー 7〜8
C -> AR : 処理状態を「却下」に更新し、却下理由を記録する
note : 勤怠記録は修正しない。まとめて保存する(Ex-2 の事後条件)

# Ex-2 とメインフロー 9〜10
alt 保存に失敗した
C -> L : 保存に失敗したことを渡す
L -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー4に戻る
else 保存に成功した
C -> U : 申請した従業員が削除済みかを取得する
U --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt 申請した従業員が削除済みユーザーでない
C -> N : 通知を登録する(申請した従業員, 却下結果, 却下理由)
note : 削除済みユーザーには通知しない(備考4)
end
C -> L : 却下の完了を渡す
L -> A : 却下が完了したことを提示する
end
