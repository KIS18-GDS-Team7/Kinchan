title UC-211 勤務実態を一覧表示する
scope メインフロー、Alt-1〜4

actor A 勤怠管理者
boundary HM 勤怠管理者ホーム画面
boundary RL 勤怠実態一覧表示画面
control C 勤務実態制御
participant DM DataManager
entity OU 所属単位
entity U 従業員
entity R 勤怠記録
entity SF シフト

# メインフロー 1〜2
A -> HM : 勤怠実態ボタンを押す(勤務実態の一覧表示を要求する)
note : 勤怠管理者ホーム画面の勤怠実態ボタンから勤怠実態一覧表示画面に移る(画面遷移図)
HM -> C : 管理先の従業員を要求する
C -> DM : アクターの管理先と、その従業員を取得する
DM -> OU : アクターの管理先と、その従業員を取得する
OU --> DM : 管理先と従業員の一覧
DM --> C : 管理先と従業員の一覧

# メインフロー 2〜4、Alt-2、Alt-3
loop 期間の指定に誤りが無くなるまで繰り返す
C -> RL : 管理先と従業員を渡す
RL -> A : 管理先と従業員の一覧を提示し、対象の従業員と期間の指定を求める
A -> RL : 対象の従業員と期間を指定する
note : 管理先の従業員から1人、または1つ以上の管理先の全従業員(備考10)
alt 削除済みユーザーを含めることを指定した
A -> RL : 削除済みユーザーを含めることを指定する
RL -> C : 勤務実態を要求する(従業員, 期間, 削除済みユーザーを含める)
C -> C : 削除済みユーザーを対象の従業員に含める
note : Alt-3。メインフロー4に進む
else 指定しない
RL -> C : 勤務実態を要求する(従業員, 期間)
note : 通常は削除済みユーザーを含めない(備考9)
end
C -> C : 指定された期間を検証する
opt 期間の開始日が終了日より後
C -> RL : 期間の指定の誤りを渡す
RL -> A : 期間の指定に誤りがあることを提示する
note : Alt-2。メインフロー2に戻る
end
end

# メインフロー 5 で判定に使う記録の取得
C -> DM : 対象の従業員の、期間と当月の勤怠記録を取得する
DM -> R : 対象の従業員の、期間と当月の勤怠記録を取得する
R --> DM : 日ごとの打刻の一覧(種類, 打刻日時)
DM --> C : 日ごとの打刻の一覧(種類, 打刻日時)
note : 勤怠記録は出勤打刻を行った日に属する(備考4、#82)
C -> DM : 対象の従業員の、期間の公開済みのシフトを取得する
DM -> SF : 対象の従業員の、期間の公開済みのシフトを取得する
SF --> DM : シフトの一覧
DM --> C : シフトの一覧

# Alt-1
break 勤怠記録も公開済みのシフトも存在しない
C -> RL : 存在しないことを渡す
RL -> A : 該当する勤怠記録も公開済みのシフトも存在しないことを提示する
note : Alt-1。このユースケースを終了する
end

# メインフロー 5〜6
loop 対象の従業員ごと
C -> C : 日ごとの休憩時間・勤務時間と、期間の合計勤務時間・残業時間を計算する
note : 秒を切り捨てて分単位で計算する(備考3)。残業時間は1日8時間を超えた勤務時間の合計(備考5)
C -> C : 遅刻・早退・欠勤・打刻漏れを判定する
note : 判定の対象は公開済みのシフトだけ(備考7)。打刻漏れを判定する時点は TBD(備考11)
C -> C : 当月の残業時間が36協定の警告に当たるかを判定する
note : 36時間以上で「注意」、45時間以上で「超過」(備考6、A-57)
end

# Alt-4
opt 36協定の警告に当たる従業員がいる
C -> RL : 該当する従業員と当月の残業時間、「注意」または「超過」を渡す
RL -> A : 該当する従業員と当月の残業時間、「注意」または「超過」を提示する
note : Alt-4。メインフロー7に進む
end

# メインフロー 7〜10
C -> DM : 各従業員の現在の勤務ステータスを取得する
DM -> U : 各従業員の現在の勤務ステータスを取得する
U --> DM : 勤務ステータス
DM --> C : 勤務ステータス
note : 勤務ステータスは概念クラス図にない(備考1、暫定)
C -> RL : 各従業員の現在の勤務ステータスを渡す
RL -> A : 各従業員の現在の勤務ステータス(「出勤中」「退勤中」「休憩中」)を提示する
C -> RL : 各従業員の日ごとの勤務を渡す
RL -> A : 各従業員の日ごとの勤務(各打刻、休憩時間、勤務時間)を提示する
note : 打刻日時は秒まで提示する(備考2)
C -> RL : 各従業員の期間の合計を渡す
RL -> A : 各従業員の期間の合計勤務時間、残業時間、遅刻・早退・欠勤の回数を提示する
C -> RL : 各従業員の遅刻・早退・打刻漏れがある日を渡す
RL -> A : 各従業員の遅刻、早退、打刻漏れがある日を提示する
note : 集計結果は CSV ファイルとして出力できる(備考8、暫定)
