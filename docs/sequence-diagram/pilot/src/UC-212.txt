title UC-212 シフト日時変更申請を一覧表示する
scope メインフロー、Alt-1〜6

actor A 勤怠管理者
boundary HM 勤怠管理者ホーム画面
boundary L シフト日時変更申請一覧表示画面
boundary V シフト変更承認確認画面
control C シフト日時変更承認制御
entity OU 所属単位
entity AR シフト日時変更申請
entity SF シフト

# メインフロー 1〜2
A -> HM : シフト変更申請確認ボタンを押す(シフト日時変更申請の一覧表示を要求する)
note : 勤怠管理者ホーム画面のシフト変更申請確認ボタンからシフト日時変更申請一覧表示画面に移る(画面遷移図)
HM -> C : シフト日時変更申請の一覧を要求する
C -> OU : アクターの管理先の従業員を取得する
OU --> C : 従業員の一覧
note : 管理先が複数ならすべての管理先の分(備考3)。削除済みユーザーは通常含めない(備考2)
C -> AR : 管理先の従業員の「未処理」のシフト日時変更申請を取得する
AR --> C : 一覧(従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 送信日時)
C -> SF : 各申請の変更前のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻

# メインフロー 2 と Alt-1
alt 該当するシフト日時変更申請が存在しない
C -> L : 存在しないことを表示する
L -> A : 該当するシフト日時変更申請が存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 該当するシフト日時変更申請が存在する
C -> L : シフト日時変更申請の一覧を表示する
L -> A : 「未処理」のシフト日時変更申請の一覧(従業員名、変更前のシフト、変更後の勤務日・開始時刻・終了時刻、申請理由、送信日時)を提示する
end

# Alt-2〜4、Alt-6
opt 該当するシフト日時変更申請が存在しなかった、またはアクターが条件を指定して探す
loop 条件に合うシフト日時変更申請が提示されるまで繰り返す
A -> L : 条件(期間, 従業員, 処理状態, 管理先)を指定する
note : 削除済みユーザーを含めることも指定できる(Alt-4)
L -> C : 条件に合う一覧を要求する(期間, 従業員, 処理状態, 管理先, 削除済みユーザーを含めるか)
C -> C : 指定された条件を検証する
alt 期間の開始日が終了日より後
C -> L : 期間の指定の誤りを表示する
L -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 誤りが無い
C -> AR : 条件に合うシフト日時変更申請を取得する
AR --> C : 一覧
note : 期間は変更前のシフトの勤務日で絞る(備考4)
opt 条件に合うシフト日時変更申請が存在しない
C -> L : 存在しないことを表示する
L -> A : 条件に合うシフト日時変更申請が存在しないことを提示する
note : Alt-6。Alt-2の1に戻る
end
end
end
alt 削除済みユーザーを含めることを指定した
C -> L : 削除済みユーザーの分を含めた一覧を表示する
L -> A : 削除済みユーザーのシフト日時変更申請を含めた一覧を提示する
note : Alt-4。メインフロー3に戻る(備考2、#86)
else 指定しない
C -> L : 条件に合う一覧を表示する
L -> A : 条件に合うシフト日時変更申請の一覧を提示する
note : Alt-2の3。メインフロー3に戻る
end
end

# メインフロー 3〜4
A -> L : 詳細を提示するシフト日時変更申請を指定して内容確認ボタンを押す
note : 内容確認ボタンからシフト変更承認確認画面に移る(画面遷移図)
L -> C : 詳細を要求する(シフト日時変更申請)
C -> AR : シフト日時変更申請を取得する
AR --> C : 従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態, 却下理由
C -> SF : 変更前のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻
C -> V : シフト日時変更申請の詳細を表示する
V -> A : 変更前のシフトの勤務日・開始時刻・終了時刻、変更後の勤務日・開始時刻・終了時刻、申請理由、処理状態、却下理由(「却下」のとき)を提示する

# メインフロー 5 と Alt-5
C -> SF : 同じ従業員の、変更後の日時と重なる他のシフトを探す
SF --> C : 重複するシフト
note : 重複は時刻の重なりで判定する(備考1、A-33)
opt 変更後の日時が登録済みのシフトと重複している
C -> V : 重複しているシフトを表示する
V -> A : 重複しているシフトを提示する
note : Alt-5。メインフロー6に進む
end

# メインフロー 6
C -> V : 重複の判定の結果を表示する
V -> A : 重複の判定の結果を提示する
note : 重複の有無によらず承認・却下に進める(備考1)。拡張点:「未処理」なら承認 → UC-213、却下 → UC-214
