title UC-214 シフト日時変更申請を却下する
scope メインフロー、Alt-1〜3、Ex-1、Ex-2

actor A 勤怠管理者
boundary L シフト日時変更申請一覧表示画面
boundary V シフト変更承認確認画面
control C シフト日時変更承認制御
participant DM DataManager
entity AR シフト日時変更申請
entity U 従業員
entity N 通知

# メインフロー 1〜2
A -> L : 「未処理」のシフト日時変更申請を指定して却下を要求する(UC-212 から)
note : 一覧の内容確認ボタンからシフト変更承認確認画面に移る(画面遷移図)
L -> C : 却下するシフト日時変更申請の内容を要求する(シフト日時変更申請)
C -> DM : シフト日時変更申請を取得する
DM -> AR : シフト日時変更申請を取得する
AR --> DM : 従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態
DM --> C : 従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態
C -> V : 却下するシフト日時変更申請の内容を渡す
V -> A : 却下するシフト日時変更申請の内容を提示し、却下理由の入力を求める

# Alt-3
opt 対象がアクター自身のシフト日時変更申請
C -> V : アクター自身のシフト日時変更申請であることを渡す
V -> A : 対象がアクター自身のシフト日時変更申請であることを提示する
note : Alt-3。メインフロー3に進む。自身の申請も却下できる(備考3、A-55)
end

# メインフロー 3〜4
A -> V : 却下理由を入力する
note : 必須の自由記述。定型文から選んで挿入できる(備考1、A-46)
V -> A : 却下の確認を求める

# Ex-1
break 却下のキャンセルを要求した
A -> V : キャンセルボタンを押す
V -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> V : キャンセルの完了を渡す
V -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらない
end

# メインフロー 5〜6
A -> V : 却下を指示する
note : 却下を指示するボタンは画面遷移図にない(暫定)
V -> C : 却下を要求する(シフト日時変更申請, 却下理由)
C -> DM : 処理状態を取得する
DM -> AR : 処理状態を取得する
AR --> DM : 処理状態
DM --> C : 処理状態
C -> C : 却下理由が入力されていること、処理状態が「未処理」であることを検証する

# Alt-2
break 処理状態が「未処理」でなくなっている
C -> V : 却下できないことを渡す
V -> A : 対象のシフト日時変更申請が却下できない状態であることを提示する
note : Alt-2。UC-212 に戻る。他の勤怠管理者が処理した、または従業員が取り下げた場合(備考6)
end

# Alt-1 とメインフロー 7〜10、Ex-2
alt 却下理由が入力されていない
C -> V : 却下理由が必要であることを渡す
V -> A : 却下理由の入力が必要であることを提示する
note : Alt-1。メインフロー2に戻る
else 却下理由が入力されている
C -> DM : 処理状態を「却下」に更新し、却下理由を記録する
DM -> AR : 処理状態を「却下」に更新し、却下理由を記録する
note : シフトは変更しない。まとめて保存する(事後条件)
alt 保存に失敗した
C -> V : 保存に失敗したことを渡す
V -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー4に戻る
else 保存に成功した
C -> DM : 申請した従業員が削除済みかを取得する
DM -> U : 申請した従業員が削除済みかを取得する
U --> DM : 削除済みかどうか
DM --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt 申請した従業員が削除済みユーザーでない
C -> DM : 通知を登録する(申請した従業員, 却下結果, 却下理由)
DM -> N : 通知を登録する(申請した従業員, 却下結果, 却下理由)
note : 削除済みユーザーには通知しない(備考2)
end
C -> L : 却下の完了を渡す
note : 却下後に移る画面は画面遷移図にない(暫定。承認ボタンと同じくシフト日時変更申請一覧表示画面とした)
L -> A : 却下が完了したことを提示する
end
end
