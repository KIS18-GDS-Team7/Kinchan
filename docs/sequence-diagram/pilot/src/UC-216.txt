title UC-216 シフトを公開する
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A 勤怠管理者
boundary S シフト作成画面
control C シフト制御
entity OU 所属単位
entity TP シフト対象受付期間
entity SF シフト
entity U 従業員
entity N 通知

# メインフロー 1〜3
A -> S : シフトの公開を要求する
note : 公開を要求するボタンは画面遷移図にない(暫定)
S -> C : 管理先と対象期間を要求する
C -> OU : アクターの管理先を取得する
OU --> C : 管理先の一覧
C -> TP : 管理先に登録された対象期間を取得する
TP --> C : 対象期間の一覧
note : 対象期間は UC-215 で登録したもの。公開の単位とするのは暫定(備考4)
C -> S : 管理先と対象期間を渡す
S -> A : 管理先と対象期間の一覧を提示し、管理先と対象期間の指定を求める
A -> S : 管理先と対象期間を指定する
S -> C : 公開するシフトを要求する(管理先, 対象期間)

# メインフロー 4 の取得
C -> SF : 管理先の従業員の、対象期間に勤務日がある下書きのシフトを取得する
SF --> C : 一覧(従業員名, 勤務日, 開始時刻, 終了時刻)
note : 公開するのは UC-201 で登録した下書きだけ。公開済みは変えない(備考2)

# Alt-1
break 対象期間に勤務日がある下書きのシフトが存在しない
C -> S : 公開するシフトが存在しないことを渡す
S -> A : 公開するシフトが存在しないことを提示する
note : Alt-1。このユースケースを終了する
end

# メインフロー 4
C -> S : 下書きのシフトの一覧を渡す
S -> A : 下書きのシフトの一覧(従業員名、勤務日、開始時刻、終了時刻)を提示し、公開の確認を求める

# Ex-1
break 公開のキャンセルを要求した
A -> S : キャンセルボタンを押す
S -> C : キャンセルを要求する
C -> S : キャンセルの完了を渡す
S -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフトの状態は変わらない
end

# メインフロー 5〜6
A -> S : 公開を指示する
S -> C : 公開を要求する(管理先, 対象期間)
C -> SF : 提示したシフトの状態を「公開」に更新する
note : 対象期間ごとにまとめて公開する。1件ずつは公開しない(備考1)

# Ex-2 とメインフロー 7〜8
alt 保存に失敗した
C -> S : 保存に失敗したことを渡す
S -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー4に戻る。従業員には通知しない(Ex-2 の事後条件)
else 保存に成功した
loop 公開したシフトがある従業員ごと
C -> U : 従業員が削除済みかを取得する
U --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt 削除済みユーザーでない
C -> N : 通知を登録する(従業員, シフトが公開された)
note : 削除済みユーザーには通知しない(備考5)
end
end
C -> S : 公開の完了を渡す
S -> A : 公開が完了したことを提示する
end
