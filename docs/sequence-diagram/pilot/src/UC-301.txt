title UC-301 ログインする
scope メインフロー、Alt-1

actor A 従業員
boundary L ログイン画面
boundary H 従業員ホーム画面
control C ログイン制御
entity U 従業員

# メインフロー 1
A -> L : ログインを要求する
note : 権限によらず同じ手順(備考1、ADR-0012)

# メインフロー 2〜5 と Alt-1
loop ユーザーIDとパスワードが一致するまで繰り返す
L -> A : ユーザーIDとパスワードの入力を求める
A -> L : ユーザーIDとパスワードを入力する
A -> L : ログインボタンを押す(ログインを指示する)
L -> C : ログインを要求する(ユーザーID, パスワード)
C -> U : ユーザーIDで従業員を探す(削除済みを除く)
U --> C : 従業員(パスワード)
note : ユーザーIDは概念クラス図にない(暫定)。削除済みを表す属性もない(ADR-0013、暫定)
C -> C : 入力されたユーザーIDとパスワードを検証する
note : 登録されていないユーザーIDと削除済みユーザーも Alt-1 と同じ扱い(備考2、#86)
opt ユーザーIDまたはパスワードが誤っている
C -> L : ログインできないことを表示する
L -> A : ログインできないことを提示する
note : Alt-1。メインフロー2に戻る。試行回数の制限は設けない(備考3、A-14)
end
end

# メインフロー 6
C -> C : アクターをログインした状態にする
C -> H : ログインの完了を表示する
note : ログイン画面のログインボタンから従業員ホーム画面に移る(画面遷移図)
H -> A : ログインが完了したことを提示する
