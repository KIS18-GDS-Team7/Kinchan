title UC-302 ログアウトする
scope メインフロー、Ex-1

actor A 従業員
boundary H 従業員ホーム画面
boundary L ログイン画面
control C ログイン制御

# メインフロー 1〜2
A -> H : ログアウトボタンを押す
H -> A : ログアウトの確認を求める
note : 確認を求める画面は画面遷移図にない(暫定)

# Ex-1
break ログアウトのキャンセルを要求した
A -> H : キャンセルボタンを押す
H -> C : キャンセルを要求する
C -> H : キャンセルの完了を渡す
H -> A : キャンセルが完了したことを提示する
note : 待機状態に戻る(Ex-1 の 3)。ログインしたままである(Ex-1 の事後条件)
end

# メインフロー 3〜5
A -> H : ログアウトを指示する
H -> C : ログアウトを要求する
C -> C : アクターをログアウトした状態にする
C -> L : ログアウトの完了を渡す
note : 従業員ホーム画面のログアウトボタンからログイン画面に移る(画面遷移図)
L -> A : ログアウトが完了したことを提示する
