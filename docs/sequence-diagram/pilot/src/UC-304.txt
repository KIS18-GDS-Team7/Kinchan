title UC-304 出退勤を打刻する
scope メインフロー、Alt-1、Alt-2、Ex-1

actor A 従業員
boundary H 従業員ホーム画面
control C 打刻制御
entity U 従業員
entity SF シフト
entity R 勤怠記録
entity P 打刻

# メインフロー 1〜2
A -> H : 出勤ボタンまたは退勤ボタンを押す(打刻の種類)
H -> C : 打刻を要求する(打刻の種類)
C -> U : 勤務ステータスを取得する
U --> C : 勤務ステータス
note : 勤務ステータスは概念クラス図にない(UC-304 備考2、暫定)
C -> C : 打刻の種類と勤務ステータスの整合を判定する
note : 「出勤」は「退勤中」のとき、「退勤」は「出勤中」のときに整合する(備考5)

# Alt-1
break 整合しない
C -> H : 打刻できない理由を渡す
H -> A : 打刻できないことと、その理由を提示する
note : Alt-1。このユースケースを終了する
end

# メインフロー 3
opt 打刻の種類が「出勤」
C -> SF : 当日を勤務日とするアクターの公開済みのシフトを探す
SF --> C : シフトの有無
note : 有無だけを判定し、時刻は照合しない(備考8)
end

# Alt-2
break 打刻の種類が「出勤」で、公開済みのシフトが無い
C -> H : シフトが無いため打刻できないことを渡す
H -> A : 当日を勤務日とする公開済みのシフトが無いため打刻できないことを提示する
note : Alt-2。このユースケースを終了する。シフトが無い日も打刻できるようにする変更は #122 で提案中(未マージ)
end

# メインフロー 4〜5
C -> R : 打刻が属する勤怠記録を取得する(無ければ作成する)
R --> C : 勤怠記録
note : 勤務は出勤打刻を行った日の勤怠記録に属する(備考7)
C -> P : 打刻を記録する(種類, 打刻日時)
C -> U : 勤務ステータスを更新する(出勤中/退勤中)
note : 打刻と勤務ステータスはまとめて保存する(Ex-1 の事後条件)

# Ex-1
break 保存に失敗した
C -> H : 保存に失敗したことを渡す
H -> A : 保存に失敗したことを提示する
note : Ex-1。このユースケースを中断する
end

# メインフロー 6
C -> H : 打刻の結果を渡す(打刻の種類, 打刻日時, 更新後の勤務ステータス)
H -> A : 打刻の結果を提示する
note : 打刻日時は秒まで提示する(備考6)
