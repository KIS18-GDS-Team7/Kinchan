title UC-306 Alt-1 「未処理」の勤怠修正申請を変更する
scope Alt-1、Alt-5〜7、Ex-1、Ex-3。メインフローと Alt-2〜4、Ex-2 は別図(UC-306)

actor A 従業員
boundary AL 勤怠修正申請内容一覧表示画面
boundary F 勤怠修正申請画面
boundary D 入力確認ダイアログ
control C 勤怠修正申請制御
entity AR 勤怠修正申請
entity R 勤怠記録
entity OU 所属単位
entity N 通知

# メインフロー 1 (Alt-1 の開始) と Alt-1 の 1
A -> AL : 「未処理」の勤怠修正申請を指定して変更を要求する(UC-310 から)
note : 勤怠修正申請内容一覧表示画面の勤怠修正申請ボタンから勤怠修正申請画面に移る(画面遷移図)。変更を要求するボタンは画面遷移図にない(暫定)
AL -> C : 勤怠修正申請の変更を要求する(勤怠修正申請)
C -> AR : 対象の勤怠修正申請を取得する
AR --> C : 対象日, 修正後の打刻の一覧, 申請理由, 処理状態
C -> C : 対象日が修正申請の期限内かを判定する
note : 期限を過ぎた後は「未処理」の勤怠修正申請も変更できない(備考4、#85)。N は TBD(備考6)

# Alt-5
break 期限を過ぎている
C -> AL : 期限を過ぎているため変更できないことを渡す
AL -> A : 修正申請の期限を過ぎているため対象の勤怠修正申請を変更できないことを提示する
note : Alt-5。このユースケースを終了する
end

# Alt-1 の 2〜4 と Alt-6
C -> R : 対象日の勤怠記録の打刻の一覧を取得する
R --> C : 打刻の一覧(種類, 打刻日時)
note : 現在の打刻の一覧は対象日の勤怠記録の打刻の一覧(備考1)
loop 誤りが無くなるまで繰り返す
C -> F : 勤怠修正申請の内容を渡す(対象日, 現在の打刻の一覧, 修正後の打刻の一覧, 申請理由)
F -> A : 対象の勤怠修正申請の内容を提示し、修正後の打刻の一覧と申請理由の入力を求める
A -> F : 修正後の打刻の一覧と申請理由を入力する
A -> F : 確認ボタンを押す
F -> C : 入力内容の検証を要求する(修正後の打刻の一覧, 申請理由)
C -> C : 打刻の一覧の整合と申請理由の有無を検証する
note : 出勤、0回以上の(休憩開始, 休憩終了)、退勤の順で、打刻日時が昇順(備考2)。申請理由は変更でも必須(備考5)
opt 誤りがある
C -> F : 誤りの内容を渡す
F -> A : 誤りの内容を提示する
note : Alt-6。Alt-1の2に戻る
end
end

# Alt-1 の 5
C -> D : 申請内容を渡す(対象日, 現在の打刻の一覧, 修正後の打刻の一覧, 申請理由)
note : 勤怠修正申請画面の確認ボタンから入力確認ダイアログを開く(画面遷移図)
D -> A : 勤怠修正申請の内容を提示し、送信の確認を求める

# Ex-1
break 送信のキャンセルを要求した
A -> D : キャンセルボタンを押す
D -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> D : キャンセルの完了を渡す
D -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。勤怠修正申請は更新されない
end

# Alt-1 の 6〜7
A -> D : 送信ボタンを押す
D -> C : 送信を要求する
C -> AR : 対象の勤怠修正申請の処理状態を取得する
AR --> C : 処理状態
C -> C : 処理状態が「未処理」であることを検証する

# Alt-7
break 処理状態が「未処理」でなくなっている
C -> D : 変更できないことを渡す
D -> A : 対象の勤怠修正申請を変更できないことを提示する
note : Alt-7。このユースケースを終了する。一覧を提示した後に承認・却下・取り下げされた場合(備考10)
end

# Alt-1 の 8
C -> AR : 対象の勤怠修正申請を入力された内容に更新する(修正後の打刻の一覧, 申請理由)
note : 処理状態は「未処理」のまま。勤怠修正申請は増えない(備考10)。勤怠記録はまだ修正しない(備考11)

# Ex-3 と Alt-1 の 9〜10 (メインフロー 11)
alt 保存に失敗した
C -> D : 保存に失敗したことを渡す
D -> A : 保存に失敗したことを提示する
note : Ex-3。入力された内容を保持したまま、Alt-1の5に戻る
else 保存に成功した
C -> OU : アクターの所属を管理先に持つ勤怠管理者を取得する
OU --> C : 勤怠管理者の一覧
C -> N : 通知を登録する(勤怠管理者ごと, 勤怠修正申請が送信された)
note : 通知は UC-317 で提示される(備考7、ADR-0006)
C -> AL : 送信の完了を渡す
note : Alt-1の10。メインフロー11に進む。入力確認ダイアログの送信ボタンから勤怠修正申請内容一覧表示画面に移る(画面遷移図)
AL -> A : 送信が完了したことを提示する
end
