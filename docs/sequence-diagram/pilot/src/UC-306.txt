title UC-306 勤怠修正申請を送信する
scope メインフロー、Alt-2〜4、Ex-1、Ex-2。Alt-1(「未処理」の申請の変更)と Alt-5〜7、Ex-3 は別図(UC-306-alt1)

actor A 従業員
boundary RL 勤怠記録一覧表示画面
boundary F 勤怠修正申請画面
boundary D 入力確認ダイアログ
boundary AL 勤怠修正申請内容一覧表示画面
control C 勤怠修正申請制御
participant DM DataManager
entity AR 勤怠修正申請
entity R 勤怠記録
entity OU 所属単位
entity N 通知

# メインフロー 1〜3
A -> RL : 対象日を指定して勤怠修正申請ボタンを押す(UC-313 から)
note : 勤怠記録一覧表示画面の勤怠修正申請ボタンから勤怠修正申請画面に移る(画面遷移図)
RL -> C : 勤怠修正申請の入力を要求する(対象日)
C -> C : 対象日が当日以前で、修正申請の期限内かを判定する
note : 当月分はいつでも、前月分は当月N日まで、前々月以前は不可(備考4、#85)。N は TBD

# Alt-2
break 対象日が当日より後、または期限を過ぎている
C -> RL : 送信できないことを渡す
RL -> A : 対象日の勤怠修正申請を送信できないことを提示する
note : Alt-2。このユースケースを終了する
end

C -> DM : 対象日の「未処理」の勤怠修正申請を探す
DM -> AR : 対象日の「未処理」の勤怠修正申請を探す
AR --> DM : 有無
DM --> C : 有無

# Alt-3
break 「未処理」の勤怠修正申請がすでにある
C -> RL : すでにあることと、UC-310 から変更できることを渡す
RL -> A : 「未処理」の勤怠修正申請がすでにあることと、UC-310 から変更できることを提示する
note : Alt-3。このユースケースを終了する
end

# メインフロー 4〜6 と Alt-4
C -> DM : 対象日の勤怠記録の打刻の一覧を取得する
DM -> R : 対象日の勤怠記録の打刻の一覧を取得する
R --> DM : 打刻の一覧(種類, 打刻日時)
DM --> C : 打刻の一覧(種類, 打刻日時)
loop 誤りが無くなるまで繰り返す
C -> F : 現在の打刻の一覧を渡す
F -> A : 現在の打刻の一覧を提示し、修正後の打刻の一覧と申請理由の入力を求める
note : 修正後の打刻の一覧の初期値は現在の打刻の一覧(備考1)
A -> F : 修正後の打刻の一覧と申請理由を入力する
A -> F : 確認ボタンを押す
F -> C : 入力内容の検証を要求する(修正後の打刻の一覧, 申請理由)
C -> C : 打刻の一覧の整合と申請理由の有無を検証する
note : 出勤、0回以上の(休憩開始, 休憩終了)、退勤の順で、打刻日時が昇順(備考2)。申請理由は必須(備考5)
opt 誤りがある
C -> F : 誤りの内容を渡す
F -> A : 誤りの内容を提示する
note : Alt-4。メインフロー4に戻る
end
end

# メインフロー 7
C -> D : 申請内容を渡す(対象日, 現在の打刻の一覧, 修正後の打刻の一覧, 申請理由)
note : 勤怠修正申請画面の確認ボタンから入力確認ダイアログを開く(画面遷移図)
D -> A : 勤怠修正申請の内容を提示し、送信の確認を求める

# Ex-1
break 送信のキャンセルを要求した
A -> D : キャンセルボタンを押す
D -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> D : キャンセルの完了を渡す
D -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。勤怠修正申請は登録されない
end

# メインフロー 8〜9
A -> D : 送信ボタンを押す
D -> C : 送信を要求する
C -> DM : 勤怠修正申請を登録する(従業員, 対象日, 修正後の打刻の一覧, 申請理由, 送信日時, 処理状態=未処理)
DM -> AR : 勤怠修正申請を登録する(従業員, 対象日, 修正後の打刻の一覧, 申請理由, 送信日時, 処理状態=未処理)
note : 勤怠記録はまだ修正しない(事後条件、備考11)

# Ex-2 とメインフロー 10〜11
alt 保存に失敗した
C -> D : 保存に失敗したことを渡す
D -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー7に戻る
else 保存に成功した
C -> DM : アクターの所属を管理先に持つ勤怠管理者を取得する
DM -> OU : アクターの所属を管理先に持つ勤怠管理者を取得する
OU --> DM : 勤怠管理者の一覧
DM --> C : 勤怠管理者の一覧
C -> DM : 通知を登録する(勤怠管理者ごと, 勤怠修正申請が送信された)
DM -> N : 通知を登録する(勤怠管理者ごと, 勤怠修正申請が送信された)
note : 通知は UC-317 で提示される(備考7、ADR-0006)
C -> AL : 送信の完了を渡す
note : 入力確認ダイアログの送信ボタンから勤怠修正申請内容一覧表示画面に移る(画面遷移図)
AL -> A : 送信が完了したことを提示する
end
