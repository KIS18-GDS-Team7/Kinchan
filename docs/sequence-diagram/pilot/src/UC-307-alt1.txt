title UC-307 Alt-1 既存のシフト希望がある対象期間に送信する
scope Alt-1、Alt-3、Alt-5、Alt-6、Ex-1、Ex-2。メインフローと Alt-2、Alt-4(下書き保存)は別図(UC-307)

actor A 従業員
boundary HL シフト希望一覧表示画面
boundary F シフト希望入力画面
boundary D 入力確認ダイアログ
control C シフト希望制御
entity SH シフト希望
entity TP シフト対象受付期間
entity OU 所属単位
entity N 通知

# メインフロー 1〜2 (Alt-1 の開始)
A -> HL : 受付期間中の対象期間を指定してシフト希望の送信を要求する(UC-311 から)
note : シフト希望一覧表示画面のシフト希望入力ボタンからシフト希望入力画面に移る(画面遷移図)
HL -> C : シフト希望の入力を要求する(対象期間)
C -> TP : 対象期間を取得する
TP --> C : 対象期間開始日, 対象期間終了日

# Alt-1 の 1〜4 と Alt-3
loop 誤りが無くなるまで繰り返す
C -> SH : 対象期間のアクターの「取り下げ」以外のシフト希望を取得する
SH --> C : 各日のシフト希望(希望開始時刻, 希望終了時刻, 処理状態)
note : 「取り下げ」以外のシフト希望がある場合が Alt-1。無い場合はメインフロー(別図 UC-307)。「取り下げ」しか無い日は、シフト希望が無い日と同じに扱う(備考6)
C -> F : 対象期間の各日の既存のシフト希望と、変更できない日を渡す
F -> A : 対象期間の各日の「取り下げ」以外の既存のシフト希望(希望開始時刻・希望終了時刻、処理状態)を提示し、希望の入力を求める
F -> A : 「承認済」「却下」のシフト希望がある日は変更できないことを提示する
note : Alt-1の2。変更できるのは「下書き」「未処理」の日と、「取り下げ」以外のシフト希望が無い日(備考5・6)
A -> F : 希望を出す日の希望開始時刻・希望終了時刻を入力する
A -> F : 確認ボタンを押す
F -> C : 入力内容の検証を要求する(各日の希望開始時刻・希望終了時刻)
C -> C : 入力されたシフト希望を検証する
note : 希望を出す日が1日も無い、一方だけの入力、「未処理」の日の時刻が両方とも無い、希望終了時刻が希望開始時刻と同じ は誤り(Alt-3、備考1・5・8)
opt 誤りがある
C -> F : 誤りの内容を渡す
F -> A : 誤りの内容を提示する
note : Alt-3。Alt-1の1に戻る
end
end

# Alt-1 の 5
C -> D : 入力されたシフト希望の内容を渡す(希望日, 希望開始時刻, 希望終了時刻)
note : シフト希望入力画面の確認ボタンから入力確認ダイアログを開く(画面遷移図)
D -> A : 入力されたシフト希望の内容を提示し、送信の確認を求める

# Ex-1
break 送信のキャンセルを要求した
A -> D : キャンセルボタンを押す
D -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> D : キャンセルの完了を渡す
D -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフト希望は登録・更新されない。下書きとしての保存(Alt-4)は UC-307 の図に描いた
end

# Alt-1 の 6〜7
A -> D : 送信ボタンを押す
D -> C : 送信を要求する(各日の希望開始時刻・希望終了時刻)
C -> SH : 入力された日の既存のシフト希望の処理状態を取得する
SH --> C : 処理状態
C -> C : 処理状態が「下書き」「未処理」のままであることを検証する

# Alt-6 と、Alt-1 の 8 以降
alt 処理状態が「下書き」「未処理」でなくなっている
C -> D : 変更できないことを渡す
D -> A : 既存のシフト希望の処理状態が変わったため変更できないことを提示する
note : Alt-6。Alt-1の1に戻る(既存のシフト希望を取得し直して提示する)。提示した後に承認・却下・取り下げされた場合(備考6)
else 処理状態が「下書き」「未処理」のまま
C -> TP : 対象期間の受付期間を取得する
TP --> C : 受付期間開始日時, 受付期間終了日時
C -> C : 受付期間内かを判定する
note : Alt-1の8。送信を指示した時点で判定する(備考9)
alt 受付期間を過ぎている
C -> D : 送信できないことを渡す
D -> A : 受付期間を過ぎているためシフト希望を送信できないことを提示する
note : Alt-5。このユースケースを終了する
else 受付期間内
loop 「下書き」「未処理」の既存のシフト希望がある日のうち、入力された日ごと
C -> SH : シフト希望を入力された内容に更新し、処理状態を「未処理」に更新する(希望開始時刻, 希望終了時刻)
end
note : Alt-1の9〜10
loop 「取り下げ」以外のシフト希望が無い日のうち、入力された日ごと
C -> SH : シフト希望を登録する(従業員, 希望日, 希望開始時刻, 希望終了時刻, 送信日時, 処理状態=未処理)
end
note : Alt-1の11。更新と登録はまとめて保存する(Ex-2 の事後条件)
alt 保存に失敗した
C -> D : 保存に失敗したことを渡す
D -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、Alt-1の5に戻る
else 保存に成功した
C -> OU : アクターの所属を管理先に持つ勤怠管理者を取得する
OU --> C : 勤怠管理者の一覧
C -> N : 通知を登録する(勤怠管理者ごと, シフト希望が送信された)
note : Alt-1の12。通知は UC-317 で提示される(備考10、ADR-0006)
C -> HL : 送信の完了を渡す
note : Alt-1の13。メインフロー10に進む。入力確認ダイアログの送信ボタンからシフト希望一覧表示画面に移る(画面遷移図)
HL -> A : 送信が完了したことを提示する
end
end
end
