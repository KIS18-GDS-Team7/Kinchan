title UC-307 シフト希望を送信する
scope メインフロー、Alt-2、Alt-4、Alt-5、Ex-1、Ex-2。Alt-1(既存のシフト希望がある場合)と Alt-3、Alt-6 は別図(UC-307-alt1)

actor A 従業員
boundary HL シフト希望一覧表示画面
boundary F シフト希望入力画面
boundary D 入力確認ダイアログ
control C シフト希望制御
entity SH シフト希望
entity TP シフト対象受付期間
entity OU 所属単位
entity N 通知

# メインフロー 1
A -> HL : 受付期間中の対象期間を指定してシフト希望の送信を要求する(UC-311 から)
note : シフト希望一覧表示画面のシフト希望入力ボタンからシフト希望入力画面に移る(画面遷移図)
HL -> C : シフト希望の入力を要求する(対象期間)
C -> TP : 対象期間を取得する
TP --> C : 対象期間開始日, 対象期間終了日
C -> SH : 対象期間のアクターの「取り下げ」以外のシフト希望を探す
SH --> C : 有無
note : すでにある場合は Alt-1(別図 UC-307-alt1)。「取り下げ」しか無い日は、シフト希望が無い日と同じに扱う(備考6)

# メインフロー 2〜4 と Alt-2
loop 誤りが無くなるまで繰り返す
C -> F : 対象期間の各日を渡す
F -> A : 対象期間の各日を提示し、各日の希望の入力を求める
A -> F : 希望を出す日の希望開始時刻・希望終了時刻を入力する
A -> F : 確認ボタンを押す
F -> C : 入力内容の検証を要求する(各日の希望開始時刻・希望終了時刻)
C -> C : 入力されたシフト希望を検証する
note : 希望を出す日が1日も無い、一方だけの入力、希望終了時刻が希望開始時刻と同じ は誤り(Alt-2、備考1・8)。希望終了時刻が希望開始時刻より前なら日をまたぐ希望(備考8)
opt 誤りがある
C -> F : 誤りの内容を渡す
F -> A : 誤りの内容を提示する
note : Alt-2。メインフロー2に戻る
end
end

# メインフロー 5
C -> D : 入力されたシフト希望の内容を渡す(希望日, 希望開始時刻, 希望終了時刻)
note : シフト希望入力画面の確認ボタンから入力確認ダイアログを開く(画面遷移図)
D -> A : 入力されたシフト希望の内容を提示し、送信の確認を求める

# Ex-1
break 送信のキャンセルを要求した
A -> D : キャンセルボタンを押す
D -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> D : キャンセルの完了を渡す
D -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフト希望は登録・更新されない
end

# Alt-4 (メインフロー6 または Alt-1 の 6 から) と Ex-2
break 下書きとしての保存を指示した
A -> D : 下書き保存ボタンを押す
note : 下書き保存ボタンは画面遷移図にない(暫定)
D -> C : 下書きとしての保存を要求する(各日の希望開始時刻・希望終了時刻)
opt 「下書き」の既存のシフト希望がある日の入力がある
C -> SH : 「下書き」の既存のシフト希望を入力された内容に更新する(希望開始時刻, 希望終了時刻)
note : Alt-4の2。Alt-1の6から下書き保存した場合に当たる(メインフローでは既存のシフト希望が無い)。「未処理」の日を変更して下書き保存した場合の扱いは TBD(備考13)
end
loop 「取り下げ」以外のシフト希望が無い日のうち、入力された日ごと
C -> SH : シフト希望を登録する(従業員, 希望日, 希望開始時刻, 希望終了時刻, 処理状態=下書き)
end
note : Alt-4の3。更新と登録はまとめて保存する(Ex-2 の事後条件)。下書きは勤怠管理者に提示されない(備考4)。受付期間を判定するかは TBD(備考11)
alt 保存に失敗した
C -> D : 保存に失敗したことを渡す
D -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、確認を求めるステップ(メインフロー5またはAlt-1の5)に戻る
else 保存に成功した
C -> D : 下書きとしての保存の完了を渡す
note : 下書き保存の後の遷移先は画面遷移図にない(暫定)
D -> A : 下書きとしての保存が完了したことを提示する
note : Alt-4。このユースケースを終了する
end
end

# メインフロー 6〜7
A -> D : 送信ボタンを押す
D -> C : 送信を要求する(各日の希望開始時刻・希望終了時刻)
C -> TP : 対象期間の受付期間を取得する
TP --> C : 受付期間開始日時, 受付期間終了日時
C -> C : 受付期間内かを判定する
note : 送信を指示した時点で判定する(備考9)

# Alt-5
break 受付期間を過ぎている
C -> D : 送信できないことを渡す
D -> A : 受付期間を過ぎているためシフト希望を送信できないことを提示する
note : Alt-5。このユースケースを終了する
end

# メインフロー 8
loop 希望開始時刻・希望終了時刻が入力された日ごと
C -> SH : シフト希望を登録する(従業員, 希望日, 希望開始時刻, 希望終了時刻, 送信日時, 処理状態=未処理)
end
note : 1件は1日分(備考1・2)。各日の登録はまとめて保存する(Ex-2 の事後条件)。シフトは登録しない(事後条件、備考3)

# Ex-2 とメインフロー 9〜10
alt 保存に失敗した
C -> D : 保存に失敗したことを渡す
D -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー5に戻る
else 保存に成功した
C -> OU : アクターの所属を管理先に持つ勤怠管理者を取得する
OU --> C : 勤怠管理者の一覧
C -> N : 通知を登録する(勤怠管理者ごと, シフト希望が送信された)
note : 通知は UC-317 で提示される(備考10、ADR-0006)
C -> HL : 送信の完了を渡す
note : 入力確認ダイアログの送信ボタンからシフト希望一覧表示画面に移る(画面遷移図)
HL -> A : 送信が完了したことを提示する
end
