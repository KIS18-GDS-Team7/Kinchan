title UC-308 シフトを一覧表示する
scope メインフロー、Alt-1〜3

actor A 従業員
boundary H 従業員ホーム画面
boundary L シフト一覧表示画面
control C シフト表示制御
participant DM DataManager
entity U 従業員
entity TP シフト対象受付期間
entity SF シフト

# メインフロー 1
A -> H : シフトボタンを押す(シフトの一覧表示を要求する)
note : 従業員ホーム画面のシフトボタンからシフト一覧表示画面に移る(画面遷移図)
H -> C : シフトの一覧を要求する
C -> DM : アクターの所属単位を取得する
DM -> U : アクターの所属単位を取得する
U --> DM : 所属単位
DM --> C : 所属単位
C -> DM : 所属単位に登録された対象期間を取得する
DM -> TP : 所属単位に登録された対象期間を取得する
TP --> DM : 対象期間の一覧
DM --> C : 対象期間の一覧

# Alt-3
break 対象期間が登録されていない
C -> L : 対象期間が登録されていないことを渡す
L -> A : 対象期間が登録されていないことを提示する
note : Alt-3。このユースケースを終了する
end

# メインフロー 2 と Alt-1・Alt-2
loop 提示する対象期間を切り替えるたびに繰り返す
C -> DM : 対象期間の、所属単位の従業員の公開済みのシフトを取得する
DM -> SF : 対象期間の、所属単位の従業員の公開済みのシフトを取得する
SF --> DM : シフトの一覧(従業員名, 勤務日, 開始時刻, 終了時刻)
DM --> C : シフトの一覧(従業員名, 勤務日, 開始時刻, 終了時刻)
note : 1回目はメインフロー2(最初に提示する対象期間は TBD、備考6)、2回目以降は Alt-1の2。公開済みのシフトだけで、下書きは提示しない(備考1)。アクター自身を含む所属単位の従業員の分(備考3)
alt その対象期間に公開済みのシフトが存在しない
C -> L : 公開済みのシフトが存在しないことを渡す
L -> A : 該当する公開済みのシフトが存在しないことを提示する
note : Alt-2(メインフロー2またはAlt-1の2)。Alt-1の1に進む(備考6)
else 公開済みのシフトが存在する
C -> L : 対象期間のシフトの一覧を渡す(従業員名, 勤務日, 開始時刻, 終了時刻)
L -> A : 対象期間の公開済みのシフトの一覧(従業員名、勤務日、開始時刻、終了時刻)を提示する
end
opt 提示する対象期間を切り替えた
A -> L : 提示する対象期間を指定する
L -> C : シフトの一覧を要求する(対象期間)
note : Alt-1の1。指定された対象期間でループの先頭(Alt-1の2)に戻る
end
end

# メインフロー 3〜4
A -> L : 一覧からシフトを1件指定する
note : Alt-1の3。対象期間を切り替えた後もここに戻る
L -> C : シフトの詳細を要求する(シフト)
C -> DM : シフトを取得する
DM -> SF : シフトを取得する
SF --> DM : 従業員名, 勤務日, 開始時刻, 終了時刻
DM --> C : 従業員名, 勤務日, 開始時刻, 終了時刻
C -> L : シフトの詳細を渡す(従業員名, 勤務日, 開始時刻, 終了時刻)
L -> A : 指定されたシフトの詳細(従業員名、勤務日、開始時刻、終了時刻)を提示する
note : 拡張点: アクター自身の公開済みのシフトを指定してシフト日時変更申請の送信を要求すると UC-309
