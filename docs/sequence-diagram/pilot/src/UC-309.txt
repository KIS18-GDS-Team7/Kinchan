title UC-309 シフト日時変更申請を送信する
scope メインフロー、Alt-1〜7、Ex-1、Ex-2

actor A 従業員
boundary L シフト一覧表示画面
boundary F シフト日時変更申請表示画面
boundary D 入力確認ダイアログ
control C シフト日時変更申請制御
entity SF シフト
entity CR シフト日時変更申請
entity TP シフト対象受付期間
entity OU 所属単位
entity N 通知

# メインフロー 1〜2
A -> L : アクター自身のシフトを指定してシフト日時変更申請の送信を要求する(UC-308 から)
note : シフト一覧表示画面のシフト変更申請ボタンからシフト日時変更申請表示画面に移る(画面遷移図)
L -> C : シフト日時変更申請の入力を要求する(シフト)
C -> SF : 対象のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻
C -> C : 対象のシフトの勤務日が翌日以降かを判定する
note : 対象は勤務日が翌日以降のシフト(備考2、A-36)

# Alt-1
break 勤務日が翌日以降でない
C -> L : 対象にできないことを表示する
L -> A : 勤務日が翌日以降のシフトだけを対象にできることを提示する
note : Alt-1。このユースケースを終了する
end

# メインフロー 3
C -> CR : 対象のシフトの「未処理」のシフト日時変更申請を探す
CR --> C : 有無

# Alt-2
break 「未処理」のシフト日時変更申請がすでにある
C -> L : 送信できないことを表示する
L -> A : 「未処理」のシフト日時変更申請があるため送信できないことを提示する
note : Alt-2。このユースケースを終了する。取り下げた後は再び送信できる(備考7)
end

# メインフロー 4〜8 と Alt-3〜6
loop 誤りが無くなるまで繰り返す
C -> F : 変更前のシフトを表示する(勤務日, 開始時刻, 終了時刻)
F -> A : 変更前のシフト(勤務日、開始時刻、終了時刻)を提示し、変更後の勤務日・開始時刻・終了時刻と申請理由の入力を求める
A -> F : 変更後の勤務日・開始時刻・終了時刻と申請理由を入力する
A -> F : 確認ボタンを押す
F -> C : 入力内容の検証を要求する(変更後の勤務日, 開始時刻, 終了時刻, 申請理由)
C -> C : 入力された内容を検証する
note : 申請理由なし、日時のいずれかが未入力、終了時刻が開始時刻と同じ は誤り(Alt-3、備考3)。変更前と同じ日時は不可(Alt-4、A-83)。終了時刻が開始時刻より前なら日をまたぐ(備考8)
alt 誤りがある、または変更前と同じ日時
C -> F : 誤りの内容、または変更前と同じ日時であることを表示する
F -> A : 誤りの内容、または変更前と同じ日時であるため送信できないことを提示する
note : Alt-3・Alt-4。メインフロー4に戻る
else 誤りが無い
C -> C : 変更後の勤務日が当日以降かを判定する
note : メインフロー7(備考5)
alt 変更後の勤務日が当日より前
C -> F : 変更後の勤務日が当日より前であることを表示する
F -> A : 変更後の勤務日が当日より前であるため送信できないことを提示する
note : Alt-5。メインフロー4に戻る
else 変更後の勤務日が当日以降
C -> TP : アクターの所属に登録された対象期間を取得する
TP --> C : 対象期間の一覧
C -> C : 変更後の勤務日がアクターの所属に登録された対象期間に含まれるかを判定する
note : メインフロー8(備考4)
opt 対象期間に含まれない
C -> F : 変更後の勤務日が対象期間に含まれないことを表示する
F -> A : 変更後の勤務日が対象期間に含まれないことを提示する
note : Alt-6。メインフロー4に戻る
end
end
end
end

# メインフロー 9 と Alt-7
C -> SF : 変更後の日時と重複するアクターの他の公開済みのシフトを探す
SF --> C : 重複するシフト(勤務日, 開始時刻, 終了時刻)
note : 公開済みのシフトだけを対象にし、下書きのシフトは提示しない(備考6)
opt 重複する公開済みのシフトがある
C -> F : 重複する公開済みのシフトを表示する
F -> A : 重複する公開済みのシフトを提示する
note : Alt-7。メインフロー10に進む。重複していても送信できる(備考6、A-62)
end

# メインフロー 10
C -> D : 申請の内容を表示する(変更前のシフト, 変更後の勤務日・開始時刻・終了時刻, 申請理由)
note : シフト日時変更申請表示画面の確認ボタンから入力確認ダイアログを開く(画面遷移図)
D -> A : 申請の内容(変更前のシフト、変更後の勤務日・開始時刻・終了時刻、申請理由)を提示し、送信の確認を求める

# Ex-1
break 送信のキャンセルを要求した
A -> D : キャンセルボタンを押す
D -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> D : キャンセルの完了を表示する
D -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。シフト日時変更申請は登録されない
end

# メインフロー 11〜12
A -> D : 送信ボタンを押す
D -> C : 送信を要求する
C -> CR : シフト日時変更申請を登録する(従業員, シフト, 変更後勤務日, 変更後開始時刻, 変更後終了時刻, 申請理由, 送信日時, 処理状態=未処理)
note : 承認されるまで対象のシフトは変更しない(事後条件、備考10)

# Ex-2 とメインフロー 13〜14
alt 保存に失敗した
C -> D : 保存に失敗したことを表示する
D -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー10に戻る
else 保存に成功した
C -> OU : アクターの所属を管理先に持つ勤怠管理者を取得する
OU --> C : 勤怠管理者の一覧
C -> N : 通知を登録する(勤怠管理者ごと, シフト日時変更申請が送信された)
note : 通知は UC-317 で提示される(備考9、ADR-0006)
C -> D : 送信の完了を表示する
note : 送信後の遷移先は画面遷移図で読み取れない(入力確認ダイアログからの線はラベルが無く、勤怠修正申請内容一覧表示画面に向いている)。暫定で入力確認ダイアログから提示する
D -> A : 送信が完了したことを提示する
end
