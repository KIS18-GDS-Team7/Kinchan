title UC-310 勤怠修正申請内容を一覧表示する
scope メインフロー、Alt-1〜4

actor A 従業員
boundary H 従業員ホーム画面
boundary AL 勤怠修正申請内容一覧表示画面
control C 勤怠修正申請制御
entity AR 勤怠修正申請
entity R 勤怠記録

# メインフロー 1〜2 と Alt-1
A -> H : 勤怠修正申請ボタンを押す(勤怠修正申請の一覧表示を要求する)
note : 従業員ホーム画面の勤怠修正申請ボタンから勤怠修正申請内容一覧表示画面に移る(画面遷移図)
H -> C : 勤怠修正申請の一覧を要求する
C -> AR : アクター自身の勤怠修正申請を取得する
AR --> C : 一覧(対象日, 送信日時, 処理状態)
note : 処理状態にかかわらずすべて提示する(「未処理」「承認済」「却下」「取り下げ」、備考1・3)
alt 該当する勤怠修正申請が存在しない
C -> AL : 存在しないことを表示する
AL -> A : 該当する勤怠修正申請が存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 勤怠修正申請が存在する
C -> AL : 勤怠修正申請の一覧を表示する(対象日, 送信日時, 処理状態)
AL -> A : アクター自身の勤怠修正申請の一覧(対象日、送信日時、処理状態)を提示する
end

# Alt-2〜4
loop 条件を指定して探すたびに繰り返す(0回以上)
A -> AL : 条件(期間, 処理状態)を指定する
note : Alt-2の1
AL -> C : 条件に合う一覧を要求する(期間, 処理状態)
C -> C : 指定された条件を検証する
alt 期間の開始日が終了日より後
C -> AL : 期間の指定の誤りを表示する
AL -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 誤りが無い
C -> AR : 条件に合うアクター自身の勤怠修正申請を取得する
AR --> C : 一覧(対象日, 送信日時, 処理状態)
note : 期間は対象日で絞る(備考4、暫定)
alt 条件に合う勤怠修正申請が存在しない
C -> AL : 存在しないことを表示する
AL -> A : 条件に合う勤怠修正申請が存在しないことを提示する
note : Alt-4。Alt-2の1に戻る
else 条件に合う勤怠修正申請が存在する
C -> AL : 条件に合う一覧を表示する(対象日, 送信日時, 処理状態)
AL -> A : 条件に合う勤怠修正申請の一覧を提示する
note : Alt-2の4。メインフロー3に戻る
end
end
end

# メインフロー 3〜4
A -> AL : 詳細を提示する勤怠修正申請を指定する
AL -> C : 勤怠修正申請の詳細を要求する(勤怠修正申請)
C -> AR : 勤怠修正申請を取得する
AR --> C : 対象日, 修正後の打刻の一覧, 申請理由, 処理状態, 却下理由, 送信日時
C -> R : 対象日の勤怠記録の打刻の一覧を取得する
R --> C : 打刻の一覧(種類, 打刻日時)
C -> AL : 勤怠修正申請の詳細を表示する(対象日, 打刻の一覧, 修正後の打刻の一覧, 申請理由, 処理状態, 送信日時)
AL -> A : 指定された勤怠修正申請の詳細(対象日、対象日の勤怠記録の打刻の一覧、修正後の打刻の一覧、申請理由、処理状態、送信日時)を提示する
note : 拡張点: 「未処理」なら変更(UC-306 Alt-1、別図 UC-306-alt1)、取り下げ(UC-314)を要求できる(備考6・7)
opt 処理状態が「却下」
C -> AL : 却下理由を表示する
AL -> A : 却下理由を提示する
note : 却下理由は「却下」のときに提示する(備考2、A-51)
end
