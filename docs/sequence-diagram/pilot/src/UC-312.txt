title UC-312 休憩を打刻する
scope メインフロー、Alt-1、Ex-1

actor A 従業員
boundary H 従業員ホーム画面
control C 打刻制御
entity U 従業員
entity R 勤怠記録
entity P 打刻

# メインフロー 1〜2
A -> H : 休憩開始ボタンまたは休憩終了ボタンを押す(打刻の種類)
H -> C : 打刻を要求する(打刻の種類)
C -> U : 勤務ステータスを取得する
U --> C : 勤務ステータス
note : 勤務ステータスは概念クラス図にない(UC-304 備考2、暫定)
C -> C : 打刻の種類と勤務ステータスの整合を判定する
note : 「休憩開始」は「出勤中」のとき、「休憩終了」は「休憩中」のときに整合する(備考2、A-67)

# Alt-1
break 整合しない
C -> H : 打刻できない理由を表示する
H -> A : 打刻できないことと、その理由を提示する
note : Alt-1。このユースケースを終了する
end

# メインフロー 3〜4
C -> R : 打刻が属する勤怠記録を取得する
R --> C : 勤怠記録
note : 日をまたぐ勤務の休憩も、出勤打刻を行った日の勤怠記録に属する(備考7、#82)
C -> P : 打刻を記録する(種類, 打刻日時)
C -> U : 勤務ステータスを更新する(休憩中/出勤中)
note : 打刻と勤務ステータスはまとめて保存する(Ex-1 の事後条件)

# Ex-1
break 保存に失敗した
C -> H : 保存に失敗したことを表示する
H -> A : 保存に失敗したことを提示する
note : Ex-1。このユースケースを中断する
end

# メインフロー 5
C -> H : 打刻の結果を表示する(打刻の種類, 打刻日時, 更新後の勤務ステータス)
H -> A : 打刻の種類、打刻日時、更新後の勤務ステータスを提示する
note : 打刻日時は秒まで提示する(備考4)
