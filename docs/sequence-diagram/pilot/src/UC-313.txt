title UC-313 勤怠記録を一覧表示する
scope メインフロー、Alt-1〜4

actor A 従業員
boundary H 従業員ホーム画面
boundary L 勤怠記録一覧表示画面
control C 勤怠記録制御
entity R 勤怠記録
entity SF シフト
entity AR 勤怠修正申請
entity RH 勤怠修正履歴

# メインフロー 1〜2
A -> H : 勤怠ボタンを押す(勤怠記録の一覧表示を要求する)
note : 従業員ホーム画面の勤怠ボタンから勤怠記録一覧表示画面に移る(画面遷移図)
H -> C : 勤怠記録の一覧を要求する(当月)
note : 初期の期間は当月(備考1、A-48、暫定)
C -> R : 当月のアクター自身の勤怠記録を取得する
R --> C : 日ごとの打刻の一覧(種類, 打刻日時)
note : 勤怠記録は出勤打刻を行った日に属する(備考1、#82)
C -> SF : 当月のアクター自身の公開済みのシフトを取得する
SF --> C : シフトの一覧(勤務日, 開始時刻, 終了時刻)
note : 下書きのシフトは提示しない(備考4)
C -> AR : 当月の日を対象日とする勤怠修正申請の処理状態を取得する
AR --> C : 日ごとの処理状態
loop 日ごとに繰り返す
C -> C : 休憩時間と勤務時間を計算する
note : 休憩時間は休憩開始〜休憩終了の合計と、同じ日の勤務と勤務の間の空白時間の合計。勤務時間は各勤務の時間の合計から勤務の中の休憩を引く。秒を切り捨てて分単位(備考3、暫定)
end

# Alt-1
alt 該当する勤怠記録も公開済みのシフトも存在しない
C -> L : 勤怠記録も公開済みのシフトも存在しないことを表示する
L -> A : 該当する勤怠記録も公開済みのシフトも存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 存在する
C -> L : 勤怠記録の一覧を表示する(日ごとのシフト, 打刻の一覧, 休憩時間, 勤務時間, 勤怠修正申請の処理状態)
L -> A : 当月のアクター自身の勤怠記録の一覧を提示する
note : 打刻日時は秒まで提示する(備考2)
end

# Alt-2〜4
loop 条件(期間)を指定して探す間、繰り返す(Alt-1 の後を含む)
A -> L : 条件(期間)を指定する
L -> C : 条件に合う勤怠記録の一覧を要求する(期間)
C -> C : 期間の開始日が終了日以前であることを検証する
alt 期間の開始日が終了日より後
C -> L : 期間の指定の誤りを表示する
L -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 誤りが無い
C -> R : 期間のアクター自身の勤怠記録を取得する
R --> C : 日ごとの打刻の一覧(種類, 打刻日時)
C -> SF : 期間のアクター自身の公開済みのシフトを取得する
SF --> C : シフトの一覧(勤務日, 開始時刻, 終了時刻)
C -> AR : 期間の日を対象日とする勤怠修正申請の処理状態を取得する
AR --> C : 日ごとの処理状態
loop 日ごとに繰り返す
C -> C : 休憩時間と勤務時間を計算する
note : メインフロー2と同じ計算(備考3)
end
alt 条件に合う勤怠記録も公開済みのシフトも存在しない
C -> L : 条件に合う勤怠記録も公開済みのシフトも存在しないことを表示する
L -> A : 条件に合う勤怠記録も公開済みのシフトも存在しないことを提示する
note : Alt-4。Alt-2の1に戻る
else 存在する
C -> L : 条件に合う勤怠記録の一覧を表示する(日ごとのシフト, 打刻の一覧, 休憩時間, 勤務時間, 勤怠修正申請の処理状態)
L -> A : 条件に合うアクター自身の勤怠記録の一覧を提示する
note : Alt-2。メインフロー3に戻る
end
end
end

# メインフロー 3〜4
A -> L : 詳細を提示する日を指定する
L -> C : 勤怠記録の詳細を要求する(日)
C -> R : 指定された日の勤怠記録を取得する
R --> C : 打刻の一覧(種類, 打刻日時)
C -> RH : 指定された日の勤怠記録の修正履歴を取得する
RH --> C : 修正履歴の一覧(修正前内容, 修正者, 修正日時, 修正理由, 根拠)
note : 修正者・根拠は概念クラス図にない(備考5、暫定)。修正履歴は削除できない(備考5)
C -> C : 休憩時間と勤務時間を計算する
C -> L : 勤怠記録の詳細を表示する(打刻の一覧, 休憩時間, 勤務時間, 修正履歴)
L -> A : 指定された日の勤怠記録の詳細(打刻の一覧、休憩時間、勤務時間、修正履歴)を提示する
note : 拡張点: 指定した日について勤怠修正申請の送信を要求した場合 → UC-306(メインフロー4の後)
