title UC-315 シフト希望を取り下げる
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A 従業員
boundary L シフト希望一覧表示画面
control C シフト希望制御
entity SH シフト希望

# メインフロー 1〜2
A -> L : 「未処理」のシフト希望を指定して取り下げを要求する(UC-311 から)
note : 「下書き」のシフト希望は取り下げの対象外(備考4)
L -> C : 取り下げるシフト希望の内容を要求する(シフト希望)
C -> SH : シフト希望を取得する
SH --> C : 希望日, 希望開始時刻, 希望終了時刻, 送信日時, 処理状態
C -> L : 取り下げるシフト希望の内容を表示する
L -> A : 取り下げるシフト希望の内容を提示し、取り下げの確認を求める
note : 取り下げの確認を求める画面は画面遷移図にない(暫定)

# Ex-1
break 取り下げのキャンセルを要求した
A -> L : キャンセルボタンを押す
L -> C : キャンセルを要求する
C -> L : キャンセルの完了を表示する
L -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらない
end

# メインフロー 3〜4
A -> L : シフト希望の取り下げを指示する
L -> C : 取り下げを要求する(シフト希望)
C -> SH : 処理状態を取得する
SH --> C : 処理状態
C -> C : 処理状態が「未処理」であることを検証する

# Alt-1
break 処理状態が「未処理」でなくなっている
C -> L : 取り下げできないことを表示する
L -> A : 対象のシフト希望が取り下げできない状態であることを提示する
note : Alt-1。このユースケースを終了する。一覧を提示した後に承認・却下・取り下げされた場合に当たる(備考5)
end

# メインフロー 5
C -> SH : 処理状態を「取り下げ」に更新する
note : 削除しない(備考2、A-6)。1日分(1件)ずつ取り下げる(備考3、暫定)。シフトは登録しない(事後条件)

# Ex-2 とメインフロー 6
alt 保存に失敗した
C -> L : 保存に失敗したことを表示する
L -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー2に戻る
else 保存に成功した
C -> L : 取り下げの完了を表示する
note : 勤怠管理者には通知しない(備考6)
L -> A : 取り下げが完了したことを提示する
end
