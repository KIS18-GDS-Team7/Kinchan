title UC-318 シフト日時変更申請内容を一覧表示する
scope メインフロー、Alt-1〜4

actor A 従業員
boundary L シフト日時変更申請表示画面
control C シフト日時変更申請制御
entity SR シフト日時変更申請
entity SF シフト

# メインフロー 1〜2
A -> L : シフト日時変更申請の一覧表示を要求する
note : 申請内容の一覧画面は画面遷移図にない(暫定)。画面遷移図のシフト日時変更申請表示画面は UC-309 の入力画面
L -> C : シフト日時変更申請の一覧を要求する
C -> SR : アクター自身のシフト日時変更申請を取得する
SR --> C : 一覧(変更後勤務日, 変更後開始時刻, 変更後終了時刻, 処理状態, 送信日時)
note : 処理状態にかかわらずすべて提示する(未処理・承認済・却下・取り下げ、備考1、備考3)
loop 申請ごとに繰り返す
C -> SF : 変更前のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻
end

# Alt-1
alt 該当するシフト日時変更申請が存在しない
C -> L : シフト日時変更申請が存在しないことを表示する
L -> A : 該当するシフト日時変更申請が存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 存在する
C -> L : シフト日時変更申請の一覧を表示する(変更前のシフト, 変更後の勤務日・開始時刻・終了時刻, 処理状態, 送信日時)
L -> A : アクター自身のシフト日時変更申請の一覧を提示する
end

# Alt-2〜4
loop 条件(期間, 処理状態)を指定して探す間、繰り返す(Alt-1 の後を含む)
A -> L : 条件(期間, 処理状態)を指定する
L -> C : 条件に合う一覧を要求する(期間, 処理状態)
C -> C : 期間の開始日が終了日以前であることを検証する
alt 期間の開始日が終了日より後
C -> L : 期間の指定の誤りを表示する
L -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 誤りが無い
C -> SR : 処理状態が条件に合うアクター自身のシフト日時変更申請を取得する
SR --> C : 一覧(変更後勤務日, 変更後開始時刻, 変更後終了時刻, 処理状態, 送信日時)
loop 申請ごとに繰り返す
C -> SF : 変更前のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻
end
C -> C : 変更前のシフトの勤務日が期間に含まれる申請に絞り込む
note : 期間は変更前のシフトの勤務日で絞る(備考4、暫定)
alt 条件に合うシフト日時変更申請が存在しない
C -> L : 条件に合うシフト日時変更申請が存在しないことを表示する
L -> A : 条件に合うシフト日時変更申請が存在しないことを提示する
note : Alt-4。Alt-2の1に戻る
else 存在する
C -> L : 条件に合う一覧を表示する(変更前のシフト, 変更後の勤務日・開始時刻・終了時刻, 処理状態, 送信日時)
L -> A : 条件に合うシフト日時変更申請の一覧を提示する
note : Alt-2。メインフロー3に戻る
end
end
end

# メインフロー 3〜4
A -> L : 一覧からシフト日時変更申請を1件指定する
L -> C : 詳細を要求する(シフト日時変更申請)
C -> SR : シフト日時変更申請を取得する
SR --> C : 変更後勤務日, 変更後開始時刻, 変更後終了時刻, 申請理由, 処理状態, 却下理由, 送信日時
C -> SF : 変更前のシフトを取得する
SF --> C : 勤務日, 開始時刻, 終了時刻
C -> L : 詳細を表示する(変更前のシフト, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態, 却下理由, 送信日時)
L -> A : 指定されたシフト日時変更申請の詳細を提示する
note : 却下理由は「却下」のときだけ提示する(備考2)。「未処理」なら取り下げ → UC-316(備考7)。ここからは送信・変更できない(備考8)
