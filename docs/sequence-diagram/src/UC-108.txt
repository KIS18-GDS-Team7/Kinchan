title UC-108 所属単位を登録する
scope メインフロー、Alt-1、Alt-2、Ex-1、Ex-2

actor A マスタ管理者
boundary L 所属一覧画面
boundary F 所属編集画面
control C 所属単位制御
participant DM DataManager
entity OU 所属単位

# メインフロー 1
A -> L : 所属追加ボタンを押す(所属単位の登録を要求する)
note : 所属一覧画面の所属追加ボタンから所属編集画面に移る(画面遷移図)
L -> C : 所属単位の登録を要求する
C -> F : 所属編集画面を渡す

# メインフロー 2〜4 と Alt-1・Alt-2
loop 誤りが無くなるまで繰り返す
F -> A : 所属単位の名称の入力を求める
A -> F : 所属単位の名称を入力する
F -> C : 入力内容の検証を要求する(名称)
C -> C : 名称が入力されているかを検証する
C -> DM : 同じ名称の所属単位を探す
DM -> OU : 同じ名称の所属単位を探す
OU --> DM : 有無
DM --> C : 有無
note : 名称は必須で、同じ名称は登録できない(備考2、暫定)
opt 名称が入力されていない、または名称が重複している
C -> F : 登録できない理由を渡す
F -> A : 名称の入力が必要であること、または名称が重複していることを提示する
note : Alt-1・Alt-2。メインフロー2に戻る
end
end

# メインフロー 5
C -> F : 入力された名称を渡す
F -> A : 入力された名称を提示し、登録の確認を求める

# Ex-1
break 登録のキャンセルを要求した
A -> F : キャンセルボタンを押す
F -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> F : キャンセルの完了を渡す
F -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。所属単位は登録されない
end

# メインフロー 6〜7
A -> F : 追加ボタンを押す(所属単位の登録を指示する)
F -> C : 所属単位の登録を要求する(名称)
C -> DM : 所属単位を登録する(名称)
DM -> OU : 所属単位を登録する(名称)
note : 所属単位は入れ子にしない(備考1、ADR-0007)。変更・削除は TBD(備考3)。置ける勤怠管理者の人数は TBD(備考4)

# Ex-2 とメインフロー 8
alt 保存に失敗した
C -> F : 保存に失敗したことを渡す
F -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー5に戻る
else 保存に成功した
C -> L : 所属単位の登録の完了を渡す
note : 所属編集画面の追加ボタンから所属一覧画面に戻る(画面遷移図)
L -> A : 所属単位の登録が完了したことを提示する
end
