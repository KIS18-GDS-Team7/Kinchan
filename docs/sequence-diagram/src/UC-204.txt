title UC-204 シフト希望を一覧表示する
scope メインフロー、Alt-1〜5

actor A 勤怠管理者
boundary H 勤怠管理者ホーム画面
boundary L 従業員シフト希望一覧表示画面
control C シフト希望承認制御
participant DM DataManager
entity OU 所属単位
entity SH シフト希望
entity TP シフト対象受付期間
entity SF シフト

# メインフロー 1〜2 と Alt-1
A -> H : シフト希望確認ボタンを押す(シフト希望の一覧表示を要求する)
note : 勤怠管理者ホーム画面のシフト希望確認ボタンから従業員シフト希望一覧表示画面に移る(画面遷移図)
H -> C : シフト希望の一覧を要求する
C -> DM : アクターの管理先の従業員を取得する
DM -> OU : アクターの管理先の従業員を取得する
OU --> DM : 従業員の一覧
DM --> C : 従業員の一覧
note : 管理先が複数ならすべての管理先の分(備考1)。削除済みユーザーは通常含めない(備考4)
C -> DM : 管理先の従業員の「未処理」のシフト希望を取得する
DM -> SH : 管理先の従業員の「未処理」のシフト希望を取得する
SH --> DM : 一覧(従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 送信日時)
DM --> C : 一覧(従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 送信日時)
note : 「下書き」のシフト希望は提示しない(備考2、#87)
alt 「未処理」のシフト希望が存在しない
C -> L : 「未処理」のシフト希望が存在しないことを渡す
L -> A : 「未処理」のシフト希望が存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 「未処理」のシフト希望が存在する
C -> L : 「未処理」のシフト希望の一覧を渡す
L -> A : 「未処理」のシフト希望の一覧(従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 送信日時)を提示する
end

# Alt-2〜5
loop アクターが条件を指定して探す間、繰り返す
A -> L : 条件(期間, 従業員, 処理状態, 管理先, 削除済みユーザーを含めるか)を指定する
L -> C : 条件に合う一覧を要求する(期間, 従業員, 処理状態, 管理先, 削除済みユーザーを含めるか)
C -> C : 指定された条件を検証する
alt 期間の開始日が終了日より後
C -> L : 期間の指定の誤りを渡す
L -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 期間の指定に誤りが無い
C -> DM : 条件に合うシフト希望を取得する
DM -> SH : 条件に合うシフト希望を取得する
SH --> DM : 一覧(従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 送信日時)
DM --> C : 一覧(従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 送信日時)
note : 期間は希望日で絞る(備考3)。「承認済」「却下」「取り下げ」も提示できる(備考2)。指定があれば削除済みユーザーの分を含める(Alt-4、備考4)
alt 条件に合うシフト希望が存在しない
C -> L : 条件に合うシフト希望が存在しないことを渡す
L -> A : 条件に合うシフト希望が存在しないことを提示する
note : Alt-5。Alt-2の1に戻る
else 条件に合うシフト希望が存在する
C -> L : 条件に合うシフト希望の一覧を渡す
L -> A : 条件に合うシフト希望の一覧を提示する
note : Alt-2の3、Alt-4。メインフロー3に戻る
end
end
end

# メインフロー 3〜4
A -> L : 詳細を提示するシフト希望を指定する
L -> C : シフト希望の詳細を要求する(シフト希望)
C -> DM : シフト希望を取得する
DM -> SH : シフト希望を取得する
SH --> DM : 従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 却下理由, 送信日時
DM --> C : 従業員名, 所属単位, 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 却下理由, 送信日時
C -> DM : 所属単位に登録された、希望日を含む対象期間を取得する
DM -> TP : 所属単位に登録された、希望日を含む対象期間を取得する
TP --> DM : 対象期間開始日, 対象期間終了日
DM --> C : 対象期間開始日, 対象期間終了日
note : 対象期間はシフト希望の属性ではなく、シフト対象受付期間から取得する(概念クラス図)
C -> DM : 希望日に登録済みの同じ所属単位のシフトを取得する
DM -> SF : 希望日に登録済みの同じ所属単位のシフトを取得する
SF --> DM : シフトの一覧
DM --> C : シフトの一覧
C -> L : シフト希望の詳細と、希望日のシフトを渡す
L -> A : シフト希望の詳細(従業員名, 所属単位, 対象期間, 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 却下理由, 送信日時)と、希望日に登録済みの同じ所属単位のシフトを提示する
note : 却下理由は「却下」のときだけ。拡張点:「未処理」なら承認 → UC-205、却下 → UC-206。削除済みユーザーの分は却下だけできる(備考4)
