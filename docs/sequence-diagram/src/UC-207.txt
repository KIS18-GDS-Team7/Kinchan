title UC-207 勤怠修正申請を一覧表示する
scope メインフロー、Alt-1〜6

actor A 勤怠管理者
boundary H 勤怠管理者ホーム画面
boundary L 勤怠修正申請一覧表示画面
control C 勤怠修正承認制御
participant DM DataManager
entity OU 所属単位
entity AR 勤怠修正申請
entity R 勤怠記録
entity SF シフト

# メインフロー 1〜2 と Alt-1
A -> H : 勤怠修正申請確認ボタンを押す(勤怠修正申請の一覧表示を要求する)
note : 勤怠管理者ホーム画面の勤怠修正申請確認ボタンから勤怠修正申請一覧表示画面に移る(画面遷移図)
H -> C : 勤怠修正申請の一覧を要求する
C -> DM : アクターの管理先の従業員を取得する
DM -> OU : アクターの管理先の従業員を取得する
OU --> DM : 従業員の一覧
DM --> C : 従業員の一覧
note : 管理先が複数ならすべての管理先の分(備考3)。削除済みユーザーは通常含めない(備考2)
C -> DM : 管理先の従業員の「未処理」の勤怠修正申請を取得する
DM -> AR : 管理先の従業員の「未処理」の勤怠修正申請を取得する
AR --> DM : 一覧(従業員名, 対象日, 修正後の打刻の一覧, 申請理由, 送信日時)
DM --> C : 一覧(従業員名, 対象日, 修正後の打刻の一覧, 申請理由, 送信日時)
alt 該当する勤怠修正申請が存在しない
C -> L : 該当する勤怠修正申請が存在しないことを渡す
L -> A : 該当する勤怠修正申請が存在しないことを提示する
note : Alt-1。Alt-2の1に進む
else 該当する勤怠修正申請が存在する
C -> L : 「未処理」の勤怠修正申請の一覧を渡す
L -> A : 「未処理」の勤怠修正申請の一覧(従業員名, 対象日, 修正後の打刻の一覧, 申請理由, 送信日時)を提示する
end

# Alt-2〜4、Alt-6
loop アクターが条件を指定して探す間、繰り返す
A -> L : 条件(期間, 従業員, 処理状態, 管理先, 削除済みユーザーを含めるか)を指定する
L -> C : 条件に合う一覧を要求する(期間, 従業員, 処理状態, 管理先, 削除済みユーザーを含めるか)
C -> C : 指定された条件を検証する
alt 期間の開始日が終了日より後
C -> L : 期間の指定の誤りを渡す
L -> A : 期間の指定に誤りがあることを提示する
note : Alt-3。Alt-2の1に戻る
else 期間の指定に誤りが無い
C -> DM : 条件に合う勤怠修正申請を取得する
DM -> AR : 条件に合う勤怠修正申請を取得する
AR --> DM : 一覧(従業員名, 対象日, 修正後の打刻の一覧, 申請理由, 処理状態, 送信日時)
DM --> C : 一覧(従業員名, 対象日, 修正後の打刻の一覧, 申請理由, 処理状態, 送信日時)
note : 期間は対象日で絞る(備考4)。「取り下げ」は処理状態を指定したときに提示する(備考8)。指定があれば削除済みユーザーの分を含める(Alt-4、備考2)
alt 条件に合う勤怠修正申請が存在しない
C -> L : 条件に合う勤怠修正申請が存在しないことを渡す
L -> A : 条件に合う勤怠修正申請が存在しないことを提示する
note : Alt-6。Alt-2の1に戻る
else 条件に合う勤怠修正申請が存在する
C -> L : 条件に合う勤怠修正申請の一覧を渡す
L -> A : 条件に合う勤怠修正申請の一覧を提示する
note : Alt-2の3、Alt-4。メインフロー3に戻る
end
end
end

# メインフロー 3〜4
A -> L : 詳細を提示する勤怠修正申請を指定する
L -> C : 勤怠修正申請の詳細を要求する(勤怠修正申請)
C -> DM : 勤怠修正申請を取得する
DM -> AR : 勤怠修正申請を取得する
AR --> DM : 従業員, 対象日, 修正後の打刻の一覧, 申請理由, 処理状態, 却下理由
DM --> C : 従業員, 対象日, 修正後の打刻の一覧, 申請理由, 処理状態, 却下理由
C -> DM : 対象日の現在の勤怠記録を取得する
DM -> R : 対象日の現在の勤怠記録を取得する
R --> DM : 打刻の一覧(種類, 打刻日時)
DM --> C : 打刻の一覧(種類, 打刻日時)
C -> L : 勤怠修正申請の詳細を渡す
L -> A : 勤怠修正申請の詳細(対象日の現在の勤怠記録, 修正後の打刻の一覧, 申請理由, 処理状態, 却下理由)を提示する
note : 却下理由は「却下」のときだけ。打刻日時は秒まで提示する(備考6)

# メインフロー 5 と Alt-5
C -> DM : 対象日の公開済みのシフトを取得する
DM -> SF : 対象日の公開済みのシフトを取得する
SF --> DM : シフト(開始時刻, 終了時刻)
DM --> C : シフト(開始時刻, 終了時刻)
note : 下書きのシフトは見ない(備考1)
C -> C : 修正後の打刻の一覧が対象日のシフトと矛盾しているかを判定する
note : 対象日にシフトが無いのに修正後の打刻の一覧に勤務がある場合を矛盾とする(備考1)
opt 矛盾している
C -> L : 矛盾の内容を渡す
L -> A : 矛盾の内容を提示する
note : Alt-5。メインフロー6に進む
end

# メインフロー 6
C -> L : 判定の結果を渡す(矛盾の有無, シフトの開始時刻・終了時刻と修正後の打刻日時との差(分))
L -> A : 判定の結果(矛盾の有無。対象日にシフトがある場合は、シフトの開始時刻・終了時刻と修正後の打刻日時との差(分))を提示する
note : 矛盾があっても承認できる(備考1、A-52、ADR-0019)。拡張点:「未処理」なら承認 → UC-208、却下 → UC-209
