title UC-213 シフト日時変更申請を承認する
scope メインフロー、Alt-1〜6、Ex-1、Ex-2

actor A 勤怠管理者
boundary L シフト日時変更申請一覧表示画面
boundary V シフト変更承認確認画面
control C シフト日時変更承認制御
participant DM DataManager
entity AR シフト日時変更申請
entity SF シフト
entity TP シフト対象受付期間
entity SH シフト変更履歴
entity U 従業員
entity N 通知

# メインフロー 1〜2
A -> L : 「未処理」のシフト日時変更申請を指定して承認を要求する(UC-212 から)
note : 一覧の内容確認ボタンからシフト変更承認確認画面に移る(画面遷移図)
L -> C : 承認するシフト日時変更申請の内容を要求する(シフト日時変更申請)
C -> DM : シフト日時変更申請を取得する
DM -> AR : シフト日時変更申請を取得する
AR --> DM : 従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態
DM --> C : 従業員, 変更後の勤務日・開始時刻・終了時刻, 申請理由, 処理状態
C -> DM : 変更前のシフトを取得する
DM -> SF : 変更前のシフトを取得する
SF --> DM : 勤務日, 開始時刻, 終了時刻
DM --> C : 勤務日, 開始時刻, 終了時刻
C -> V : 承認するシフト日時変更申請の内容を渡す
V -> A : 承認するシフト日時変更申請の内容を提示し、承認の確認を求める

# Alt-4
opt 対象がアクター自身のシフト日時変更申請
C -> V : アクター自身のシフト日時変更申請であることを渡す
V -> A : 対象がアクター自身のシフト日時変更申請であることを提示する
note : Alt-4。メインフロー3に進む。自身の申請も承認できる(備考10、A-55)
end

# Ex-1
break 承認のキャンセルを要求した
A -> V : キャンセルボタンを押す
V -> C : キャンセルを要求する
C -> V : キャンセルの完了を渡す
V -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらず、シフトは変更されない
end

# メインフロー 3〜4
A -> V : 承認ボタンを押す
V -> C : 承認を要求する(シフト日時変更申請)
C -> DM : シフト日時変更申請を取得する
DM -> AR : シフト日時変更申請を取得する
AR --> DM : 従業員, 変更後の勤務日・開始時刻・終了時刻, 処理状態
DM --> C : 従業員, 変更後の勤務日・開始時刻・終了時刻, 処理状態
C -> DM : 変更前のシフトを取得する
DM -> SF : 変更前のシフトを取得する
SF --> DM : 勤務日, 開始時刻, 終了時刻, 削除済みかどうか
DM --> C : 勤務日, 開始時刻, 終了時刻, 削除済みかどうか
note : シフトの削除済みを表す属性は概念クラス図にない(暫定)
C -> C : 処理状態が「未処理」で、変更前のシフトが勤務済み・削除済みでないことを検証する
note : 勤務済みとはシフトの終了日時を現在時刻が過ぎていること。勤務中は承認できる(備考5)。ユーザーの削除で翌日以降のシフトは削除される(備考9)

# Alt-2・Alt-3
break 「未処理」でない、または変更前のシフトが勤務済み・削除済み
C -> V : 承認できない理由を渡す
V -> A : 承認できない状態であること、または変更前のシフトが変更できない状態であるため承認できないことを提示する
note : Alt-2・Alt-3。UC-212 に戻る。他の勤怠管理者が処理した、または従業員が取り下げた場合が Alt-3(備考11)
end

# メインフロー 5
C -> DM : 対象の従業員の所属に登録された対象期間を取得する
DM -> TP : 対象の従業員の所属に登録された対象期間を取得する
TP --> DM : 対象期間の一覧
DM --> C : 対象期間の一覧
C -> C : 変更後の勤務日が当日以降で、対象期間に含まれることを検証する
note : 対象期間は UC-215 で登録したもの(備考7)

# Alt-5・Alt-6
break 変更後の勤務日が当日より前、または対象期間に含まれない
C -> V : 承認できない理由を渡す
V -> A : 変更後の勤務日が当日より前、または対象期間に含まれないため承認できないことを提示する
note : Alt-5・Alt-6。UC-212 に戻る。申請は「未処理」のまま残る(備考6・7)
end

# メインフロー 6
C -> DM : 同じ従業員の、変更後の日時と重なる他のシフトを探す
DM -> SF : 同じ従業員の、変更後の日時と重なる他のシフトを探す
SF --> DM : 重複するシフト
DM --> C : 重複するシフト
note : 重複は時刻の重なりで判定する(備考4、A-33)

# Alt-1
break 変更後の日時が登録済みのシフトと重複している
C -> V : 重複しているシフトと、承認できないことを渡す
V -> A : 重複しているシフトと、そのシフト日時変更申請を承認できないことを提示する
note : Alt-1。UC-212 に戻る。申請は「未処理」のまま残る(備考4)
end

# メインフロー 7〜9
C -> DM : 処理状態を「承認済」に更新する
DM -> AR : 処理状態を「承認済」に更新する
note : 処理状態・変更履歴・シフトはまとめて保存する(Ex-2 の事後条件)
C -> DM : 変更履歴を記録する(変更前内容, 操作者, 操作日時)
DM -> SH : 変更履歴を記録する(変更前内容, 操作者, 操作日時)
note : 操作者は概念クラス図にない(暫定)
C -> DM : シフトを変更後の勤務日・開始時刻・終了時刻に更新する
DM -> SF : シフトを変更後の勤務日・開始時刻・終了時刻に更新する
note : 状態は「公開」のまま変えない(備考2)

# Ex-2 とメインフロー 10〜11
alt 保存に失敗した
C -> V : 保存に失敗したことを渡す
V -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー2に戻る
else 保存に成功した
C -> DM : 申請した従業員が削除済みかを取得する
DM -> U : 申請した従業員が削除済みかを取得する
U --> DM : 削除済みかどうか
DM --> C : 削除済みかどうか
note : 削除済みを表す属性は概念クラス図にない(ADR-0013、暫定)
opt 申請した従業員が削除済みユーザーでない
C -> DM : 通知を登録する(申請した従業員, 承認結果)
DM -> N : 通知を登録する(申請した従業員, 承認結果)
note : 承認結果の通知がシフトの変更の通知を兼ねる(備考3)。削除済みユーザーには通知しない(備考9)
end
C -> L : 承認の完了を渡す
note : 承認ボタンからシフト日時変更申請一覧表示画面に戻る(画面遷移図)
L -> A : 承認が完了したことを提示する
end
