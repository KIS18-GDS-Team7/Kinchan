title UC-215 シフト希望の対象期間・受付期間を登録する
scope メインフロー、Alt-1、Alt-2、Ex-1、Ex-2

actor A 勤怠管理者
boundary HM 勤怠管理者ホーム画面
boundary P シフト希望期間登録画面
control C 対象期間制御
participant DM DataManager
entity OU 所属単位
entity TP シフト対象受付期間

# メインフロー 1〜3
A -> HM : シフト希望期限設定ボタンを押す(シフト希望の対象期間・受付期間の登録を要求する)
note : 勤怠管理者ホーム画面のシフト希望期限設定ボタンからシフト希望期間登録画面に移る(画面遷移図)
HM -> C : アクターの管理先を要求する
C -> DM : アクターの管理先を取得する
DM -> OU : アクターの管理先を取得する
OU --> DM : 管理先の一覧
DM --> C : 管理先の一覧
C -> P : 管理先を渡す
P -> A : 管理先の一覧を提示し、管理先の指定を求める
A -> P : 管理先を指定する
note : 管理先(所属単位)ごとに登録する(備考2)

# メインフロー 4〜7、Alt-1、Alt-2
loop 誤りも重なりも無くなるまで繰り返す
P -> A : 対象期間(開始日, 終了日)と受付期間(開始日時, 終了日時)の入力を求める
A -> P : 対象期間と受付期間を入力する
A -> P : 確認ボタンを押す
P -> C : 入力内容の検証を要求する(管理先, 対象期間, 受付期間)
C -> C : 入力された対象期間と受付期間を検証する
note : 誤りは未入力、開始が終了より後または同じ(備考3)。受付期間と対象期間の前後関係の制約は TBD(備考6)
alt 対象期間または受付期間に誤りがある
C -> P : 誤りの内容を渡す
P -> A : 入力された対象期間または受付期間に誤りがあることを提示する
note : Alt-1。メインフロー4に戻る
else 誤りが無い
C -> DM : 同じ管理先の、対象期間が重なる登録済みの期間を探す
DM -> TP : 同じ管理先の、対象期間が重なる登録済みの期間を探す
TP --> DM : 重なっている対象期間
DM --> C : 重なっている対象期間
note : 重なる対象期間は登録できない(備考4)
opt 登録済みの対象期間と重なっている
C -> P : 重なっている対象期間を渡す
P -> A : 重なっている対象期間を提示する
note : Alt-2。メインフロー4に戻る
end
end
end

# メインフロー 8
C -> P : 入力された対象期間と受付期間を渡す
P -> A : 入力された対象期間と受付期間を提示し、登録の確認を求める

# Ex-1
break 登録のキャンセルを要求した
A -> P : キャンセルボタンを押す
P -> C : キャンセルを要求する
C -> C : 入力された内容を破棄する
C -> P : キャンセルの完了を渡す
P -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。対象期間と受付期間は登録されない
end

# メインフロー 9〜10
A -> P : 登録を指示する
note : 登録を指示するボタンは画面遷移図にない(暫定)
P -> C : 登録を要求する(管理先, 対象期間, 受付期間)
C -> DM : 対象期間と受付期間を登録する(管理先, 対象期間開始日, 対象期間終了日, 受付期間開始日時, 受付期間終了日時)
DM -> TP : 対象期間と受付期間を登録する(管理先, 対象期間開始日, 対象期間終了日, 受付期間開始日時, 受付期間終了日時)
note : 対で登録する(備考1)。変更・削除は TBD(備考7)。管理先の従業員に通知するかは TBD(備考8)

# Ex-2 とメインフロー 11
alt 保存に失敗した
C -> P : 保存に失敗したことを渡す
P -> A : 保存に失敗したことを提示する
note : Ex-2。入力された内容を保持したまま、メインフロー8に戻る
else 保存に成功した
C -> P : 登録の完了を渡す
P -> A : 登録が完了したことを提示する
end
