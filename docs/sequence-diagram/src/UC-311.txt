title UC-311 シフト希望を一覧表示する
scope メインフロー、Alt-1〜3

actor A 従業員
boundary L シフト一覧表示画面
boundary HL シフト希望一覧表示画面
control C シフト希望制御
participant DM DataManager
entity U 従業員
entity TP シフト対象受付期間
entity SH シフト希望

# メインフロー 1
A -> L : シフト希望ボタンを押す(シフト希望の一覧表示を要求する)
note : シフト一覧表示画面のシフト希望ボタンからシフト希望一覧表示画面に移る(画面遷移図)
L -> C : シフト希望の一覧を要求する
C -> DM : アクターの所属単位を取得する
DM -> U : アクターの所属単位を取得する
U --> DM : 所属単位
DM --> C : 所属単位
C -> DM : 所属単位に登録された対象期間と受付期間を取得する
DM -> TP : 所属単位に登録された対象期間と受付期間を取得する
TP --> DM : 対象期間の一覧(対象期間開始日, 対象期間終了日, 受付期間開始日時, 受付期間終了日時)
DM --> C : 対象期間の一覧(対象期間開始日, 対象期間終了日, 受付期間開始日時, 受付期間終了日時)

# Alt-3
break 対象期間が登録されていない
C -> HL : 対象期間が登録されていないことを渡す
HL -> A : 対象期間が登録されていないことを提示する
note : Alt-3。このユースケースを終了する
end

C -> C : 最初に提示する対象期間を決める
note : 受付期間中の対象期間。無ければ直近の対象期間(備考3、暫定)

# メインフロー 2 と Alt-1・Alt-2
loop 提示する対象期間を切り替えるたびに繰り返す
C -> DM : 対象期間のアクター自身のシフト希望を取得する
DM -> SH : 対象期間のアクター自身のシフト希望を取得する
SH --> DM : 一覧(希望日, 希望開始時刻, 希望終了時刻, 処理状態)
DM --> C : 一覧(希望日, 希望開始時刻, 希望終了時刻, 処理状態)
note : 1回目はメインフロー2、2回目以降は Alt-1の2。「下書き」もアクター自身には提示する(備考1)
alt その対象期間にアクター自身のシフト希望が存在しない
C -> HL : シフト希望が存在しないことを渡す
HL -> A : 該当するシフト希望が存在しないことを提示する
note : Alt-2(メインフロー2またはAlt-1の2)。Alt-1の1に進む。受付期間中なら UC-307 で送信を始められる(拡張点、備考5)
else シフト希望が存在する
C -> HL : シフト希望の一覧を渡す(希望日, 希望開始時刻, 希望終了時刻, 処理状態)
HL -> A : 対象期間のアクター自身のシフト希望の一覧(希望日、希望開始時刻・希望終了時刻、処理状態)を提示する
note : 拡張点: 受付期間中の対象期間についてシフト希望の送信を要求すると UC-307
end
opt 提示する対象期間を切り替えた
A -> HL : 提示する対象期間を指定する
HL -> C : シフト希望の一覧を要求する(対象期間)
note : Alt-1の1。指定された対象期間でループの先頭(Alt-1の2)に戻る
end
end

# メインフロー 3〜4
A -> HL : 一覧からシフト希望を1件指定する
note : Alt-1の3。対象期間を切り替えた後もここに戻る
HL -> C : シフト希望の詳細を要求する(シフト希望)
C -> DM : シフト希望を取得する
DM -> SH : シフト希望を取得する
SH --> DM : 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 却下理由, 送信日時
DM --> C : 希望日, 希望開始時刻, 希望終了時刻, 処理状態, 却下理由, 送信日時
C -> HL : シフト希望の詳細を渡す(希望日, 希望開始時刻, 希望終了時刻, 処理状態, 送信日時)
HL -> A : 指定されたシフト希望の詳細(希望日、希望開始時刻・希望終了時刻、処理状態、送信日時)を提示する
note : 拡張点: 「未処理」なら取り下げを要求すると UC-315(備考5)
opt 処理状態が「却下」
C -> HL : 却下理由を渡す
HL -> A : 却下理由を提示する
note : 却下理由は「却下」のときに提示する(備考2、#87)
end
