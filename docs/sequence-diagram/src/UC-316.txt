title UC-316 シフト日時変更申請を取り下げる
scope メインフロー、Alt-1、Ex-1、Ex-2

actor A 従業員
boundary L シフト日時変更申請表示画面
control C シフト日時変更申請制御
participant DM DataManager
entity SR シフト日時変更申請
entity SF シフト

# メインフロー 1〜2
A -> L : 「未処理」のシフト日時変更申請を指定して取り下げを要求する(UC-318 から)
note : 申請内容の一覧画面は画面遷移図にない(暫定)。画面遷移図のシフト日時変更申請表示画面は UC-309 の入力画面
L -> C : 取り下げるシフト日時変更申請の内容を要求する(シフト日時変更申請)
C -> DM : シフト日時変更申請を取得する
DM -> SR : シフト日時変更申請を取得する
SR --> DM : 変更後勤務日, 変更後開始時刻, 変更後終了時刻, 申請理由, 送信日時, 処理状態
DM --> C : 変更後勤務日, 変更後開始時刻, 変更後終了時刻, 申請理由, 送信日時, 処理状態
C -> DM : 変更前のシフトを取得する
DM -> SF : 変更前のシフトを取得する
SF --> DM : 勤務日, 開始時刻, 終了時刻
DM --> C : 勤務日, 開始時刻, 終了時刻
C -> L : 取り下げるシフト日時変更申請の内容を渡す
L -> A : 取り下げるシフト日時変更申請の内容を提示し、取り下げの確認を求める
note : 取り下げの確認を求める画面は画面遷移図にない(暫定)

# Ex-1
break 取り下げのキャンセルを要求した
A -> L : キャンセルボタンを押す
L -> C : キャンセルを要求する
C -> L : キャンセルの完了を渡す
L -> A : キャンセルが完了したことを提示する
note : Ex-1。待機状態に戻る。処理状態は変わらない
end

# メインフロー 3〜4
A -> L : シフト日時変更申請の取り下げを指示する
L -> C : 取り下げを要求する(シフト日時変更申請)
C -> DM : 処理状態を取得する
DM -> SR : 処理状態を取得する
SR --> DM : 処理状態
DM --> C : 処理状態
C -> C : 処理状態が「未処理」であることを検証する

# Alt-1
break 処理状態が「未処理」でなくなっている
C -> L : 取り下げできないことを渡す
L -> A : 対象のシフト日時変更申請が取り下げできない状態であることを提示する
note : Alt-1。このユースケースを終了する。一覧を提示した後に承認・却下・取り下げされた場合に当たる(備考4)
end

# メインフロー 5
C -> DM : 処理状態を「取り下げ」に更新する
DM -> SR : 処理状態を「取り下げ」に更新する
note : 削除しない(備考2、A-6)。シフトは変更しない(事後条件)

# Ex-2 とメインフロー 6
alt 保存に失敗した
C -> L : 保存に失敗したことを渡す
L -> A : 保存に失敗したことを提示する
note : Ex-2。メインフロー2に戻る
else 保存に成功した
C -> L : 取り下げの完了を渡す
note : 勤怠管理者には通知しない(備考5)
L -> A : 取り下げが完了したことを提示する
end
