title UC-317 通知を表示する
scope メインフロー、Alt-1。アクターは従業員と勤怠管理者(備考2)。通知の内容の一覧は備考3・5

actor A 従業員
actor M 勤怠管理者
boundary EH 従業員ホーム画面
boundary EN 通知表示画面
boundary MH 勤怠管理者ホーム画面
boundary MN 勤怠管理者通知表示画面
control C 通知制御
participant DM DataManager
entity N 通知
entity T 勤怠修正申請

# メインフロー 1
alt アクターが従業員
A -> EH : 通知ボタンを押す(通知の表示を要求する)
note : 従業員ホーム画面の通知ボタンから通知表示画面に移る(画面遷移図)
EH -> C : 通知の一覧を要求する
else アクターが勤怠管理者
M -> MH : 通知の表示を要求する
note : 勤怠管理者側の通知表示画面と、そこに移るボタンは画面遷移図にない(暫定)
MH -> C : 通知の一覧を要求する
end
C -> DM : アクター宛ての通知を取得する
DM -> N : アクター宛ての通知を取得する
N --> DM : 通知の一覧(内容, 作成日時)
DM --> C : 通知の一覧(内容, 作成日時)
note : 勤怠管理者には、アクター自身の所属単位の従業員として受け取った通知も含めてすべて提示する(備考2)。既読の扱いは TBD(備考6)

# Alt-1
break アクター宛ての通知が存在しない
alt アクターが従業員
C -> EN : 通知が存在しないことを渡す
EN -> A : アクター宛ての通知が存在しないことを提示する
else アクターが勤怠管理者
C -> MN : 通知が存在しないことを渡す
MN -> M : アクター宛ての通知が存在しないことを提示する
end
note : Alt-1。このユースケースを終了する
end

# メインフロー 2〜5
alt アクターが従業員
C -> EN : 通知の一覧を渡す(内容, 作成日時)
EN -> A : アクター宛ての通知の一覧(内容、作成日時)を提示する
A -> EN : 一覧から通知を1件指定する
EN -> C : 通知の内容を要求する(通知)
else アクターが勤怠管理者
C -> MN : 通知の一覧を渡す(内容, 作成日時)
MN -> M : アクター宛ての通知の一覧(内容、作成日時)を提示する
M -> MN : 一覧から通知を1件指定する
MN -> C : 通知の内容を要求する(通知)
end
C -> DM : 通知を取得する
DM -> N : 通知を取得する
N --> DM : 内容, 作成日時, 関連する対象の種類, 関連する対象のID
DM --> C : 内容, 作成日時, 関連する対象の種類, 関連する対象のID
note : 関連する対象の種類と ID は概念クラス図にない(暫定)
C -> DM : 関連する対象を取得する(関連する対象のID)
DM -> T : 関連する対象を取得する(関連する対象のID)
T --> DM : 関連する対象
DM --> C : 関連する対象
note : 対象の種類に応じて、シフト・シフト希望・勤怠修正申請・シフト日時変更申請・勤怠記録のいずれかから取得する(MF5)。図は勤怠修正申請を代表として描く。削除されたシフトの通知で何を提示するかは TBD(備考7)
alt アクターが従業員
C -> EN : 通知の内容と関連する対象を渡す
EN -> A : 指定された通知の内容と、その通知に関連する対象を提示する
else アクターが勤怠管理者
C -> MN : 通知の内容と関連する対象を渡す
MN -> M : 指定された通知の内容と、その通知に関連する対象を提示する
note : 関連する対象は UC-207・UC-204・UC-212 で提示されるもの(備考5)
end
