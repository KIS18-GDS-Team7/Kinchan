# UC-206 シフト希望を確認する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト希望を確認する(UC-206) |
| 目的（ゴール） | 従業員から送信されたシフト希望を一覧で確認し、承認・却下を判断するための情報を得る |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者がシフト希望の確認要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001) |
| 事後条件 | ・アクターにシフト希望の一覧と、指定したシフト希望の詳細が提示されていること |
| 拡張点 | シフト希望への対応<br>(メインフロー6の部分) |
| 関連ユースケース | シフト希望を承認する(UC-207) ≪extend≫<br>シフト希望を却下する(UC-208) ≪extend≫ |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト希望の確認を要求する
2. システムはアクターに担当する店舗の従業員から送信された未処理のシフト希望の一覧(従業員名、希望日、希望時間帯、提出日時)を提示する
3. アクターはシステムに詳細を確認するシフト希望を指定する
4. システムはアクターに指定されたシフト希望の詳細を提示する
5. システムはアクターに希望日に登録済みのシフトと人員の状況を提示する
6. アクターは必要に応じてシフト希望を承認する(UC-207)、または却下する(UC-208)
7. アクターはすべてのシフト希望を確認するまでメインフロー3〜6を繰り返す

### 代替フロー

**Alt-1：未処理のシフト希望が存在しなかった場合**

1. システムは未処理のシフト希望が存在しないことをアクターに提示する
2. このユースケースを終了する

**Alt-2：アクターが条件(期間、従業員、処理状態)を指定してシフト希望を探す場合**

1. アクターはシステムに条件を指定する
2. システムは条件に合うシフト希望の一覧をアクターに提示する
3. メインフロー3に戻る

### 例外フロー

なし
