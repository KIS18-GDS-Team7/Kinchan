# UC-216 シフト日時変更申請を却下する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト日時変更申請を却下する(UC-216) |
| 目的（ゴール） | シフト日時変更申請を却下し、却下の理由とともに結果を従業員に知らせる |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者がシフト日時変更申請の却下要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・アクターの担当する店舗の従業員から送信された未処理のシフト日時変更申請が存在すること |
| 事後条件 | ・シフト日時変更申請の処理状態が「却下」になっていること<br>・却下理由が記録されていること<br>・登録済みのシフトが変更されていないこと<br>・従業員に却下結果と却下理由が通知されていること |
| 拡張点 | なし |
| 関連ユースケース | シフト日時変更申請を確認する(UC-214) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト日時変更申請の却下を要求する
2. システムはアクターに却下するシフト日時変更申請の内容を提示し、却下理由の入力を求める
3. アクターはシステムに却下理由を入力する
4. システムはアクターに却下の確認を求める
5. アクターはシステムに却下を指示する
6. システムはシフト日時変更申請の処理状態を「却下」に更新し、却下理由を記録する
7. システムは従業員に却下結果と却下理由を通知する
8. システムはアクターに却下が完了したことを提示する

### 代替フロー

**Alt-1：却下理由が入力されていなかった場合**

1. システムは却下理由の入力が必要であることをアクターに提示する
2. メインフロー2に戻る

**Alt-2：対象のシフト日時変更申請がすでに処理済み、または従業員によって取り下げられていた場合**

1. システムは対象のシフト日時変更申請が却下できない状態であることをアクターに提示する
2. シフト日時変更申請を確認する(UC-214)に戻る

### 例外フロー

**Ex-1：メインフロー5より前にアクターが却下のキャンセルを要求した場合**

1. アクターはシステムに却下のキャンセルを要求する
2. システムは入力された却下理由を破棄する
3. システムはアクターにキャンセルが完了したことを提示する
4. システムは待機状態に戻る

事後条件

- シフト日時変更申請の処理状態が変わっていないこと
- システムが待機状態に戻っていること
