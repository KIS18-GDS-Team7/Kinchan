# UC-107 ユーザー一覧を表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | ユーザー一覧を表示する(UC-107) |
| 目的 | アクターが登録されているユーザーの一覧と各ユーザーの詳細を表示できる状態にする |
| アクター | マスタ管理者 |
| 開始条件 | アクターがユーザーの一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターがマスタ管理者権限を持つこと |
| 事後条件 | ・アクターにユーザーの一覧が提示されていること |
| 拡張点 | なし |
| 関連ユースケース | ・ユーザーを登録する(UC-101)<br>・ユーザーを編集する(UC-102)<br>・ユーザーを削除する(UC-103)<br>・ユーザーの権限を変更する(UC-104)<br>・ユーザーの所属を設定する(UC-105)<br>・ユーザーの所属を編集する(UC-106)<br>・勤怠管理者に管理先を割り当てる(UC-109) |

## イベントフロー

### メインフロー

1. アクターはシステムにユーザーの一覧表示を要求する
2. システムはアクターに削除済みでないユーザーの一覧(氏名、ユーザーID、権限、所属、管理先)を提示する
3. アクターはシステムに一覧からユーザーを1人指定する
4. システムはアクターに指定されたユーザーの詳細(氏名、ユーザーID、権限、所属、管理先、削除済みかどうか)を提示する

### 代替フロー

#### Alt-1: メインフロー2で、該当するユーザーが存在しなかった場合

1. システムは該当するユーザーが存在しないことをアクターに提示する
2. Alt-2の1に進む

#### Alt-2: アクターが条件(氏名、ユーザーID、権限、所属)を指定して探す場合

1. アクターはシステムに条件を指定する
2. システムはアクターに条件に合うユーザーの一覧を提示する
3. メインフロー3に戻る

#### Alt-3: Alt-2の1で、アクターが削除済みユーザーを含めることを指定した場合

1. システムはアクターに削除済みユーザーを含めたユーザーの一覧を提示する
2. メインフロー3に戻る

#### Alt-4: Alt-2の2で、条件に合うユーザーが存在しなかった場合

1. システムは条件に合うユーザーが存在しないことをアクターに提示する
2. Alt-2の1に戻る

### 例外フロー

なし

## 備考

1. 一覧と詳細の項目は氏名・ユーザーID・権限・所属・管理先。管理先は勤怠管理者権限を持つユーザーにだけあり、勤怠管理者に管理先を割り当てる(UC-109)で割り当てる(2026-10-21の会話)
2. 削除済みユーザーは通常は除外し、アクターが「削除済みを含める」と指定したときに提示する(#86、A-19)
3. 氏名・ユーザーIDで探し、権限・所属で絞る(A-31)
4. アクター名はrequirements.mdと同じく「マスタ管理者」(#113。#83 の「システム管理者」から改名。それ以前は「管理者」)
5. ユーザーの登録・変更・削除・権限・所属・管理先の操作は、関連ユースケースに挙げた各ユースケースで行う
