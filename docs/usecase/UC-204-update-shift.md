# UC-204 シフトを変更する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフトを変更する(UC-204) |
| 目的（ゴール） | 登録済みのシフトの内容を変更し、従業員に最新の勤務予定を伝える |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者がシフト変更要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・変更対象のシフトが登録されていること<br>・対象の従業員がアクターの担当する店舗に所属していること |
| 事後条件 | ・対象のシフトが変更後の内容に更新されていること<br>・変更前の内容が変更履歴として記録されていること<br>・対象の従業員にシフトが変更されたことが通知されていること |
| 拡張点 | なし |
| 関連ユースケース | なし |

## イベントフロー

### メインフロー

1. アクターはシステムにシフトの変更を要求する
2. システムはアクターに変更対象となるシフトの指定を求める
3. アクターはシステムに変更対象のシフトを指定する
4. システムはアクターに指定されたシフトの現在の内容を提示する
5. アクターはシステムに変更後のシフト情報を入力する
6. システムは入力されたシフト情報が有効なものか、従業員の勤務可能時間の範囲内か確認する
7. システムはアクターに変更前と変更後の内容を提示し、変更の確認を求める
8. アクターはシステムに変更を指示する
9. システムは変更前の内容を変更履歴として記録する
10. システムはシフトを変更後の内容に更新する
11. システムは対象の従業員にシフトが変更されたことを通知する
12. システムはアクターに変更が完了したことを提示する

### 代替フロー

**Alt-1：入力されたシフト情報が誤っていた場合**

1. システムは入力されたシフト情報に誤りがあることをアクターに提示する
2. メインフロー5に戻る

**Alt-2：同じ従業員の他のシフトと日時が重複していた場合**

1. システムは重複しているシフトをアクターに提示する
2. メインフロー5に戻る

**Alt-3：変更後のシフトが従業員の勤務可能時間の範囲外だった場合**

1. システムは範囲外であることと、従業員の勤務可能時間をアクターに提示する
2. メインフロー5に戻る

**Alt-4：指定されたシフトがすでに勤務済みだった場合**

1. システムは勤務済みのシフトは変更できないことをアクターに提示する
2. メインフロー2に戻る

### 例外フロー

**Ex-1：メインフロー8より前にアクターが変更のキャンセルを要求した場合**

1. アクターはシステムに変更のキャンセルを要求する
2. システムは入力された内容を破棄する
3. システムはアクターにキャンセルが完了したことを提示する
4. システムは待機状態に戻る

事後条件

- 入力された内容が破棄されていること
- シフトが変更されていないこと
- システムが待機状態に戻っていること
