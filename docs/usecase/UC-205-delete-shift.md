# UC-205 シフトを削除する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフトを削除する(UC-205) |
| 目的（ゴール） | 不要になったシフトを削除し、従業員の勤務予定から取り除く |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者がシフト削除要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・削除対象のシフトが登録されていること<br>・対象の従業員がアクターの担当する店舗に所属していること |
| 事後条件 | ・対象のシフトが削除されていること<br>・削除したシフトの内容が削除履歴として記録されていること<br>・対象の従業員にシフトが削除されたことが通知されていること |
| 拡張点 | なし |
| 関連ユースケース | なし |

## イベントフロー

### メインフロー

1. アクターはシステムにシフトの削除を要求する
2. システムはアクターに削除対象となるシフトの指定を求める
3. アクターはシステムに削除対象のシフトを指定する
4. システムはアクターに指定されたシフトの内容を提示し、削除の確認を求める
5. アクターはシステムに削除を指示する
6. システムは削除するシフトの内容を削除履歴として記録する
7. システムはシフトを削除する
8. システムは対象の従業員にシフトが削除されたことを通知する
9. システムはアクターに削除が完了したことを提示する

### 代替フロー

**Alt-1：指定されたシフトがすでに勤務済み、または勤務中だった場合**

1. システムは勤務済み・勤務中のシフトは削除できないことをアクターに提示する
2. メインフロー2に戻る

### 例外フロー

**Ex-1：メインフロー5より前にアクターが削除のキャンセルを要求した場合**

1. アクターはシステムに削除のキャンセルを要求する
2. システムはアクターにキャンセルが完了したことを提示する
3. システムは待機状態に戻る

事後条件

- シフトが削除されていないこと
- システムが待機状態に戻っていること
