# UC-206 シフト希望を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト希望を一覧表示する(UC-206) |
| 目的 | 勤怠管理者が管理先の従業員から送信されたシフト希望を一覧と詳細で表示し、シフト希望を承認・却下できる状態にする |
| アクター | 勤怠管理者 |
| 開始条件 | アクターがシフト希望の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・アクターが勤怠管理者権限を持つこと<br>・アクターに管理先が割り当てられていること(UC-118) |
| 事後条件 | ・アクターにシフト希望の一覧と、指定したシフト希望の詳細が提示されていること |
| 拡張点 | シフト希望の承認・却下(メインフロー6) |
| 関連ユースケース | シフト希望を承認する(UC-207) ≪extend≫<br>シフト希望を却下する(UC-208) ≪extend≫<br>シフト希望の対象期間・受付期間を登録する(UC-217)<br>シフト希望を送信する(UC-307) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト希望の一覧表示を要求する
2. システムはアクターに管理先の従業員から送信された処理状態が「未処理」のシフト希望の一覧(従業員名、所属単位、希望日、種別、希望時間帯、送信日時)を提示する
3. アクターはシステムに詳細を提示するシフト希望を指定する
4. システムはアクターに指定されたシフト希望の詳細(従業員名、所属単位、対象期間、希望日、種別、希望開始時刻、希望終了時刻、処理状態、送信日時)を提示する
5. システムはアクターに希望日に登録済みの同じ所属単位のシフトを提示する
6. アクターはシフト希望を承認する(UC-207)、またはシフト希望を却下する(UC-208)

### 代替フロー

#### Alt-1: 該当するシフト希望が存在しなかった場合

1. システムは該当するシフト希望が存在しないことをアクターに提示する
2. このユースケースを終了する

#### Alt-2: アクターが条件(期間、従業員、処理状態、管理先)を指定してシフト希望を探す場合

1. アクターはシステムに条件を指定する
2. システムは指定された条件を検証する
3. システムは条件に合うシフト希望の一覧をアクターに提示する
4. メインフロー3に戻る

#### Alt-3: 指定した期間の開始日が終了日より後だった場合

1. システムは期間の指定に誤りがあることをアクターに提示する
2. Alt-2の1に戻る

#### Alt-4: アクターが削除済みユーザーのシフト希望を含めて提示するよう指定した場合

1. アクターはシステムに「削除済みを含める」を指定する
2. システムは削除済みユーザーの分を含めたシフト希望の一覧をアクターに提示する
3. メインフロー3に戻る

### 例外フロー

なし

## 備考

1. 提示するのは管理先の従業員のシフト希望だけ。管理先が複数ある場合はすべての管理先の分を提示し、Alt-2の条件で管理先を絞れる(#84、2026-10-21 の会話)
2. 処理状態が「下書き」のシフト希望は提示しない(#87)。初期の一覧は「未処理」だけを提示し、Alt-2で「承認済」「却下」「取り下げ」も提示できる
3. 種別が「休日希望」のシフト希望も一覧に提示する(A-41)。休日希望は承認・却下の対象にしない。アクターがシフトを組むときの参照情報として提示する(暫定)
4. Alt-2の期間は希望日で絞る(暫定)
5. 削除済みユーザーのシフト希望は通常は提示しない。Alt-4で提示できる。削除済みユーザーの未処理のシフト希望も承認・却下できる(#86、A-19)
6. シフト希望の対象期間・受付期間はシフト希望の対象期間・受付期間を登録する(UC-217)で登録する。シフト希望は従業員がシフト希望を送信する(UC-307)で送信し、シフト希望を取り下げる(UC-315)で取り下げる
7. 承認・却下の結果は従業員のシフト希望を一覧表示する(UC-311)で提示される
8. 勤怠管理者への通知(従業員がシフト希望を送信・取り下げたとき)はTBD(#96)
