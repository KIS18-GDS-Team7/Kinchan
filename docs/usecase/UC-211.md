# UC-211 勤務実態を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 勤務実態を一覧表示する(UC-211) |
| 目的 | アクターが管理先の従業員の勤務実態(各打刻、休憩時間、勤務時間、遅刻・早退・欠勤・打刻漏れ)と36協定の警告を表示できる状態にする |
| アクター | 勤怠管理者 |
| 開始条件 | アクターが勤務実態の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターが勤怠管理者権限を持つこと<br>・アクターに管理先が割り当てられていること(UC-109) |
| 事後条件 | ・アクターに指定した従業員・期間の勤務実態(現在の勤務ステータス、日ごとの勤務、期間の合計勤務時間・残業時間・遅刻・早退・欠勤の回数、遅刻・早退・打刻漏れがある日)が提示されていること<br>・36協定の警告に当たる従業員がいる場合、その従業員と当月の残業時間が提示されていること |
| 拡張点 | なし |
| 関連ユースケース | ・打刻をする(UC-304)<br>・勤務ステータスを変更する(UC-305)<br>・休憩を打刻する(UC-312)<br>・勤怠を修正する(UC-210) |

## イベントフロー

### メインフロー

1. アクターはシステムに勤務実態の一覧表示を要求する
2. システムはアクターに対象の従業員(管理先の従業員から1人、または1つ以上の管理先の全従業員)と期間の指定を求める
3. アクターはシステムに対象の従業員と期間を指定する
4. システムは指定された期間を検証する
5. システムは各従業員について、遅刻、早退、欠勤、打刻漏れを判定する
6. システムは各従業員の当月の残業時間が36協定の警告に当たるかを判定する
7. システムはアクターに各従業員の現在の勤務ステータス(「出勤中」「退勤中」「休憩中」)を提示する
8. システムはアクターに各従業員の日ごとの勤務(各打刻、休憩時間、勤務時間)を提示する
9. システムはアクターに各従業員の期間の合計勤務時間、残業時間、遅刻・早退・欠勤の回数を提示する
10. システムはアクターに各従業員の遅刻、早退、打刻漏れがある日を提示する

### 代替フロー

#### Alt-1: メインフロー5で、指定した従業員・期間に勤怠記録も公開済みのシフトも存在しなかった場合

1. システムは該当する勤怠記録も公開済みのシフトも存在しないことをアクターに提示する
2. このユースケースを終了する

#### Alt-2: メインフロー4で、指定された期間の開始日が終了日より後だった場合

1. システムは期間の指定に誤りがあることをアクターに提示する
2. メインフロー2に戻る

#### Alt-3: メインフロー3で、アクターが削除済みユーザーを含めることを指定した場合

1. システムは削除済みユーザーを対象の従業員に含める
2. メインフロー4に進む

#### Alt-4: メインフロー6で、当月の残業時間が36協定の警告に当たる従業員がいた場合

1. システムは該当する従業員と当月の残業時間、「注意」または「超過」をアクターに提示する
2. メインフロー7に進む

### 例外フロー

なし

## 備考

1. 勤務ステータスは「出勤中」「退勤中」「休憩中」の3値であり、打刻をする(UC-304)または休憩を打刻する(UC-312)の打刻によってのみ変わる(A-61)。勤務ステータスの変更は勤務ステータスを変更する(UC-305)で扱う。日付が変わっても変えない
2. 打刻日時は秒まで記録し、秒まで提示する(#74、A-59)
3. 休憩時間は、休憩開始から休憩終了までの時間の合計と、同じ日の勤務と勤務の間の空白時間の合計である。勤務時間は、各勤務(出勤打刻から退勤打刻まで)の時間の合計から勤務の中の休憩の時間を引いたものであり、空白時間は引かない。いずれも各打刻の秒を切り捨てて分単位で計算する(#78からの導出、暫定。A-59)。空白時間の上限はTBD(要起票)
4. 日をまたぐ勤務は出勤打刻を行った日の勤怠記録に属する(#82)
5. 残業時間は1日8時間を超えた勤務時間の合計(法定労働時間のうち1日の上限を超えた分)とする。週40時間超は扱わない(A-56、暫定)
6. 36協定の警告は入れる(#92)。当月の残業時間が36時間以上で「注意」、45時間以上で「超過」とする(A-57)。対象は残業時間であり、勤務時間の合計ではない(#92)
7. 遅刻とは出勤打刻がシフトの開始時刻より後であること、早退とは退勤打刻がシフトの終了時刻より前であること、欠勤とは勤務済みのシフトに対応する勤務が無いことをいう(A-58、暫定)。勤務済みのシフトとは、シフトの終了日時(勤務日+終了時刻。日をまたぐ場合は翌日)を現在時刻が過ぎていることをいう(暫定)。遅刻・早退・欠勤の判定の対象は公開済みのシフトだけであり、下書きのシフトは見ない(#87の再起票からの導出、暫定)
8. 集計結果をCSVファイルとして出力できる(A-60、暫定)
9. 一覧には通常、削除済みユーザーを含めない(#86、A-19)
10. 管理先が複数ある場合、全従業員を指定したときはすべての管理先の従業員を対象とする。管理先を指定して絞ることもできる(#84からの導出、暫定)
11. 打刻漏れとは出勤打刻か退勤打刻の一方だけがある勤務をいう。打刻漏れをいつ判定するかはTBD(要起票)
12. 36協定とは別に、ユーザーごとに勤務時間の合計の上限(週28時間など)を持って警告するかはTBD(要起票)
13. 勤怠記録の修正は勤怠修正申請を承認する(UC-208)または勤怠を修正する(UC-210)で行う
