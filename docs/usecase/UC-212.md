# UC-212 シフト日時変更申請を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト日時変更申請を一覧表示する(UC-212) |
| 目的 | アクターが管理先の従業員から送信されたシフト日時変更申請の一覧と詳細を表示できる状態にする |
| アクター | 勤怠管理者 |
| 開始条件 | アクターがシフト日時変更申請の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターが勤怠管理者権限を持つこと<br>・アクターに管理先が割り当てられていること(UC-109) |
| 事後条件 | ・アクターにシフト日時変更申請の一覧と、指定したシフト日時変更申請の詳細が提示されていること |
| 拡張点 | ・アクターが指定した「未処理」のシフト日時変更申請の承認を要求した場合(メインフロー6の後)<br>・アクターが指定した「未処理」のシフト日時変更申請の却下を要求した場合(メインフロー6の後) |
| 関連ユースケース | ・シフト日時変更申請を承認する(UC-213)≪extend≫<br>・シフト日時変更申請を却下する(UC-214)≪extend≫ |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト日時変更申請の一覧表示を要求する
2. システムはアクターに管理先の従業員の「未処理」のシフト日時変更申請の一覧(従業員名、変更前のシフト、変更後の勤務日・開始時刻・終了時刻、申請理由、送信日時)を提示する
3. アクターはシステムに詳細を提示するシフト日時変更申請を指定する
4. システムはアクターに指定されたシフト日時変更申請の詳細(変更前のシフトの勤務日・開始時刻・終了時刻、変更後の勤務日・開始時刻・終了時刻、申請理由、処理状態、却下理由(「却下」のとき))を提示する
5. システムは変更後の日時が同じ従業員の他のシフトと重複するかを判定する
6. システムはアクターに重複の判定の結果を提示する

### 代替フロー

#### Alt-1: メインフロー2で、該当するシフト日時変更申請が存在しなかった場合

1. システムは該当するシフト日時変更申請が存在しないことをアクターに提示する
2. Alt-2の1に進む

#### Alt-2: アクターが条件(期間、従業員、処理状態、管理先)を指定して探す場合

1. アクターはシステムに条件を指定する
2. システムは指定された条件を検証する
3. システムはアクターに条件に合うシフト日時変更申請の一覧を提示する
4. メインフロー3に戻る

#### Alt-3: Alt-2の2で、指定された期間の開始日が終了日より後だった場合

1. システムは期間の指定に誤りがあることをアクターに提示する
2. Alt-2の1に戻る

#### Alt-4: Alt-2の1で、アクターが削除済みユーザーを含めることを指定した場合

1. システムはアクターに削除済みユーザーのシフト日時変更申請を含めた一覧を提示する
2. メインフロー3に戻る

#### Alt-5: メインフロー5で、変更後の日時が登録済みのシフトと重複していた場合

1. システムは重複しているシフトをアクターに提示する
2. メインフロー6に進む

#### Alt-6: Alt-2の3で、条件に合うシフト日時変更申請が存在しなかった場合

1. システムは条件に合うシフト日時変更申請が存在しないことをアクターに提示する
2. Alt-2の1に戻る

### 例外フロー

なし

## 備考

1. 変更後の日時が同じ従業員の他のシフトと重複するかを判定する。重複は時刻の重なりで判定する(A-33)。重複の有無によらず、メインフロー6の後に承認・却下に進める。重複がある申請はシフト日時変更申請を承認する(UC-213)で承認できず、シフト日時変更申請を却下する(UC-214)で却下できる
2. 一覧には通常、削除済みユーザーのシフト日時変更申請を含めない。削除済みユーザーの「未処理」のシフト日時変更申請はAlt-4で提示し、承認・却下できる(#86、A-19)
3. 管理先が複数ある場合はすべての管理先の従業員の分を提示する。Alt-2の条件で管理先を絞れる(#84からの導出、暫定)
4. Alt-2の期間は変更前のシフトの勤務日で絞る(暫定)
5. 従業員がシフト日時変更申請を送信すると、その従業員の所属を管理先に持つ勤怠管理者に通知される(#96)。取り下げは通知されない(2026-10-22の会話)。一覧はこのユースケースで提示する
6. シフト日時変更申請は従業員がシフト日時変更申請を送信する(UC-309)で送信する。対象は従業員自身の公開済みで勤務日が翌日以降のシフトである(A-36)。従業員がシフト日時変更申請を取り下げる(UC-316)で取り下げたシフト日時変更申請は処理状態「取り下げ」であり、Alt-2で処理状態を指定したときに提示する
