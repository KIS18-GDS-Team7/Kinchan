# UC-213 勤務実態を表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 勤務実態を表示する(UC-213) |
| 目的（ゴール） | 従業員の実際の出退勤時刻と勤務時間をリアルタイムで提示し、予定シフトとの差異や36協定の上限を超える長時間労働をアクターに示す |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者が勤務実態の表示要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001) |
| 事後条件 | ・指定した従業員・期間の勤務実態(出退勤時刻、勤務時間、予定シフトとの差異)がアクターに提示されていること |
| 拡張点 | なし |
| 関連ユースケース | なし |

## イベントフロー

### メインフロー

1. アクターはシステムに勤務実態の表示を要求する
2. システムはアクターに担当する店舗の中から対象となる従業員と期間の指定を求める
3. アクターはシステムに対象となる従業員と期間を指定する
4. システムは指定された条件の最新の打刻記録を1分単位で集計する
5. システムはアクターに各従業員の現在の勤務ステータス(勤務中、休憩中、退勤済みなど)を提示する
6. システムはアクターに日ごとの出勤時刻、退勤時刻、休憩時間、勤務時間を提示する
7. システムはアクターに期間内の合計勤務時間、残業時間、遅刻・早退・欠勤の回数を提示する
8. システムはアクターに予定シフトと打刻記録に差異がある日(遅刻、早退、打刻漏れ)を提示する
9. アクターは別の従業員・期間を表示する場合、メインフロー2〜8を繰り返す

### 代替フロー

**Alt-1：指定された条件に該当する勤怠記録が存在しなかった場合**

1. システムは該当する勤怠記録が存在しないことをアクターに提示する
2. メインフロー2に戻る

**Alt-2：残業時間が36協定の上限を超えている、または超えそうな従業員がいた場合**

1. システムは該当する従業員と残業時間を警告としてアクターに提示する
2. メインフロー9に進む

### 例外フロー

なし

## 備考

1. 残業時間の上限は36協定に合わせて設定する(値と「超えそう」と判定する基準はTBD)
2. 集計結果をファイルとして出力できるようにするかはTBD
3. 勤務時間は1分単位で集計し、丸めは行わない(労働基準法に基づく)
4. 勤務ステータスは従業員の打刻(UC-304)と勤務ステータスの変更(UC-305)によって変わる
