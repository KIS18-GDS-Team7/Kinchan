# UC-214 シフト日時変更申請を表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト日時変更申請を表示する(UC-214) |
| 目的（ゴール） | 従業員から送信されたシフト日時変更申請の一覧と詳細をアクターに提示し、承認・却下に必要な情報を示す |
| アクター | 勤怠管理者 |
| 開始条件（起動トリガー） | 勤怠管理者がシフト日時変更申請の表示要求を出す |
| 事前条件 | ・アクターがログインしていること(UC-001) |
| 事後条件 | ・アクターにシフト日時変更申請の一覧と、指定したシフト日時変更申請の詳細が提示されていること |
| 拡張点 | シフト日時変更申請への対応<br>(メインフロー6の部分) |
| 関連ユースケース | シフト日時変更申請を承認する(UC-215) ≪extend≫<br>シフト日時変更申請を却下する(UC-216) ≪extend≫ |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト日時変更申請の表示を要求する
2. システムはアクターに担当する店舗の従業員から送信された未処理のシフト日時変更申請の一覧(従業員名、変更前のシフト、変更希望の日時、申請理由、申請日時)を提示する
3. アクターはシステムに詳細を表示するシフト日時変更申請を指定する
4. システムはアクターに指定されたシフト日時変更申請の詳細を提示する
5. システムは変更希望の日時に他のシフトとの重複や人員不足が生じないか確認し、結果をアクターに提示する
6. アクターは必要に応じてシフト日時変更申請を承認する(UC-215)、または却下する(UC-216)
7. アクターは未処理のシフト日時変更申請がなくなるまでメインフロー3〜6を繰り返す

### 代替フロー

**Alt-1：未処理のシフト日時変更申請が存在しなかった場合**

1. システムは未処理のシフト日時変更申請が存在しないことをアクターに提示する
2. このユースケースを終了する

**Alt-2：アクターが条件(期間、従業員、処理状態)を指定してシフト日時変更申請を探す場合**

1. アクターはシステムに条件を指定する
2. システムは条件に合うシフト日時変更申請の一覧をアクターに提示する
3. メインフロー3に戻る

**Alt-3：変更希望の日時で重複や人員不足が生じる場合**

1. システムは重複・人員不足の内容をアクターに提示する
2. メインフロー6に進む

### 例外フロー

なし

## 備考

2. シフト日時変更申請は従業員がシフト日時変更申請を送信する(UC-309)で送信する
