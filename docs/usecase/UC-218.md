# UC-218 シフトを公開する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフトを公開する(UC-218) |
| 目的 | アクターが対象期間の下書きのシフトをまとめて公開し、そのシフトが従業員に表示される状態にする |
| アクター | 勤怠管理者 |
| 開始条件 | アクターがシフトの公開を要求する |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・アクターが勤怠管理者権限を持つこと<br>・アクターに管理先が割り当てられていること(UC-118)<br>・指定する管理先に対象期間が登録されていること(UC-217) |
| 事後条件 | ・指定した管理先の従業員の、対象期間に勤務日がある下書きのシフトの状態が「公開」になっていること<br>・このユースケースの実行で公開したシフトがある従業員それぞれにシフトが公開されたことが通知されていること |
| 拡張点 | なし |
| 関連ユースケース | ・シフト希望の対象期間・受付期間を登録する(UC-217)<br>・シフトを登録する(UC-203)<br>・シフト希望を承認する(UC-207)<br>・シフトを変更する(UC-204)<br>・シフトを削除する(UC-205)<br>・ユーザーの所属を編集する(UC-111)<br>・シフトを一覧表示する(UC-308) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフトの公開を要求する
2. システムはアクターに管理先と対象期間の指定を求める
3. アクターはシステムに管理先と対象期間を指定する
4. システムはアクターに指定された管理先の従業員の、対象期間に勤務日がある下書きのシフトの一覧(従業員名、勤務日、開始時刻、終了時刻)を提示し、公開の確認を求める
5. アクターはシステムに公開を指示する
6. システムは提示したシフトの状態を「公開」に更新する
7. システムはこのユースケースの実行で公開したシフトがある従業員それぞれにシフトが公開されたことを通知する
8. システムはアクターに公開が完了したことを提示する

### 代替フロー

#### Alt-1: メインフロー4で、対象期間に勤務日がある下書きのシフトが存在しなかった場合

1. システムは公開するシフトが存在しないことをアクターに提示する
2. このユースケースを終了する

### 例外フロー

#### Ex-1: メインフロー5より前にアクターが公開のキャンセルを要求した場合

1. アクターはシステムに公開のキャンセルを要求する
2. システムはアクターにキャンセルが完了したことを提示する
3. システムは待機状態に戻る

事後条件

- シフトの状態が変更されていないこと
- システムが待機状態に戻っていること

#### Ex-2: システムがシフトの保存に失敗した場合

1. システムはアクターに保存に失敗したことを提示する
2. メインフロー4に戻る

事後条件

- シフトの状態が変更されていないこと
- 従業員に通知されていないこと

## 備考

1. #87の再起票と2026-10-21の会話により新設。シフトの状態は「下書き」「公開」の2値で、対象期間ごとにまとめて公開する。1件ずつの公開はしない
2. 公開するのは、シフトを登録する(UC-203)で登録した下書きのシフトだけ。シフト希望を承認する(UC-207)で承認して登録するシフトは状態「公開」で登録されるため、このユースケースの対象でない(#87、2026-10-22の会話)。公開済みのシフトの状態は変えない
3. すでに公開した対象期間に後から登録した下書きのシフトも、このユースケースで改めて公開する(暫定)
4. 公開の単位をシフト希望の対象期間・受付期間を登録する(UC-217)の対象期間とするのは暫定。シフトは、登録・変更の時点で勤務日が所属の対象期間に含まれる(2026-10-22の会話)
5. ユーザーの所属を編集する(UC-111)で所属を変えた後の既存のシフト(変更前の所属の対象期間に含まれるもの)の扱い(下書きの公開、シフトを一覧表示する(UC-308)での提示)はTBD(要起票)。シフト希望の対象期間・受付期間を登録する(UC-217)で登録した対象期間の変更・削除の後の扱いも同じTBDに含める
6. 新設のユースケースであり、IDは仮。requirements.mdには無く、追記は別途
7. 公開後のシフトの変更・削除はシフトを変更する(UC-204)・シフトを削除する(UC-205)で行い、その都度対象の従業員に通知する(#87の再起票)
8. 公開されたシフトは、シフトを一覧表示する(UC-308)で従業員に提示される。下書きのシフトは提示されない
