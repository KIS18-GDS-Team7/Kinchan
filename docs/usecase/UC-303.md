# UC-303 ホームを表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | ホームを表示する(UC-303) |
| 目的 | アクターがログイン後に、アクター自身の現在の勤務ステータス・当日のシフト・当日の打刻・「未処理」の申請と希望の件数・通知の件数を表示し、打刻・シフト希望の送信・通知の表示を始められる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターがホームの表示を要求する、またはログインする(UC-301)が完了する |
| 事前条件 | ・アクターがログインしていること(UC-301) |
| 事後条件 | ・アクターにアクター自身の現在の勤務ステータス・当日のシフト・当日の打刻・「未処理」の申請と希望の件数・通知の件数が提示されていること |
| 拡張点 | ・出勤・退勤の打刻(メインフロー2の後)<br>・休憩の打刻(メインフロー2の後)<br>・通知の表示(メインフロー2の後)<br>・シフト希望の送信(Alt-1の1の後) |
| 関連ユースケース | ・打刻をする(UC-304)≪extend≫<br>・休憩を打刻する(UC-312)≪extend≫<br>・通知を表示する(UC-317)≪extend≫<br>・シフト希望を送信する(UC-307)≪extend≫<br>・ログインする(UC-301)<br>・勤務ステータスを変更する(UC-305) |

## イベントフロー

### メインフロー

1. アクターはシステムにホームの表示を要求する
2. システムはアクターにアクターの現在の勤務ステータス、当日を勤務日とするアクターの公開済みのシフト、当日の打刻(種類、打刻日時)、アクターの「未処理」の勤怠修正申請・シフト希望・シフト日時変更申請の件数、アクター宛ての通知の件数を提示する

### 代替フロー

#### Alt-1: メインフロー2で、アクターの所属に受付期間中の対象期間が登録されていた場合

1. システムはメインフロー2の内容に加えて、受付期間中の対象期間(開始日、終了日)と、その対象期間のシフト希望を送信できることをアクターに提示する
2. このユースケースを終了する

### 例外フロー

なし

4. UC名と提示する内容はTBD(#61)
