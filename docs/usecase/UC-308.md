# UC-308 シフトを一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフトを一覧表示する(UC-308) |
| 目的 | アクターが、アクター自身を含む所属単位の従業員の公開済みのシフトを表示できる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターがシフトの一覧の表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・アクターの所属が設定されていること(UC-110) |
| 事後条件 | ・アクターにアクターの所属単位の従業員の公開済みのシフトが提示されていること |
| 拡張点 | ・シフト日時変更申請の送信(メインフロー4の後) |
| 関連ユースケース | ・シフト日時変更申請を送信する(UC-309)≪extend≫<br>・ホームを表示する(UC-303)<br>・シフトを公開する(UC-218)<br>・シフト希望を承認する(UC-207)<br>・シフトを変更する(UC-204)<br>・シフトを削除する(UC-205) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフトの一覧の表示を要求する
2. システムはアクターに、アクターの所属単位の従業員の公開済みのシフトの一覧(従業員名、勤務日、開始時刻、終了時刻)を対象期間ごとに提示する
3. アクターはシステムに一覧からシフトを1件指定する
4. システムはアクターに指定されたシフトの詳細(従業員名、勤務日、開始時刻、終了時刻)を提示する

### 代替フロー

#### Alt-1: アクターが提示する対象期間を切り替えた場合

1. アクターはシステムに提示する対象期間を指定する
2. システムはアクターに指定された対象期間の公開済みのシフトの一覧(従業員名、勤務日、開始時刻、終了時刻)を提示する
3. メインフロー3に進む

#### Alt-2: 提示する対象期間に公開済みのシフトが無かった場合

1. システムは公開済みのシフトが無いことをアクターに提示する
2. このユースケースを終了する

### 例外フロー

なし

## 備考

1. 提示するのは状態が「公開」のシフトだけ。状態が「下書き」のシフトは提示しない(#87)。シフトを登録する(UC-203)で登録した下書きのシフトは、シフトを公開する(UC-218)で公開されるまで従業員に提示されない
2. シフト希望を承認する(UC-207)で登録したシフトは状態「公開」で登録され、承認した時点で提示される(#87、2026-10-22の会話)
3. 提示する範囲はアクターの所属単位の従業員(アクター自身を含む)のシフト(A-74を所属単位に読み替え)
4. 公開後にシフトを変更する(UC-204)・シフトを削除する(UC-205)で変更・削除されたシフトは、変更後の内容を提示する(#87)
5. シフトの勤務日は登録済みの対象期間に含まれる日に限られるため、どの対象期間にも含まれないシフトは存在しない(2026-10-22の会話)
6. 一覧の単位は対象期間ごと(暫定)。最初に提示する対象期間はTBD(要起票)
7. requirements.mdでは「登録シフトを一覧表示する」。改名は別途
8. アクター自身のシフトを指定して、シフト日時変更申請を送信する(UC-309)を要求できる。承認された変更はこのユースケースで変更後のシフトとして提示される
