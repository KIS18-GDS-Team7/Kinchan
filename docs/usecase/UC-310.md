# UC-310 勤怠修正申請内容を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 勤怠修正申請内容を一覧表示する(UC-310) |
| 目的 | アクターがアクター自身の送信した勤怠修正申請の一覧と詳細(処理状態、却下理由を含む)を表示し、変更・取り下げの対象を指定できる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターが勤怠修正申請の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターの所属が設定されていること(UC-105) |
| 事後条件 | ・アクターに勤怠修正申請の一覧と、指定した勤怠修正申請の詳細が提示されていること |
| 拡張点 | ・「未処理」の勤怠修正申請の変更・取り下げ(メインフロー4の後) |
| 関連ユースケース | ・勤怠修正申請を送信する(UC-306)≪extend≫<br>・勤怠修正申請を取り下げる(UC-314)≪extend≫<br>・ホームを表示する(UC-303)<br>・勤怠記録を一覧表示する(UC-313)<br>・通知を表示する(UC-317) |

## イベントフロー

### メインフロー

1. アクターはシステムに勤怠修正申請の一覧表示を要求する
2. システムはアクターにアクター自身の勤怠修正申請の一覧(対象日、送信日時、処理状態)を提示する
3. アクターはシステムに詳細を提示する勤怠修正申請を指定する
4. システムはアクターに指定された勤怠修正申請の詳細(対象日、対象日の勤怠記録の打刻の一覧、修正後の打刻の一覧、申請理由、処理状態、却下理由(「却下」のとき)、送信日時)を提示する

### 代替フロー

#### Alt-1: メインフロー2で、該当する勤怠修正申請が存在しなかった場合

1. システムは該当する勤怠修正申請が存在しないことをアクターに提示する
2. Alt-2の1に進む

#### Alt-2: アクターが条件(期間、処理状態)を指定して探す場合

1. アクターはシステムに条件を指定する
2. システムは指定された条件を検証する
3. システムはアクターに条件に合う勤怠修正申請の一覧を提示する
4. メインフロー3に戻る

#### Alt-3: Alt-2の2で、指定された期間の開始日が終了日より後だった場合

1. システムは期間の指定に誤りがあることをアクターに提示する
2. Alt-2の1に戻る

#### Alt-4: Alt-2の3で、条件に合う勤怠修正申請が存在しなかった場合

1. システムは条件に合う勤怠修正申請が存在しないことをアクターに提示する
2. Alt-2の1に戻る

### 例外フロー

なし

## 備考

1. 一覧は処理状態にかかわらず、アクター自身のすべての勤怠修正申請(「未処理」「承認済」「却下」「取り下げ」)を提示する
2. 却下理由は処理状態が「却下」のときに提示する(A-51)
3. 取り下げた勤怠修正申請はデータを消さず、処理状態「取り下げ」で提示する(A-6)
4. 条件の期間は対象日で絞る(暫定)
5. UC名はrequirements.mdのまま
6. 変更できるのは処理状態が「未処理」の勤怠修正申請だけであり、変更は勤怠修正申請を送信する(UC-306)のAlt-1で行う
7. 取り下げられるのは処理状態が「未処理」の勤怠修正申請だけであり、取り下げは勤怠修正申請を取り下げる(UC-314)で行う
8. 承認結果・却下結果は通知としても作られ、通知を表示する(UC-317)で提示される
