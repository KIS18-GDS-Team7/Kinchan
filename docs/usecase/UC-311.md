# UC-311 シフト希望を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト希望を一覧表示する(UC-311) |
| 目的 | アクターがアクター自身のシフト希望とその処理状態・却下理由を対象期間ごとに表示できる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターがシフト希望の一覧の表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-001)<br>・アクターの所属が設定されていること(UC-110) |
| 事後条件 | ・アクターにアクター自身のシフト希望が対象期間ごとに提示されていること |
| 拡張点 | ・シフト希望の送信(メインフロー2の後)<br>・シフト希望の取り下げ(メインフロー4の後) |
| 関連ユースケース | ・シフト希望を送信する(UC-307)≪extend≫<br>・シフト希望を取り下げる(UC-315)≪extend≫<br>・シフト希望の対象期間・受付期間を登録する(UC-217)<br>・シフト希望を承認する(UC-207)<br>・シフト希望を却下する(UC-208) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト希望の一覧の表示を要求する
2. システムはアクターに、受付期間中の対象期間(無ければ直近の対象期間)のアクター自身のシフト希望の一覧(希望日、種別、希望開始時刻・希望終了時刻、処理状態)を提示する
3. アクターはシステムに一覧からシフト希望を1件指定する
4. システムはアクターに指定されたシフト希望の詳細(希望日、種別、希望開始時刻・希望終了時刻、処理状態、却下理由(「却下」のとき)、送信日時)を提示する

### 代替フロー

#### Alt-1: アクターが提示する対象期間を切り替えた場合

1. アクターはシステムに提示する対象期間を指定する
2. システムはアクターに指定された対象期間のアクター自身のシフト希望の一覧(希望日、種別、希望開始時刻・希望終了時刻、処理状態)を提示する
3. メインフロー3に進む

#### Alt-2: 提示する対象期間にアクターのシフト希望が無かった場合

1. システムはシフト希望が無いことをアクターに提示する
2. このユースケースを終了する

#### Alt-3: アクターの所属単位に対象期間が登録されていなかった場合

1. システムは対象期間が登録されていないことをアクターに提示する
2. このユースケースを終了する

### 例外フロー

なし

## 備考

1. 種別「時間指定」のシフト希望の処理状態は「下書き」「未処理」「承認済」「却下」「取り下げ」(#87)。「下書き」のシフト希望はアクター自身には提示する(勤怠管理者には提示しない)
2. 処理状態が「却下」のシフト希望には却下理由を提示する(#87)
3. 種別「休日希望」のシフト希望は承認・却下の対象にならないため、処理状態は「下書き」「送信済」「取り下げ」のいずれかになる。「送信済」は送信した「休日希望」だけが取る処理状態(A-41、2026-10-22の会話)
4. 最初に提示する対象期間は受付期間中の対象期間とし、無ければ直近の対象期間とする(暫定)
5. 過去の対象期間のシフト希望をどこまで提示するかはTBD(要起票)
6. 受付期間中の対象期間については、シフト希望を送信する(UC-307)を要求してシフト希望を送信・変更できる。「未処理」の「時間指定」のシフト希望と「送信済」の「休日希望」のシフト希望は、シフト希望を取り下げる(UC-315)を要求して取り下げられる
7. 対象期間と受付期間は、勤怠管理者がシフト希望の対象期間・受付期間を登録する(UC-217)で登録する(#88)
8. 承認結果・却下結果はシフト希望を承認する(UC-207)・シフト希望を却下する(UC-208)で通知され、このユースケースで処理状態として提示される
