# UC-311 シフト希望を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | シフト希望を一覧表示する(UC-311) |
| 目的 | アクターがアクター自身のシフト希望とその処理状態・却下理由を対象期間ごとに表示できる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターがシフト希望の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターの所属が設定されていること(UC-105) |
| 事後条件 | ・アクターにアクター自身のシフト希望が対象期間ごとに提示されていること |
| 拡張点 | ・シフト希望の送信(メインフロー2、Alt-1の2、またはAlt-2の1の後。条件: アクターが受付期間中の対象期間についてシフト希望の送信を要求した場合)<br>・「未処理」のシフト希望の取り下げ(メインフロー4の後。条件: アクターが指定した「未処理」のシフト希望の取り下げを要求した場合) |
| 関連ユースケース | ・シフト希望を送信する(UC-307)≪extend≫<br>・シフト希望を取り下げる(UC-315)≪extend≫<br>・シフト希望の対象期間・受付期間を登録する(UC-215)<br>・シフト希望を承認する(UC-205)<br>・シフト希望を却下する(UC-206) |

## イベントフロー

### メインフロー

1. アクターはシステムにシフト希望の一覧表示を要求する
2. システムはアクターに、受付期間中の対象期間(無ければ直近の対象期間)のアクター自身のシフト希望の一覧(希望日、希望開始時刻・希望終了時刻、処理状態)を提示する
3. アクターはシステムに一覧からシフト希望を1件指定する
4. システムはアクターに指定されたシフト希望の詳細(希望日、希望開始時刻・希望終了時刻、処理状態、却下理由(「却下」のとき)、送信日時)を提示する

### 代替フロー

#### Alt-1: アクターが提示する対象期間を切り替えた場合

1. アクターはシステムに提示する対象期間を指定する
2. システムはアクターに指定された対象期間のアクター自身のシフト希望の一覧(希望日、希望開始時刻・希望終了時刻、処理状態)を提示する
3. メインフロー3に戻る

#### Alt-2: メインフロー2またはAlt-1の2で、提示する対象期間はあるが、その対象期間にアクター自身のシフト希望が存在しなかった場合

1. システムは該当するシフト希望が存在しないことをアクターに提示する
2. Alt-1の1に進む

#### Alt-3: メインフロー2で、アクターの所属に対象期間が登録されていなかった場合

1. システムは対象期間が登録されていないことをアクターに提示する
2. このユースケースを終了する

### 例外フロー

なし

## 備考

1. シフト希望の処理状態は「下書き」「未処理」「承認済」「却下」「取り下げ」(#87、2026-10-21の会話)。「下書き」のシフト希望はアクター自身には提示する(勤怠管理者には提示しない)
2. 処理状態が「却下」のシフト希望には却下理由を提示する(#87)
3. 最初に提示する対象期間は受付期間中の対象期間とし、無ければ直近の対象期間とする(暫定)
4. 過去の対象期間のシフト希望をどこまで提示するかはTBD(要起票)
5. 受付期間中の対象期間については、シフト希望を送信する(UC-307)でシフト希望を送信・変更できる。希望が無い対象期間でも送信を始められる(Alt-2の1の後の拡張点)。また、シフト希望が無い対象期間から別の対象期間に切り替えられる(Alt-2からAlt-1)。「未処理」のシフト希望は、シフト希望を取り下げる(UC-315)で取り下げられる
6. 対象期間と受付期間は、勤怠管理者がシフト希望の対象期間・受付期間を登録する(UC-215)で登録する(#88)
7. 承認結果・却下結果はシフト希望を承認する(UC-205)・シフト希望を却下する(UC-206)で通知され、このユースケースで処理状態として提示される
