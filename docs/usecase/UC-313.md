# UC-313 勤怠記録を一覧表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 勤怠記録を一覧表示する(UC-313) |
| 目的 | アクターがアクター自身の勤怠記録(シフト、打刻、休憩時間、勤務時間、勤怠修正申請の処理状態)を期間ごとに表示し、勤怠修正申請の対象日を指定できる状態にする |
| アクター | 従業員 |
| 開始条件 | アクターが勤怠記録の一覧表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-301)<br>・アクターの所属が設定されていること(UC-105) |
| 事後条件 | ・アクターに期間の勤怠記録の一覧と、指定した日の勤怠記録の詳細が提示されていること |
| 拡張点 | ・勤怠修正申請の送信(メインフロー4の後。条件: アクターが指定した日について勤怠修正申請の送信を要求した場合) |
| 関連ユースケース | ・勤怠修正申請を送信する(UC-306)≪extend≫<br>・出退勤を打刻する(UC-304)<br>・休憩を打刻する(UC-312)<br>・勤怠修正申請内容を一覧表示する(UC-310)<br>・従業員の勤怠を修正する(UC-210) |

## イベントフロー

### メインフロー

1. アクターはシステムに勤怠記録の一覧表示を要求する
2. システムはアクターに当月のアクター自身の勤怠記録の一覧(日ごとの公開済みのシフト、各打刻(種類、打刻日時)、休憩時間、勤務時間、その日を対象日とする勤怠修正申請の処理状態)を提示する
3. アクターはシステムに詳細を提示する日を指定する
4. システムはアクターに指定された日の勤怠記録の詳細(打刻の一覧(種類、打刻日時)、休憩時間、勤務時間、修正履歴)を提示する

### 代替フロー

#### Alt-1: メインフロー2で、該当する勤怠記録も公開済みのシフトも存在しなかった場合

1. システムは該当する勤怠記録も公開済みのシフトも存在しないことをアクターに提示する
2. Alt-2の1に進む

#### Alt-2: アクターが条件(期間)を指定して探す場合

1. アクターはシステムに条件を指定する
2. システムは指定された条件を検証する
3. システムはアクターに条件に合うアクター自身の勤怠記録の一覧を提示する
4. メインフロー3に戻る

#### Alt-3: Alt-2の2で、指定された期間の開始日が終了日より後だった場合

1. システムは期間の指定に誤りがあることをアクターに提示する
2. Alt-2の1に戻る

#### Alt-4: Alt-2の3で、条件に合う勤怠記録も公開済みのシフトも存在しなかった場合

1. システムは条件に合う勤怠記録も公開済みのシフトも存在しないことをアクターに提示する
2. Alt-2の1に戻る

### 例外フロー

なし

## 備考

1. 初期の期間は当月とする(A-48、暫定)。期間は勤怠記録の属する日で絞る。勤怠記録は出勤打刻を行った日に属し、日をまたぐ勤務も出勤打刻を行った日の勤怠記録として提示する(#82)
2. 打刻日時は秒まで提示する(#74、A-59)
3. 休憩時間は、休憩開始から休憩終了までの時間の合計と、同じ日の勤務と勤務の間の空白時間の合計である。勤務時間は、各勤務(出勤打刻から退勤打刻まで)の時間の合計から勤務の中の休憩の時間を引いたものであり、空白時間は引かない。いずれも各打刻の秒を切り捨てて分単位で計算する(#78からの導出、暫定。A-59)。空白時間の上限はTBD(要起票)
4. シフトは公開済みのものだけを提示し、下書きのシフトは提示しない(#87の再起票)
5. 修正履歴は勤怠記録を修正したときの修正前の内容・修正者・修正日時・修正理由・根拠(勤怠修正申請に基づく修正か、勤怠管理者の直接修正か)を記録したものであり、削除できない(振り直し前のドラフトUC-212、A-54)。修正履歴の修正理由は、従業員の勤怠を修正する(UC-210)による修正では入力された修正理由、勤怠修正申請を承認する(UC-208)による修正では申請理由とする(暫定)。修正履歴は従業員の勤怠を修正する(UC-210)とこのユースケースで提示する(A-54、暫定)
6. 打刻漏れの判定時点はTBD(要起票)
7. 新設のユースケースであり、IDは仮。requirements.mdのUC一覧にも追記済み
8. このユースケースは勤怠修正申請を送信する(UC-306)の起点である。当月に勤怠記録も公開済みのシフトも無い場合も、Alt-1からAlt-2に進んで期間を指定し直し、前月の日を対象日に指定して勤怠修正申請を要求できる(前月分の勤怠修正申請は当月N日まで送信できる。#85)。対象日が修正申請の期限を過ぎていた場合などの扱いは勤怠修正申請を送信する(UC-306)に書く
9. 勤怠修正申請の処理状態は勤怠修正申請内容を一覧表示する(UC-310)でも提示する
