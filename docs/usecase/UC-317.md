# UC-317 通知を表示する

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 通知を表示する(UC-317) |
| 目的 | アクターがアクター自身宛ての通知と、その通知に関連する対象を表示できる状態にする |
| アクター | 従業員、勤怠管理者 |
| 開始条件 | アクターが通知の表示を要求する |
| 事前条件 | ・アクターがログインしていること(UC-001) |
| 事後条件 | ・アクターにアクター宛ての通知が提示されていること |
| 拡張点 | なし |
| 関連ユースケース | ・ホームを表示する(UC-303)<br>・シフトを一覧表示する(UC-308)<br>・シフト希望を一覧表示する(UC-311)<br>・シフト日時変更申請内容を一覧表示する(UC-318)<br>・勤怠修正申請内容を一覧表示する(UC-310)<br>・勤怠記録を一覧表示する(UC-313) |

## イベントフロー

### メインフロー

1. アクターはシステムに通知の表示を要求する
2. システムはアクターにアクター宛ての通知の一覧(内容、作成日時)を提示する
3. アクターはシステムに一覧から通知を1件指定する
4. システムはアクターに指定された通知の内容を提示する
5. システムはアクターにその通知に関連する対象(シフト、シフト希望、勤怠修正申請、シフト日時変更申請、勤怠記録のいずれか)を提示する

### 代替フロー

#### Alt-1: メインフロー2で、アクター宛ての通知が存在しなかった場合

1. システムはアクター宛ての通知が存在しないことをアクターに提示する
2. このユースケースを終了する

### 例外フロー

なし

## 備考
